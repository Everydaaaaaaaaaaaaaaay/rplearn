# 小一原创插图源文件

12 个 SVG 均由本项目逐项绘制，未使用教材图片、描摹教材构图或外部素材。它们是正式 PNG 的可编辑源文件，不直接由客户端加载。

- 文具：book、pencil、ruler、schoolbag。
- 水果：apple、banana、orange、pear。
- 五官：eye、ear、nose、mouth。

2026-09-26 将每个 SVG 渲染为 512 × 512、不透明白底、8 位 RGB PNG，逐张目视检查形状、裁切与英文答案泄露。文件 SHA-256、尺寸、图意和实际审核记录登记在上级 `catalog.json` 的 `imageAssets` 中。使用该图片的各道题另有选项语义和替代描述审核。

修改 SVG 后需重新渲染、目视检查并注册新的内容标识；不要覆盖旧摘要文件。题目引用变化也要发布新版本，保留已开始挑战引用的旧图片。
