## 实际来源核读

所有题目、脚本、人物讨论和故事都是作者逐道书写的原创材料。ETS资料只用于确定任务与技能边界，没有改写其样题，没有加入TOEFL Essentials或旧版综合写作、旧版四任务口语。

- [ETS Writing](https://www.ets.org/toefl/test-takers/ibt/about/content/writing.html)：实际读 Writing tasks type、What to Expect。用户指定的 `writing/.html` 返回错误，改读同站规范路径。采用句子重组、邮件与学术讨论三个方向，后两者的真实产出独立列为proposed。
- [ETS Reading](https://www.ets.org/toefl/test-takers/ibt/about/content/reading.html)：实际读 Reading Task Types、What to Expect。采用补词、日常材料和学术阅读的局部技能；单题短文及单空补词不声称完整复制官方组题结构。
- [ETS Listening](https://www.ets.org/toefl/test-takers/ibt/about/content/listening.html)：实际读 Listening Task Types、What to Expect。网页写“two”但随后列出四类，故依据其四个条目及规格PDF设计简短回应、对话、公告、学术短讲。
- [ETS Speaking](https://www.ets.org/toefl/test-takers/ibt/about/content/speaking.html)：实际读 Speaking Task Types、What to Expect。听后复述和访谈必须收集真实口语，不能拿选择题替代。
- [ETS 2026规格PDF](https://www.in.ets.org/content/dam/ets-org/pdfs/toefl/toefl-ibt-test-specifications-2026.pdf)：实际核读解析正文的四科概览，以及Reading印刷7–9、Listening 10–12、Writing 13–14、Speaking 15–17页的Claim、Stimulus、能力陈述和任务约束。PDF阅读器页码比印刷页码加1；不是整本目视核读。只抽取技能边界，不复制官方量表，也不声称作者题目经过官方难度校准。

先核读了本目录README、`postgraduate-second-unit.astra.json`、当前`content.ts`和`first-review-spec.md`。现有正式合同支持arrange、choice、completion、listeningChoice、matching、cloze，但没有托福方向的level值；作者稿额外字段与待制作媒体不能直接导入正式合同。

## 交付与训练蓝图

两组各18题，各配一个完整、简洁的双语开场小故事。故事不被拆到题间，所有题都不根据故事作答。

| 项目 | 数量与范围 |
| --- | --- |
| 句子重组 | 6题：嵌入问句、关系从句、过去反事实、形式主语、explain论元、比较关联 |
| 文字选择 | 16题：指代、语境义、句子功能、证据范围、条件通知、邮件及讨论辨析、衔接与摘要 |
| 听力选择 | 9题：2短回应、3对话、2公告、2学术短讲；完整脚本，全部pending |
| 开放补词 | 3题：2个完整单词恢复、1个限定词表条件连接语 |
| 真正配对 | 1题：三条主张和四条论据，包含主题相关但不直接支持的干扰 |
| 真正多空 | 1题：103词篇章中两处逻辑关系，两套合理填法显式接收 |
| 独立proposed | 邮件、学术讨论、听后复述、四问访谈；不计入36题 |

第二组b07、b11、b17分别为92、101、103个按空白分隔的英文词/空位单元。三个完整材料分别增加分母和自报限制、检索收益与双重编辑工作、历史事件顺序与动机的不同证据边界；不是仅把第一组换主题拉长。

`difficulty`是作者对所需推理的描述，没有对应考试分数。客观题中的邮件和讨论只训练辨析；独立写作、语音可理解度、流利度仍没有测量证据。

## 跨题泄漏与呈现约束

逐题检查故事、同组前后题、另一组以及proposed题：没有复用材料，没有题目要求读取前题答案。动物、校园、科研主题偶有相近，但事实、目标与推理路径不同。a04和b04分别是名词及事件回指，a15和b16分别是说明例子及反例；a07、b06、b07分别是因果混杂、时间外推、分母与自报，不是同一结构填槽换词。

b09的一题内部三对材料、b17的一题内部两空属于明确整体任务，不伪装成三次或两次独立作答。独立访谈proposed允许同一背景下连续提问，但不要求上一回答正确才能完成下一问；不得拆成四道有唯一内容答案的客观题。

9段听力的题面和选项不能在答前泄露脚本。音频脚本、解释、答案、解析字段都不能进入用户答前可见数据；制作与主审时才能读取。缺音频时不静默变成阅读题后仍记录听力通过。必要降级必须明确标为阅读脚本训练，另计证据。

重播、提示、揭示和撤销保留曝光事件；重做正确不记录成未暴露首次表现。未做学习者长期效果或真人难度验证。
