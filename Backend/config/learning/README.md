## 文件与审核语义

- `catalog.json`：来源的实际核读范围、证据哈希、能力目标和唯一单元目录。
- `units/<id>.json`：版本化剧情、独立题干、答案、提示与解释。
- `reviews/<id>.json`：绑定内容哈希的逐题作者自审；每个选择项的适切性、正确/错误作答样例及歧义处理。
- `audio/<内容标识>.wav`：原创固定语音，24 kHz、单声道、16 位 PCM；元数据及审核范围登记在目录的 `audioAssets`。96 段原文由作者编写，使用本地 Supertonic3 的 M5/F3/M3 固定声音生产。最终文件经统一音量、峰值检查，以及不提供提示词的 base.en / small.en 识别核对；小一的 school bag/schoolbag 只合并分词。Ruby 两段 pear 使用标准同音词 pair 辅助合成，识别核对实际合成输入 pair；原始问题、处理方式及证据见对应音频审核。工具不支持音频输入，未声称完成人耳音色、口音与韵律审听。

- `images/<内容标识>.png`：目录的 `imageAssets` 登记 SHA-256、尺寸、来源、图片描述与审核结论。只接受 128～1024 像素、2 MB 内、单帧 8 位 RGB/RGBA PNG；校验文件摘要、块 CRC、解压长度与扫描行。当前登记 44 张小一原创插图，源文件保存在 `image-sources/`；工程样本不导入此处。

图片选择、听辨选择和配对题的选项可引用 `imageAssetId`。`text` 用于无障碍替代描述及提交后的解析，应描述图意、避免直接写出待测英文答案；逐题 `imageReview` 必须实际核对语义辨识、歧义、替代描述和答案泄露。客户端作答前展示图片及编号，全部加载、解码后才解锁；失败可以重试或跳过。词块组句不接收图片。

`approved` 表示作者完成本批内容自审并允许发布，不表示独立教研专家审定、与全部教材逐课等价或真人学习效果已证明。教材目录核对和正文核读分别记录：三年级交友主题有正文依据，家庭、动物、颜色、数字主题仅核对该册目录，语言任务同时依据已核读课标一级要求。四年级另核读人教 PEP 2013 年版、译林 2013 年第二版下册的指定正文页；公开社区存档的实际版本、文件哈希、页码和适用边界见[研究与验收记录](../../../docs/learning-program/primary4-content-2026-09-26.md)。九年级核读人教、外研两册的指定正文，审定年份与出版信息分开记录，见[九年级研究与验收](../../../docs/learning-program/junior3-content-2026-09-26.md)。旧版正文依据不等于当前新版逐课匹配，本次其余七档正文范围见全年级首轮覆盖记录。

每个年级现有的六至九个能力目标也不是九星课程矩阵。当前只有基础样板，不足以覆盖全年级能力或支持完整自动升级；九星仍按全局实得分累积。进阶引擎已支持覆盖门槛和迁移题，但正式进阶清单保持空，待完整课程、间隔复现和迁移挑战完成后再配置。

## 验证与发布

在 `Backend` 目录执行：

```sh
pnpm learning:validate
pnpm learning:publish <上一步输出的完整 catalogHash>
```

验证命令不连接数据库。发布命令先验证全部内容并核对哈希，再连接环境指定的数据库，在一个事务内发布整个目录；同版本内容不可改写，重复发布相同内容不增加版本。冲突导致全批回滚。已有尝试引用的单元版本保持冻结。

发布检查拒绝缺少来源、目标档位不符、重复题干、审核内容变更、判题反例不符、选项解释缺失、生成内容混入，以及未经资产验收的音频/图片。音频同时检查文件格式、长度、时长、峰值、哈希、题目原文和角色声音。自动检查不能替代逐题语义审核；更新答案或解析后必须重新阅读并更新对应审核记录，不能只批量重算哈希。

有视听资源时，发布器先将内容寻址文件上传到已配置的对象存储，检查远端长度/类型/校验和，再在同一数据库事务中登记资源元数据和单元版本。失败不会发布缺少资源的单元；已上传但尚未登记的内容寻址文件可由下一次发布复用。不要删除旧音频或图片，已开始的挑战仍可能引用它。

上线使用发布包内的同一目录：

```sh
node dist/cli/learning-catalog.js validate
node dist/cli/learning-catalog.js publish <已验证哈希>
```

需使用正常服务环境配置。发布后通过已鉴权的学习接口检查角色供给、真实抽题、独立题干、补答和唯一奖励；不得把测试分数写入真实用户账号。

听力下载通过 `/v1/learning/attempts/:id/audio/:questionId`：必须拥有该挑战，服务端从冻结版本定位资源，签名地址有效期五分钟。接口不返回听力原文或声音配置。客户端不向对象存储转发账号令牌，并检查资源身份、长度和 SHA-256；失败可重试或跳过补答。


图片下载通过 `/v1/learning/attempts/:id/images/:questionId/:assetId`，必须拥有挑战且该冻结题目引用了此图片。响应只含五分钟签名地址、格式、尺寸、长度及摘要，不返回审核和来源资料。客户端校验字节与 PNG 尺寸，再进行有界解码。任何发布入口均拒绝引用未登记图片；已登记资源与审核元数据不可改写。后台现有单元详情支持可视化图片复核、录音试听和素材来源说明；图片上传尚未提供，正式图片仍走上述目录审核发布流程。

## 题库耗尽后的补库

`generation.json` 是独立版本化蓝图，公开角色设定、允许目标、语言范围与实际核读来源参与蓝图哈希。当前开放三个主角色的小学三、四年级文字题；其它档位和私有角色保持等待，不借用已有角色、不降低难度，也不把私人聊天发送给模型。四年级依据已核读的 PEP 与译林旧版正文，明确钟点、日常活动、天气、许可、衣物、价格、季节和能力表达边界；每单元只选一至两个目标，主要目标至少三题。生成内容明确标记为 generated，不计入手编预设数量。

开启 `LEARNING_GENERATION_ENABLED=true` 后，Worker 每 30 秒检查任务；异步生成不阻塞普通作业和聊天计数。租约五分钟，最多三次尝试，失败按 5/25/125 分钟退避（第三次终止）。每个 UTC 日最多取得 `LEARNING_GENERATION_DAILY_JOBS` 次租约，默认 6；每次最多两次供应商请求，每次输出最多 16000 token、120 秒超时、不内部重试。服务端内容成本不调用用户聊天额度扣费路径。实际成功用量与模型记入运行记录，未返回用量的失败仍占预算；预算是请求上限，不是准确金额上限。供应商和模型由 `LEARNING_GENERATION_PROVIDER` / `LEARNING_GENERATION_MODEL` 明确配置，当前生产使用 DeepSeek `deepseek-flash` 高档推理，不隐式回退到其它模型。

作者输出先经严格合同、范围与近似重复检查；独立审题请求隐藏作者答案和解析，逐题重新解答并给出实质错误反例。程序核对两者是否符合确定性判题。语义上的新颖性和难度另由审题模型与初批逐题复核检查，字符串相似度不能证明语义完全不重复。作者解析没有在盲审中被验证，必须由发布前复核者检查。

初批只进入 `review` 候选池，不直接成为用户题目。使用下列运维命令检查并逐题复核；模型评分通过不能代替此步骤：

```sh
pnpm learning:generation list
pnpm learning:generation inspect <任务UUID>
pnpm learning:generation publish /安全路径/审核.json
pnpm learning:generation reject /安全路径/退回.json
```

审核文件字段为 `jobId`、`candidateHash`、`reviewer`、`notes`。填写实际复核者与逐题结论，包括题干独立性、答案变体、干扰项、提示、解析、角色、档位和新颖性。不得填虚构教师。哈希必须来自当前候选；蓝图变更后旧候选不能发布。发布事务重新去重、核对盲审与内容哈希，并原子写入公共版本和任务状态。多个用户可抽同一公开单元，同用户仍不重抽同一 ID；满条等待不扣机会。

`node dist/cli/learning-generation.js` 是发布包对应入口，参数相同；`run` 单次处理同样要求开关与预算。失败保留经结构验证的候选、独立审题结果和错误阶段；任务与运行表不保存用户身份或聊天。早期各批仍需逐题复核，自动语义审核质量、低水位预生成、内容质量反馈与撤回工作流继续开发，不能据此称为无人值守的完整课程生产系统。

## 实时听力（2026-10-23）

新版 App 的学习听力（含声音选项）和水平测试均在设备上使用随包 Supertonic 实时合成：第一遍 F1，第二遍 M5。每段只保留内存中的当前语句，不生成或下载两套题目录音；模型缺失、合成或播放失败明确报错，不换成系统语音，也不计为听完。完整听完第一遍即可作答，第二遍可选；同一题组的共享材料保留播放进度。

`GET /v1/learning/attempts/:id/speech/:questionId/:assetId` 只向挑战所有者提供该题实际引用的朗读脚本，响应禁止缓存。脚本不显示在题面上。高阶独立听力理解题的英文问题在材料后停顿三秒再读出；完整原创题组的单遍脚本由 `Scripts/export-listening-scripts.py` 从 SHA 绑定作者稿导出到 `listening-scripts.json`，包含原有示例和材料顺序，不把原音轨内的重复再叠加到两遍播放。

9 个单元的 50 道题已重新自审：高阶听力题面及选项改为英文，12 道原听写改成语义理解选择。新组卷不再选用听写及旧版中文高阶听力题，旧蓝图的听写槽位改选同目标的理解选择题。小学低年级图画任务保留适龄中文操作说明。旧录音、已发布单元版本、历史尝试和原有判分合同全部保留；已开始的挑战继续使用冻结题面，新内容用于新开的练习。后端发布不能代替 iOS 客户端更新。
