# 原创角色单元目录

这一目录保存正式手编内容，不保存教材原文、教材图片、供应商密钥或工程测试夹具。

当前为小学三年级的 **9 个单元、54 道独立题目**，Oliver、Ruby、Marcus 各 3 个。题型包括选择、听辨选择、词块组句、配对、短填空与听写；三个单元的第 2 版各包含一段听辨和一段听写，已有挑战保持原版本。

| 角色 | 单元 |
| --- | --- |
| Oliver | 旧书店的新朋友、为书架找颜色、书签装进小纸袋 |
| Ruby | 海边集合的第一声问候、送给海边朋友的明信片、野餐布上的小选择 |
| Marcus | 奶奶厨房里的照片墙、街角颜色速写、餐车前的礼貌小停留 |

## 文件与审核语义

- `catalog.json`：来源的实际核读范围、证据哈希、能力目标和唯一单元目录。
- `units/<id>.json`：版本化剧情、独立题干、答案、提示与解释。
- `reviews/<id>.json`：绑定内容哈希的逐题作者自审；每个选择项的适切性、正确/错误作答样例及歧义处理。
- `audio/<内容标识>.wav`：原创固定语音，24 kHz、单声道、16 位 PCM；元数据及审核范围登记在目录的 `audioAssets`。六段原文由作者编写，使用本地 Supertonic3 的 M5/F3/M3 固定声音生产。最终文件经统一音量、峰值检查，以及不提供提示词的 base.en / small.en 逐字识别。工具不支持音频输入，未声称完成人耳音色、口音与韵律审听。

`approved` 表示作者完成本批内容自审并允许发布，不表示独立教研专家审定、与全部教材逐课等价或真人学习效果已证明。教材目录核对和正文核读分别记录；目前交友主题有正文依据，家庭、动物、颜色、数字主题仅核对该册目录，语言任务同时依据已核读课标一级要求。外研、译林等版本和其他年级仍待补齐。

九个能力目标也不是九星课程矩阵。当前只有基础样板，不足以覆盖全年级能力或支持完整自动升级；九星仍按全局实得分累积，后续需增加间隔复现、迁移挑战与课程覆盖门槛。

## 验证与发布

在 `Backend` 目录执行：

```sh
pnpm learning:validate
pnpm learning:publish <上一步输出的完整 catalogHash>
```

验证命令不连接数据库。发布命令先验证全部内容并核对哈希，再连接环境指定的数据库，在一个事务内发布整个目录；同版本内容不可改写，重复发布相同内容不增加版本。冲突导致全批回滚。已有尝试引用的单元版本保持冻结。

发布检查拒绝缺少来源、目标档位不符、重复题干、审核内容变更、判题反例不符、选项解释缺失、生成内容混入，以及未经资产验收的音频/图片。音频同时检查文件格式、长度、时长、峰值、哈希、题目原文和角色声音。自动检查不能替代逐题语义审核；更新答案或解析后必须重新阅读并更新对应审核记录，不能只批量重算哈希。

有音频时，发布器先将内容寻址文件上传到已配置的对象存储，检查远端长度/类型/校验和，再在同一数据库事务中登记音频元数据和单元版本。失败不会发布缺少资源的单元；已上传但尚未登记的内容寻址文件可由下一次发布复用。不要删除旧音频，已开始的挑战仍可能引用它。

上线使用发布包内的同一目录：

```sh
node dist/cli/learning-catalog.js validate
node dist/cli/learning-catalog.js publish <已验证哈希>
```

需使用正常服务环境配置。发布后通过已鉴权的学习接口检查角色供给、真实抽题、独立题干、补答和唯一奖励；不得把测试分数写入真实用户账号。

听力下载通过 `/v1/learning/attempts/:id/audio/:questionId`：必须拥有该挑战，服务端从冻结版本定位资源，签名地址有效期五分钟。接口不返回听力原文或声音配置。客户端不向对象存储转发账号令牌，并检查资源身份、长度和 SHA-256；失败可重试或跳过补答。
