## 实际费用

- 首轮人物/故事生成，包含 3 次格式重试：**¥0.15526224**。
- 加上语义修订和修订中的重试，共 **26 次调用、¥0.3791448（$0.052659）**。
- 全部 26 次都有费用回执，没有把失败或未知账单按零元计算。
- 按相同范围线性放大至 200 人：**约 ¥7.58**。建议先预留 **¥20–30** 给全库查重和更多重写；这是规划余量，不是固定报价。
- 以用户估计余额 ¥90 计算，目前看充裕；没有核实账户实际余额。此处是 GLM/OpenRouter API 费用，不包括 Codex 用量、人工审阅、存储流量或以后新增内容。

本批输入 65,590 token，输出（含思考）85,641 token。单次响应中位数 32.311 秒，最长 148.331 秒。这些等待发生在预制作阶段，样本试读没有现场模型请求。批量脚本各轮起止可从 costs.json 查看；开发和编辑时间不等于 API 请求时间。规模扩大后可能有更多相似角色需要重写，不能只用请求数量保证总价。

## 检查结果与限制

- 10 个身份、10 张头像均不同；头像 SHA、已验收状态、年龄和创作性别匹配已核对。
- 40 条路径全部可达，结尾完整且文本不同；文字源合计约 **173 KiB**，200 人按此比例约 **3.4 MiB**（不含已有头像、语音及索引）。
- 人物在全样本做了 45 组两两比较。仅用旧兼容分类时曾有一次误报：两个具体职业落入 other，导致总分虚高。补上根据叙事编写的正确标签、经现有服务端协调后，最高分 51，没有触发重复阈值。
- 相似度分数不是唯一性的保证。已对完整分支做语义复核，修正错误字数、场景跳转、未经选择的动作、悬空互动、道具和人物设定不一致。内容仍待用户判断是否达到期望风格。
- 这 10 人作为伦敦样本；未进行与全部现有线上人物的比较。正式 200 人需要跨城市全库审查、场景覆盖和重复相遇故事设计。
- 试读页可以走所有选择分支；尚未验证实际 iPhone 15 秒外出动画、缓存下载和旧好友迁移。
