# 完整题组数据合同：研究草案1

2026-10-13。此合同定义基准库需要保留的内容与实施条件，尚非生产API或已通过独立验收的命题规格。依据已核读的国内课标、NEEA完整完形/语法题组、Cambridge阅读/听力、CEFR-J阅读/写作及郑州评分资料。来源结构见[观察登记](observed-structures.json)，评分例见[评分观察](observed-scoring-structures.json)。

## 对象与身份

卷轴是关卡的导航与进度容器，一个关卡引用一至多个完整题组。题组是共享材料、任务要求、相关问题及实施条件共同构成的最小验收单元。题目数量取决于任务：已观察到4题阅读、5空听力、6空完形、10空语法和15空完形，写作则是一份开放产出。它们不是固定数量的孤立题目拼盘。

| 对象 | 必需身份与版本 | 内容及关系 |
| --- | --- | --- |
| 关卡/卷轴 | `checkpointId`、`blueprintVersion`、`progressionPolicyVersion` | 顺序、适用范围、能力目标、题组引用、时间预算、通关条件；角色头像关联至要求，开场故事不作为必需字段 |
| 题组 | `groupId`、`groupVersion`、`contractVersion`、`scoringVersion` | 类型、原卷分区、材料引用、任务要求、题目顺序、支架、实施、评分和私有审核引用 |
| 材料 | `materialId`、`materialVersion`、原始及清洗后摘要 | 文本/图/表/音/视频；段落、句子、版面、空位、时间段和内容权限分别记录 |
| 作答单元 | `itemId`、`itemVersion`、源题号 | 选择、填空、短答、匹配、排序、写作、翻译、口头产出或互动；一个题组可混合相关任务 |
| 来源/改写家族 | `sourceId`、`acquisitionId`、`sourceVariant`、`familyId`、`adaptationId` | 原卷/手册/数据集版本，纸笔/数字、普通/学校版，页码和题号；跨题库及跨split同源关系 |
| 尝试 | `attemptId`、完整快照摘要、版本引用 | 作答、呈现顺序、媒体/支架实际暴露、状态、判分、计时、首次/重复、重放和纠错 |

材料、问题和来源家族分别拥有身份。只改变题号、选项顺序、人物名或解析，不自动产生新的未曝光材料。文章不因复制到多个年级目录变成新样本。对身份规则的例外须人工说明，不能仅靠题干字符串哈希去重。

## 核心字段与未知状态

所有字段区分`verified`、`provisional`、`unknown`、`not_applicable`，后两项必须给出原因。材料取得、配套关联、内容复核、用途核验、目标学生标定各有独立状态；没有答案的样卷可作结构观察，不能作自动评分锚题。未取得的音频不填虚构资产ID，未测用时不填观察值。

| 字段组 | 必需内容 | 核验要求 |
| --- | --- | --- |
| 适用范围 | 产品水平、年级/学期、学制/英语起点、地区、教材系列/ISBN/版次、备考方向；CEFR/CSE声明单列 | 区分来源声明、专家判定、实证对齐；无证据不互换标签 |
| 学习目标 | 主目标、次目标、能力维度、语言功能、认知任务、先修目标及来源 | 先修“教过”、当前“理解”、产出“掌握”分别记录 |
| 材料特征 | 主题、体裁、语域、词汇/POS/义项、语法与篇章、词数/句数、信息密度、图表和背景知识 | 记录算法、词数规则、清洗版本、未知词与置信区间；不能凭可读性数字判年级 |
| 指令 | 题组与题目要求、指令语言、角色头像、例题/示范、回答方式与限制 | 指令清楚、完整；翻译或改写保留原始来源和变更，重新复核难度 |
| 题面与选择 | 私有原稿引用、公开呈现引用、稳定选项ID、干扰项理由、否定/多选条件 | 选项显示序与答案身份分开；禁用OCR字母位置推断答案 |
| 答案与证据 | 私有键、合法替代、适用组合、材料证据跨度/时间点、解释、反例 | 原始答案、人工核验、模型建议分开；不得生成“原卷答案”补缺 |
| 配套与权利 | 每个原文/图/录音/评分例的来源、许可、署名、允许用途、期限和外部传输条件 | 主文件许可不自动覆盖第三方组件；公共可见不自动满足商用 |
| 审核与标定 | 作者、独立复核、分歧、裁决、金标准资格、目标人群、作答统计、曝光和偏差 | Agent自审不是专家或学生验证；未决分歧阻止升格为金标准 |

题面长文本按结构块存储，保留原文段落与空位，不为塞入现有1200字符字段而删句或截断。媒体素材需明确是否解题必需；纯装饰图、可访问替代和测量模式分别处理。

## 空位、材料和关联约束

空位是显式结构节点`slotId`，不是用数字或括号正则从原文猜出的子题。每个空位对应作答单元及评分引用；显示号和源题号不是身份。空位周围文本保持完整，可定位到原文页/段落/字符范围；字符范围注明Unicode口径和清洗版本。源PDF跨页标题、双栏、旋转、上下标和表格须人工或逐任务文件校正。

多篇材料分别编号；任务引用所需材料，不能把一整卷当成每题共同文章。匹配题保留可否重复使用右项、余项与多对一规则。词库完形保留词形是否可变、是否重复、每空候选还是共享词库。开放完形不强制提供词块支架，也不能套用现有词块题“token不得重复”的限制。

实际人教七下Unit1 GrammarFocus3b要求六空补全及动物名词下划线；3c先变十个名词的复数再用于自主表达。这些是复合动作，不能只导入空位。当前0.2尚无专门文本标注响应，拟议span对象在已通过的原创基线上被拒绝，见[来源驱动的表达缺口](observed-representation-gaps.json)。后续标注合同须记录材料/块/版本及坐标口径，明确标注基于填空前还是填空后的文本，保留各动作、未知键及评分关系。仅在指令字符串写“加下划线”不表示已经能保存和复审标注作答。

听力记录整段资产与独立片段，二者有关联但不混同。片段含起止时间、说话人、脚本范围、信号/静音、语速及计算方法、口音、题图、重放次数、预读和检查时段。容器时长、可播放、脚本对应、全程语义核听各需证据。口语互动还要记录交互对象、轮次、追问/重复/改述条件、等待时间、允许帮助与停止规则。

## 评分合同

评分方式按题型与版本指定，不能统一用一个“标准答案字符串”或二元对错。

- 客观选择：合法答案集合、单选/多选、稳定选项ID、遗漏/多选规则和各项分值。
- 文本短答：合法形式、条件替代、单复数、英美变体、可选词、数字/单位/日期/时间格式、大小写、空白与标点归一化。容忍拼写须有逐题依据，禁止全局模糊字符串匹配。
- 多空：逐空成绩与全组成绩，互相制约的答案按完整合法组合核验，不能把不同合法组合拼成未获认可的组合；空位缺答和格式非法分开。
- 转换/分段：评分片段、每片段分值及条件、关键词保留、原句语义、词数规则；先核明原说明，不能用总分除以题数自行发明部分得分。
- 写作/翻译/口语：评分维度、档级描述、整体定档规则、分数区间、零分/封顶/扣分条件、评分例的已评等级、允许支架、人工裁决及评分者一致性。分档例可以带错误，不是唯一满分答案。

每个评分结果保留`awardedSourceMarks`、`possibleSourceMarks`、状态/理由、评分版本与审核状态；未知分值保持未知。`productReward`和`promotionEvidence`由另一版本化政策计算。考试原始分、CEFR等级、经验值、星级和精熟证据不得直接等同。

[已评分作答合同0.1](../Performances/Contract.md)独立保留来源只公布任务band、未公布各维度数字的真实作答。现有0.1/0.2的维度分档示例不自动升级；禁止为了塞入其字段而将任务总分复制成各维度分数。图表依赖、手写图像、缺题干和未知历史rubric应用版本分别保留。

[研究合同0.2](../Studies/2026-10-13-answer-coverage-response-scope.md)补充答案覆盖范围与作答范围。参考例或覆盖未知的文本键不得用于排他字符串判错；完整句键与局部空位分别保存，转换须保留原键、实际作答形式和抽取依据。旧版0.1继续读取，不自动升级或补造范围信息。

源实体考试的用笔、字迹、答题卡位置规则保留在来源记录。数字任务明确适用/不适用及改编理由，不能将物理规则复制成用户错误。排位/诊断与带提示练习分别计证据；提示后答对和首答正确不能合并为同一种掌握证明。

## 解析、提示与实际暴露

题组规定提交边界、能否返回改答、何时显示答案/脚本/译文、哪些相关问题仍待作答。共享文章的题A解析可能泄露题B答案，首答测量默认整组提交后反馈；练习可采用逐题反馈，但必须记录暴露，后续相关题不得再计未辅助诊断证据。提示与解析都可能泄漏答案，公开投影要按阶段白名单生成，不能只删除名为`answer`的字段。

角色头像放在题组要求上方或旁边，所属角色通过真实角色资料引用，不将录音说话人冒充角色。指令正文应直接说明作答要求。可选装饰内容不承担解题线索，也不插入必须跳过的角色开场故事。

## 时间、恢复与历史

分别记录准备/读题、阅读、媒体播放、作答、修改、提交等待、评分等待和反馈回顾时间。前台停留与有效学习不同；离开、后台、长空闲、暂停、崩溃与断网单列。首轮、提示后、重做和补答分别统计。录音长度不包含全部作答耗时，预估分钟不等于观测时长。

关卡预算包括相关题组共享阅读成本，不把文章阅读重复加在每题上。每日20—30分钟预算及1000字符触发、升星/升档节奏需以实际聊天速率、可得题量、作答和回顾分布验证，未取得数据不写成立时间区间。

活动尝试冻结材料、题目、评分、曝光、蓝图及奖励版本。后台修订/下架不覆盖历史，完成与奖励写入可重试且幂等；更正成绩保留原结果、理由和差额记录。升级合同需协商客户端能力，包括开始、恢复、补答和多设备；旧端无法表达的新题型不得静默拆题或丢字段。

## 现有实现差距与迁移边界

已核读`Backend/src/modules/learning/content.ts`、`grading.ts`及公共题库文档。当前单元最多18题、cloze最多6空/12词块；开场beats最少2段且必须有开场；长文本1200字符；评分结果主状态为correct/incorrect/skipped。已有多答案、合法完整组合、私有答案投影和版本快照可延续，仍需新增共享材料、逐空开放作答、分段/产出评分与组内暴露合同。现有1题1点、60点1星与9星1档属产品策略，不是语言质量标准。

本批不改生产代码、已发挑战或历史数据。后续实现应独立设计新合同、服务/仓储及客户端兼容，隔离验证后迁移，保留旧快照读取能力；不为容纳完整题组破坏既有数据。`Feature`间依赖、私有答案隔离和媒体服务端权限沿用仓库边界。
