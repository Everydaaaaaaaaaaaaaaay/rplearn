# 初一十空四选：游戏盒里的清单

阅读下面完整短文，从每题四个选项中为第1—10空各选最合适的一项。

Our class has five board games (棋盘游戏). We can use them on rainy lunch breaks. There is a small card in each box. It (1) ____ the number of pieces in that game.

Before playing, we put all the pieces on a table and (2) ____ them. If a piece is missing, we tell our teacher. We do not take a piece from (3) ____ game, because the second game will then be missing a piece too.

Some games are new to us. We read the (4) ____ together before we begin. If we still have a question, we can ask a student who knows the game. We play for fun, so the winner does not get a (5) ____.

When the lunch bell rings, we stop and put everything (6) ____ in its own box. The piece card helps us check again. The boxes go on a (7) ____ shelf, where rain cannot reach them through the open window.

Every Friday, a different pair of students checks the shelf. They choose a different game for the front of the shelf, so classmates can (8) ____ notice it. We take (9) ____ doing this job. It takes only a few minutes, but it keeps the games ready for the (10) ____ players.

### 答案与逐项依据

1. A。A：清单卡列明棋子数量；B：卡不会使数量遗失，作用是列明；C：卡不烹饪棋子数量；D：数字清单不是破坏游戏的物体

2. B。A：不是重涂棋子，后文是检查缺件；B：与卡上件数核对，要数棋子；C：不把游戏零件扔掉，目的为检查；D：要全放桌上看清，不能藏起

3. B。A：both game缺复数形式，且班里共五盒，不是限定一对游戏；B：不从另一个游戏拿零件，以免第二盒也缺件；C：each指五盒中的每一盒，不等于另一个游戏；D：五盒游戏，每盒都取会影响所有五盒，不是仅另一个游戏

4. A。A：不熟悉游戏先一起读规则，后才能玩；B：游戏盒不是餐馆菜单；C：未提私人信件，玩法疑问需游戏规则；D：同学日记不提供本盒玩法

5. A。A：为乐趣玩，胜者无奖品；B：学生本有姓名，游戏未涉及授名；C：游戏仍需轮流，获胜不等于没有轮次；D：玩游戏围桌坐，非胜者不能坐下

6. C。A：put out不是把东西放回自己的盒子；B：put off一般推迟，与零件回盒不合；C：put everything back放回各自盒子；D：put about用于传播消息，不能表示把零件放回盒里

7. C。A：雨进不来不是潮湿架子的理由；B：未提书架损坏，无法由防雨推出broken；C：雨进不来，确保干燥；D：书架要放游戏盒，不能是空架子

8. D。A：不是与饥饿有关的摆放位置；B：摆放方便不使同学生气地注意；C：没因换游戏而悲伤的情节；D：摆前排使同学容易注意

9. B。A：工作安全简单，不是轮流冒险的意思；B：take turns轮流做值日；C：没有乘车去做此项任务；D：没有拍照安排，take photos doing不表示轮换

10. D。A：不是为缺席者特设，准备给后来要玩的人；B：此后还有玩家，不是最后一批已离开的人；C：没有因疲劳才选择提供游戏的规则；D：收好给下一批玩家

### 全组回填

Our class has five board games (棋盘游戏). We can use them on rainy lunch breaks. There is a small card in each box. It shows the number of pieces in that game.

Before playing, we put all the pieces on a table and count them. If a piece is missing, we tell our teacher. We do not take a piece from another game, because the second game will then be missing a piece too.

Some games are new to us. We read the rules together before we begin. If we still have a question, we can ask a student who knows the game. We play for fun, so the winner does not get a prize.

When the lunch bell rings, we stop and put everything back in its own box. The piece card helps us check again. The boxes go on a dry shelf, where rain cannot reach them through the open window.

Every Friday, a different pair of students checks the shelf. They choose a different game for the front of the shelf, so classmates can easily notice it. We take turns doing this job. It takes only a few minutes, but it keeps the games ready for the next players.
