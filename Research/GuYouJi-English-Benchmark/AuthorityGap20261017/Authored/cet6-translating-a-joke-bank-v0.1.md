# 六级：一句双关的两种译法

## 学生题面

阅读完整短文，从A—O中为全部十空各选一个最佳词项，填写字母。词形不变；每项最多使用一次，五项不用。材料为虚构情境。

In a fictional seminar, translator Mei presents two versions of a joke from an imaginary novel. Her purpose is not (1) ____ to decide which sounds more amusing. She wants to expose the different losses hidden by the simple instruction to “translate faithfully”.

The first version preserves every event but takes twice as long to read aloud. The second achieves considerable (2) ____ by removing a repeated phrase. Unfortunately, that phrase is what makes the final remark funny. Mei asks whether a translator should always try to (3) ____ a verbal pattern even when the result sounds awkward in the new language. She offers no universal answer, since the pattern may serve a different purpose elsewhere.

Another problem is (4) ____. A character's description can refer either to a broken clock or to an unreliable friend, and later scenes exploit both readings. One participant wants the translation to state (5) ____ which meaning is intended. Mei objects: the original has deliberately withheld that decision. Adding an explanation would settle a question the novelist left open.

Some loss appears (6) ____ to Mei in this particular example: the group has found no expression that retains both meanings and the same rhythm. Yet this does not license arbitrary changes. Moving the clock's failure a week earlier would (7) ____ the story's chronology, creating a sequence different from the one narrated.

The translator must therefore (8) ____ demands that pull in different directions; fidelity to events and sensitivity to voice both still have to be met. Mei marks her preferred wording as (9) ____, ready to replace it if a better solution emerges. The (10) ____ question beneath these disagreements is what, precisely, each version asks its readers to notice.

共享词库：A. ambiguity · B. coherent · C. compression · D. concede · E. distort · F. eliminate · G. explicitly · H. inevitable · I. merely · J. preserve · K. provisional · L. reconcile · M. reluctant · N. simultaneous · O. underlying

## 作者核对

### 1：I

not merely...后接更深目的，表示不只是判好不好笑。explicitly只描述明确程度，不承担这个从简单裁决转向揭示损失的递进；其余项非此处修饰不定式的副词。

### 2：C

twice as long与removing phrase说明篇幅compression压缩。ambiguity歧义不等缩短；其他候选不提供此after considerable的篇幅压缩名词。

### 3：J

尽管awkward是否仍保留verbal pattern，preserve对应。eliminate去掉与still保留重复所产笑点的疑问方向相反；distort扭曲、concede让步、reconcile调和不表示保持该模式不变；其余项非此不定式动作。

### 4：A

either clock or friend且both readings说明ambiguity双重理解。compression是压缩长度而非两个指称；其他项不提供这个双义现象名词。

### 5：G

state explicitly which meaning与原作deliberately withheld相反，是明确说出所指。merely只表范围限制，不能概括要求消除歧义的明确程度；其他项非此副词。

### 6：H

该判断归属于Mei：按小组目前找不到双义且同节奏表达的经验，她认为本例损失inevitable不可避免；不是作者证明所有可能译法都已穷尽。coherent连贯、provisional暂定、reluctant不情愿、simultaneous同时、underlying潜在均不概括她对难以全保留的必然损失判断。

### 7：E

改动日期会distort chronology，形成不同时间线。eliminate chronology是去除时间顺序而非换成另一顺序；preserve保留与different sequence相反；reconcile调和未有两时间线待并存，concede让步不表示变动时间；其余项非此动作。

### 8：L

both demands still met，须reconcile调和不同要求。eliminate去除、distort扭曲都放弃忠实目标；preserve仅各自保留不表达解决相互拉扯，concede demands不是兼顾；其余项非此动词。

### 9：K

ready to replace if better出现说明provisional暂定。coherent只讲连贯，无法表达保留修订的状态；inevitable不可避免、reluctant不愿、simultaneous同时、underlying潜在都不概括暂择待改。

### 10：O

beneath these disagreements释义underlying基础/深层问题。coherent连贯、provisional暂定、inevitable不可避免、simultaneous同时、reluctant不情愿均不表各表面分歧共同指向的底层；其余项非此前置形容词。

完整向量I/C/J/A/G/H/E/L/K/O；十个不同词库项，未用五项为B coherent/D concede/F eliminate/M reluctant/N simultaneous。逐槽位可合语法不自动等整组最佳：必须同时核对上下文和原印每项最多一次规则。词库仅十五项，控件逐空重复不当150个独立词项。正文/题干/候选/输出负荷分别记录。
