The chart shows the results. The number below each bar matches a problem number in the list. The height of a bar shows how many students chose that problem. 1. Which problem did the largest number of students choose?
   A. Planning revision time.
   B. Understanding new words.
   C. Reading long instructions.

2. How many students chose concentrating in a noisy room?
   A. 36.
   B. 28.
   C. 18.

3. Which statement must be true?
   A. The number of problem choices was greater than 50.
   B. Every student chose exactly the same number of problems.
   C. No student chose more than one problem.

<!-- responses:end -->

## 作者核对

### 1：B

2号56%为28人最大；10号48%=24人，4号40%=20人均较少。

### 2：C

6号36%×50=18；36为百分数，28是2号56%人数。

### 3：A

总160选择>50，A；B160/50=3.2非整数，不能人人相同整数选择数；C若至多一人一选至多50，违160。
