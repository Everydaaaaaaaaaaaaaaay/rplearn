# 高级：零件目录五位顾问

## 学生题面

阅读同一专题文章中五位虚构顾问的完整意见，为十条陈述分别选择对应顾问A—E。字母可以重复使用；按建议的对象、条件与责任范围判断。

### A catalogue that can be used

Five fictional consultants discuss a single professional project.

A — Mina, technical illustrator

A beautifully enlarged component can be surprisingly hard to recognise when the reader has no idea where it belongs. I pair the close view with a context view that shows its position among neighbouring parts. More detail is not always more help; the purpose of the second image is orientation, not decoration. Be equally careful about apparent size. Unless a drawing is explicitly identified as being to scale, readers should not have to infer a component's dimensions from how much page space it occupies. Put the relevant measurements in the entry. A small part may deserve the largest illustration because its identifying features would otherwise be invisible. Visual prominence and physical size answer different questions.

B — Dev, repair technician

Before recommending a replacement, establish which version of the machine the customer actually owns. A familiar model name may cover several serial-number ranges with incompatible components. The catalogue should state those ranges where the replacement is listed, rather than leaving them in a general introductory note. When a replacement fails, record the reason instead of merely recording another returned item. Was the supplied part incorrect, was the machine version misidentified, or was a different fault responsible? Those are different failures of the process. An undifferentiated pile of returns makes it harder to improve either the catalogue or the service conversation. The evidence needed for a useful correction often disappears when the box is simply put back on the shelf.

C — Lena, warehouse manager

Do not give a retired part number to a new component. Old catalogues continue to circulate, and a number that now means something else can turn an apparently precise order into an unpredictable one. Retain the old number as a historical reference, clearly marked as no longer current. I am less strict about the words customers use to search. People develop familiar names for components, and those names can be useful routes into the catalogue even when they are unsuitable as the official entry heading. Add them to the search index and direct them to the agreed entry. Protect the identity of the part without insisting that every customer first learn the vocabulary of the warehouse.

D — Arun, translation adviser

An isolated label is a poor translation brief. Send the whole page, including the illustration and surrounding instructions, so that a phrase such as this section has a visible referent. The same short word can denote different things in different assemblies. Context does not make expertise unnecessary, but it prevents an avoidable kind of guesswork. Within the published catalogue, use one agreed technical term for a component across the relevant entries. Readers should not have to decide whether two elegant alternatives name two different parts. That does not prevent a search index from accepting informal expressions; it distinguishes the stable language of the entry from the various routes by which people may find it.

E — Iris, documentation manager

A corrected description does not necessarily announce a redesigned component. Keep the history of the object separate from the history of its documentation, or a punctuation correction can appear to change which item a customer should order. Both histories need dates, but they are not interchangeable versions of one story. Remember, too, the people using printed copies. Updating the online master will not repair the information on a page already in somebody's workshop. Issue a clearly dated correction sheet and make it easy to find which entries it replaces. A quiet change in a current file may satisfy the production team while leaving the original error fully operational for the readers who most need the correction.

## 作者核对

### 1：A

A close view配context view定位相邻部件；D也要整页图给译者但不要求目录并排两视图，B机型/C编号/E版本均非放大加位置图。

### 2：D

D whole page含图及周围指令，为this section提供visible referent。A图像定位给读者非短语翻译语境，B序号/C搜索/E更正也不解释代指。

### 3：B

B serial-number ranges写在replacement列项处，不留总导言。A尺寸列项/C索引也谈位置但不是机型兼容范围，D术语/E改版不作此建议。

### 4：E

E明确object history与documentation history分开，标点更正不等重新设计。B区分故障原因非文档与实物改动，A尺寸/C编号/D用词均未作这两个版本历史区分。

### 5：C

C不把retired part number给新件，旧目录仍流通会误配订单。E旧印本更正虽近但无重分配标识问题；A图/B兼容/D术语也不谈退役号重用。

### 6：B

B记录incorrect part/version misidentified/different fault的原因而非another returned item。E更正版本无退货分类，A图/C搜索/D翻译也非售后失败原因。

### 7：A

A除明确to scale外不从占页大小推尺寸，entry列measurement。B兼容号码/C旧标识/D指代/E文档历史均未区分图面显著性和实物大小。

### 8：C

C同时主张客户熟名加入索引与退役零件号不得重派，两条件共同唯一。D只说可接受非正式搜索词、不讨论退役号，不能仅凭一半命题选D；A图/B兼容及退货/E更正历史都不同时具备两条。

### 9：D

D要求one agreed technical term across entries，不能因优美变词让读者误认两件。C保护part identity但接受客户搜索俗名，不提出跨条目统一译名规则；A图/B兼容/E版本无该用词规定。

### 10：E

E issued clearly dated correction sheet给printed copies，online master改动不能修旧页。C虽提旧目录继续流通但建议不重用编号而非更正单；A/B/D无此纸本补订途径。
