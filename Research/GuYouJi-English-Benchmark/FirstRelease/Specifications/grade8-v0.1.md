# 初二阅读与语言运用规格0.1

来源为[题组观察](../source-group-observations.json)的g8.2025.matchingA、readingB/C、cloze。四组来自西城一卷，通州卷待作为第二来源；本版是生成可执行规格，尚不是全初二分布。

| 项目 | 可执行要求 | 证据身份 |
| --- | --- | --- |
| 取材 | 普通初二；可有校园/家庭关系、活动介绍和较简单的研究过程说明；不要求逐教材单元对齐 | 已核读西城四组＋用户年级口径 |
| 阅读 | 默认一个完整共享材料、4题四选；匹配任务另保留4卡/3人物/1多余项及每个人的全部条件 | readingB/C与matchingA结构观察，默认不是全国统一题数 |
| 阅读考点 | 过程、前后变化、因果/目的、人物选择、整体意义；说明文须区分原型与最终版本、比较条件与观测结果 | readingB/C；各组不用机械固定题型百分比 |
| 语言输入 | 叙事可有过去时、完成时、对话、心理活动和中文释义；说明可有比较、因果和带限定的结论 | cloze/readingB/C观察；输入出现某形式不等于空位须测它 |
| 完形 | 默认10空四选；完整事件转折、人物关系和结尾，不只按邻词搭配挖空；混合词义、搭配、心理与跨句线索 | cloze实际10空；缺失故事结尾可能破坏部分空位可解性 |
| 语法填空 | 不把单项选择自动改名为语法填空；当前所选卷为句子级四选单项填空，开放式篇章语法填空的年级锚组仍需补 | PDF3所见13—22；题型差异保留，本版不虚构统一10空语法模式 |
| 干扰项 | 按阶段混淆、动作/人物误归、局部代整体、比较对象或结论外推设计；每项需逐题排除理由 | 来源机制＋暂定工程审核规则 |
| 结论与事实 | 文内的测试结果不能自动升级真实科学发现；新编研究情境明确虚构，结论限定在材料数据 | readingC的数学任务/呼吸抱枕；工程规则 |
| 正确性 | 单选有唯一最佳响应；匹配满足全部条件；不靠未提供的常识或外部知识补答案 | 工程硬规则，源键另保留错印/分歧可能 |

本批尚未完成扫描正文的统一词数转录，不填写“初二真实长度区间”。原创阅读暂以约250词、4题四选为工程默认，依据所选说明/叙事任务的结构负荷选择，不冒充源统计。个别词可释义，但不能提前解释正在测的词义。无长句比例、CEFR细档或学生分钟数阈值。

生成同时参照本规格与完整配套锚题。头像可以放在答题要求旁，题面不添加角色开场故事。作者需先按文内证据解题，再核查每个干扰项与结论范围；独立专家、学生难度/用时、商用准入和第二卷对照仍待完成。
