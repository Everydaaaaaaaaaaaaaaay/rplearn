# 初一阅读与语言运用规格0.1（首轮，待扩样）

依据[选定初一题组](../source-group-observations.json)中的g7.2021.cloze、readingB、vocabularyA/B。当前只有一份新增配套卷的四组，另有常熟既有来源待对照；这是可执行首轮规格，不称年级总体分布或最终稳定标准。

| 项目 | 首轮要求 | 身份与依据 |
| --- | --- | --- |
| 定位 | 普通初一年级；学校、日常生活、兴趣、社区等可理解情境；教材/学期只作元数据 | 用户接受的取材口径；源阅读为校园活动、完形为日常筹款 |
| 阅读结构 | 保留完整共享文章和全部问题；当前三选一、5题；可选分人物叙述 | g7.2021.readingB实际结构；不是所有初一卷固定三选一 |
| 语言负荷 | 常用词和清楚人物/时间关系为主；关键生词可加中文释义，考查词义的词不提前释义 | 源给charm/microphone等释义；calm按上下文考查 |
| 输入与考点 | 可以有语境可理解的从句、完成时等输入；不能由输入出现某形式就要求它成为必测考点 | 源完形有has raised、what he thought，实际空位主要考意义/搭配/逻辑 |
| 阅读能力 | 显式目的、人物/范围细节、短跨度推断、上下文词义及整体标题；每题须有可定位依据 | 源五题分别覆盖这些功能；不规定五题比例为全卷标准 |
| 完形 | 当前10空、三选一，词与词组均可；语境、搭配、指代和跨句线索共同决定答案 | g7.2021.cloze；不要只按词性相同认定选项可用 |
| 词语运用 | 明确选择原词/短语还是适当形式；保留词库、一次性复用和允许多词响应 | 源A/B两种任务；asks for/to grow表明空位不是统一单词长度 |
| 问题范围 | 学校与班级、不同人物、先后阶段不能混淆；未提及不改写为明确否定 | 源readingB的school/class/三人物关系；生成审核要求 |
| 干扰项 | 使用范围错误、人物误归、原因/结果或时点混淆、局部概括代替整体等机制；逐项写出排除理由 | 源EXCEPT及标题题；以下为首版工程审核规则 |
| 正确性 | 文章明确支持唯一最佳选项；如有两个合理选项，先改题再提交；答案不能依赖常识补全 | 暂定工程硬规则，保证生成题可解 |

长度目前只有两个具体观察：gapped完形191 token、含人物姓名年龄的阅读220 token，计数口径见私有审计/观察表。它们用于选择相近锚题，不把191—220当全初一准入区间。首轮生成阅读暂以约200词、5题三选一作为工程默认；超出默认时需要给出匹配来源和理由，后续扩样后更新。该默认没有学生用时/难度标定。

生成时同时输入本规格与相匹配的完整锚题，原创材料和问题。作者审核逐题记录依据和干扰项，不把源解析中的不充分理由直接复制为标准。角色头像可留给产品展示；题面不添加角色开场故事。

后续必做：常熟等第二来源对照、更多体裁/正常难度样本、词汇义项和语言特征分布、实际解题分歧及生成修正。CEFR、产品细档、独立专家、学生用时和商用材料准入均未在本版成立。
