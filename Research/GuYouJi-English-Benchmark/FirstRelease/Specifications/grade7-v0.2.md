# 初一规格0.2：文字与图文任务并列

本版修订[0.1](grade7-v0.1.md)的生成默认，原图书馆阅读保留依0.1的候选和摘要。依据[题组观察](../source-group-observations.json)中新东方2021下期四组与常熟2019上期三组，两卷家族；年份/学期差异按用户接受口径保留，不声称当前全国学生已标定。

| 任务 | 首版允许模式 | 依据与执行要求 |
| --- | --- | --- |
| 阅读 | 5题三选纯文字/分人物叙述；3题四选文字＋日历；3题四选文字＋人物图片 | g7.2021.readingB、g7.2019.readingA/B；数量和选项不统一硬编码，图文模式须提供完整图与所有图选项 |
| 阅读功能 | 目的/范围细节/局部推断/语境词义/题旨；日期规则与日历联合、代词所指、人物空间/属性关系 | 已核选定组；不同模式按信息负荷选功能，不每组机械凑相同比例 |
| 完形 | 完整单篇10空，三选或四选 | g7.2021.cloze与g7.2019.cloze；选项数不直接等同难度，保留前后事件/心理、搭配、指代和转折线索 |
| 词语运用 | 当前10项词库、一次性使用；原词/短语模式与给词变形模式分别提供说明 | g7.2021.vocabularyA/B任选；多词短语/不定式等响应合法，不拼成20空必做 |
| 语言负荷 | 常用情境、清楚角色/时间关系；可有语境支持的从句、完成时等输入，考点需另有空位约束 | 两源实际输入，不能用“初一不能见该形式”拒绝可理解语料，也不能强制测该形式 |
| 生成正确性 | 人物命名一致、动作/动机完整、单选唯一最佳、开放空合法集合明列；细节/指代不得靠未给常识补全 | 暂定工程硬规则；来源异常不是规范范句 |

常熟完形有Eric/Tom/Jack及MrDavis/MrGreen混用，原记录保留，不把它们改成一致后冒充原卷。阅读B中MrPhelps always us缺动词，同样不能模仿为规范输入。日历明确JUNE2019，问this year需绑定此语境，不能按程序运行年份重算或漏掉年份。

初一也可有图文关系与跨句推断，不只做简单词表选择。新生成图片题若图缺失就不完整；暂先扩文本完形和词库任务，图文原型另保留具体缺口。日历/照片来源的社会研究和性别泛化只作语料主张，未验证事实，不复制为教育规范。

原初一阅读199 token/三选5题仍匹配第一模式，不因另一卷四选3题而判不符。约200词默认只是原型起点，两卷尚未统计总体词汇/长句分布、无CEFR细档/学生分钟阈值。后续生成同时输入本版和匹配完整锚组，逐题作者解答；独立、学生和商用准入仍待完成。
