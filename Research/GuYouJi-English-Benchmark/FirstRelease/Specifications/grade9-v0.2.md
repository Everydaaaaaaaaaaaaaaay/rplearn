# 初三阅读、完形与短文填空规格0.2

继承[0.1](grade9-v0.1.md)，加入[第二年份官方卷对照](../Comparisons/grade9-source-comparison-v0.1.md)。两份均为福建省卷，不据此声称全国分布。现有原创候选继续绑定创作时的0.1摘要，不能回写成按0.2创作。

| 维度 | 可执行要求 | 来源观察与工程边界 |
| --- | --- | --- |
| 定位 | 普通初三，按年级取材；教材/学期作元数据，接受正常差异 | 用户口径；学生能力、产品细档与CEFR未标定 |
| 阅读模式 | 单篇说明文5题四选；也可为五行编号表格＋5题四选。先选模式及完整锚组 | g9.2026.readingC、g9.2025.readingA；表格标题、行号、条件不能删 |
| 阅读操作 | 局部细节、条件/方法、指代、段落焦点、整篇标题；表格增加跨行分类、建议与出版领域判断 | 各组实际考点，非每次全测或固定比例 |
| 证据范围 | 标题概括整篇；段落题只按指定段；跨行题须满足所有选中行。必要下划线/行号明确显示 | 源2026第58及2025第49；不借文章外环保常识替代行内证据 |
| 完形 | 完整叙事10空三选，可混合词义、短语、角色、先后、让步、原因/结果和跨句线索 | 两年均10空三选；医疗服务与成长行动情境不是唯一主题 |
| 短文填空 | 单篇10空；根据语境或给词填一个词，所有空均受一词限制；全文回填检查 | 两年题面要求一致；不给词和给词都不能擅改成高中多词模式 |
| 形式覆盖 | 时态、介词、冠词、并列、副词、复数、一致、最高级、动名词、代词；另可考派生名词、物主限定词、共享被动中的分词 | 两年实际目标集合，非强制每卷组合；reported继承前面的are，不需要再填are |
| 输入负荷 | 允许时间/因果/让步/关系从句、被动、分词和复杂名词短语；语境/释义支持必要词汇 | 已见输入，不由形式出现推为对应空位必考；统一长度与长句比例未知 |
| 衔接任务 | 若做五空五选，保留全文、标题层次和全部选项；说明新题是否可复用 | g9.2025.insertionE；源未明确一次性，不能从键恰各一次倒推规则。本版核心原创仍为阅读/完形/语言填空 |
| 键与编辑质量 | 源参考键单独保存；新题要逐项排除/回填，并主动试合法替代。编辑风险句只参考任务结构 | 2025语法Modern technology…have存在主谓风险；原样保留，不当一致性范句。开放键不是穷尽证明 |
| 展示 | 指令旁可放头像；不加独立角色故事；标题题不提前显示直接泄露答案的标题 | 产品要求与工程规则 |

原创篇幅仍是工程选择，实际词数逐候选保存；源文未完成统一校正计数，不声称约300词是实测年级区间。生成使用本规格＋匹配完整锚组，保留新材料中每题证据与干扰项/替代检查。第二年份比较已成立；更多地区/体裁负荷、独立教师、学生用时难度和商用许可继续未知。
