# 高三阅读、完形与语法填空规格0.2

继承[0.1](grade12-v0.1.md)，增加[鞍山第二卷对照](../Comparisons/grade12-source-comparison-v0.1.md)。江淮2024届首联考实际2023年8月；鞍山正文2025—2026高三第一次质量监测。两卷阶段较早，不代表整个高三后期冲刺难度。

| 模式/维度 | 可执行要求 | 证据及边界 |
| --- | --- | --- |
| 阅读结构 | 四选共享多简介3题、长篇报道/说明/论证4题；题量依实际承载信息与完整锚模式选择 | 第一卷A/B及鞍山A/B/C/D；不强制每篇5题 |
| 阅读功能 | 需求/条件匹配、跨简介共性、目标读者、动机/品质、例证功能、词义、指代、主因、论证方式与整体标题 | 鞍山新增经济指标文化论证及心理实验；部分源题有键风险，不能自动准入 |
| 概念/数值 | 定义明确对象/分母/条件；整体结论保留限定；例证证明的是一般现象还是指定对象必须与题干一致 | 鞍山C混写总支出/收入分母、B24泛例与特定流行混称，列反例 |
| 方法/视角 | 观察/偏好实验/理论机制/应用建议分开；现有文本观点与外部事实分开，读者不能靠百科补答案 | 已见不同篇章功能；“多见面必被喜欢”等普遍外推不作生成规范 |
| 标题与词义 | 标题覆盖全文核心机制；词义题选项必须有可成立的语境同义，不能强选“最接近”弥补缺项 | 鞍山D33contempt与键ignorance不符、D35仅平均脸遗漏曝光机制；保留源键、排除正向示范 |
| 完形 | 单篇15空四选，完整行动/长期经历；动作施受、时间推进、约束、词组/习语与局部词义混合 | 两卷实际一致；人物生平信息只作文内证据 |
| 语法 | 单篇10空；无给词1词、给词形式可多词，完整回填；新题所有合法变体明列 | 两卷实际结构；鞍山65 to have come为完成不定式三词 |
| 形式集合 | 冠词、分词、时态/一致、副词、地点关系、介词、不定式/被动/派生；再有结果分词、动名词主语、完成不定式 | 实际目标集合而非每组固定比例；源62was/is inspired保留原允许分支 |
| 输入 | 多主题/抽象词汇、从句、分词、名词化、同位解释/引语；中文释义保留且不能泄答案 | 源结构观察，学生词汇比例、长句比例与分钟未知 |
| 衔接扩展 | 五空七选保留全部选项/标题/正文，两个多余项；新题复用规则明确 | 鞍山文件7，非当前核心原创已覆盖声明 |

生成匹配规格＋完整组的结构和证据分析，新素材不能复制未授权原文或沿用错误键。原四简介原创仍绑定0.1；需补15空完形、单篇语法及较复杂阅读作者核查。错印lo clean和新源编辑风险保留反例，不用校正文本冒称原题。

两卷的完整组配套不等于独立教师金标准；真实难度/耗时、产品细档、商用及真正隐藏模型验收仍未成立。头像可置指令旁，不加角色开场故事。
