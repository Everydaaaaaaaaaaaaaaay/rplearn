# 高三阅读、完形与语法填空规格0.1

依据[江淮十校选定四组](../source-group-observations.json)g12.2023.readingA/B、cloze、grammar。实际卷期2023年8月、2024届高三；CDN202403不是卷期。普通联考，文中学生设计比赛不等于竞赛卷。

| 项目 | 可执行要求 | 证据身份 |
| --- | --- | --- |
| 阅读结构 | 当前四简介共享3题四选、人物/设计报道4题四选；短讯与长叙述都可，不强行高三每篇5题 | readingA/B实际结构；更复杂说明/论证待补，不以简单检索代表全年级 |
| 阅读考点 | 需求匹配、局部信息、跨简介共性；人物动机、用途、受益者和品质的文本推断 | 两锚组；可以保留基础题，不因年级提高而扭曲问题 |
| 输入 | 多主题词汇、分词修饰、关系从句、同位解释、引语/视角；必要低频词可释义 | 两阅读及语言运用实际输入；没有真实长句比例/词汇等级分布 |
| 完形 | 本轮单篇15空四选；保留动作施受、过程推进、同时/顺序关系，词组/习语和局部词义一起构成线索 | cloze文件7—8/键10；不是高一高二北京10空模式 |
| 语法 | 单篇10空，无给词填1词，给词形式可多词；不强改三篇共10空 | grammar文件8/键10，与北京锚模式并列 |
| 考点 | 按读音冠词、分词、主谓一致、副词、地点关系从句、不定式、被动与时态、派生词、介词 | 原10空；不机械按每种一空生成所有新组 |
| 合法变体 | 源62明确was/is inspired两种，须保留；新组按完整语境分析，不能由主键存在就否定合法变体 | 源明确允许与作者变体分析分别记录 |
| 源错误 | 源61实际印lo clean；分析to clean单列，不把错印计评分金标准或生成范句 | 原图/原生一致的真实编辑风险 |
| 干扰项 | 范围/条件、段落目的、人物特征、动作关系与习语整体含义可用；共性题检查所有小简介 | 来源机制＋工程审核规则；词性形式一致不自动证明选项质量 |

没有高三总体长度、CEFR细档、学生分钟数或年级差值。本轮生成可先用四简介/3题四选的相匹配任务，但仍须补较复杂说明/论证对照；不能据这一个早期高三卷声称全年高三备考难度完整。已有NEEA适应性来源未取相应键，暂不能作已配套评分锚题。

生成使用规格与完整匹配锚组两维约束，原创场景/数据/问题。实际作者逐题解答，必要修题再解，列每项排除依据。第二来源与更多难度、独立专家、学生标定及商业准入仍未知；角色头像展示，无开场故事。
