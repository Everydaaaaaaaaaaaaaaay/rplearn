# 初三规格0.3：苏州官方卷加入后的扩展草案

在[0.2](grade9-v0.2.md)福建两年份之外加入[苏州2024官方笔试](../Expansions/Grade9Suzhou2024Comparison-v0.1.md)。新增模式有完整题面/键及逐项作者分析，当前核心索引0.14仍绑定0.2和原53源目录；本版是可执行扩展草案，未回写旧候选历史。为新模式生成时必须同时选对应完整扩展组，不能只更换年级规格却沿用不匹配锚。

| 维度 | 允许的模式与操作 | 证据与边界 |
| --- | --- | --- |
| 定位 | 普通初三，以年级取材，教材/学期仅元数据 | 福建2025/2026与苏州2024；更多年份/地区仍缺，不定全国题型比例 |
| 阅读 | 五题四选说明/五行表格；另有六行图表三题、人物/行业/双节故事四题四选 | 选择完整模式；源Suzhou11—13、14—17、18—21、22—25；题数随承载信息，不统一改成五题 |
| 阅读操作 | 条件/方法/指代/焦点/标题，及表格字段、例证作用、人物阶段/观点、生产/销售/出口的不同数量、外部场景与内部感受 | 原表与必要图/下划线均保留；国内销量用文内总销售减出口，不能减产量或验证外部现实统计 |
| 完形 | 完整十空三选，或完整十空四选 | 原福建模式与Suzhou1—10；不能凭年级强制三选或在同一组混选项数 |
| 短文语法 | 福建：给词和无提示全部一词；苏州：无提示一词或给词正确形式，未明确给词全一词 | 两种指令制度必须显式选择。给词参考键恰一词不证明词数规则；共享were＋taken不能重复填被动助动词 |
| 单词运用 | 八空汉语意义/首字母、每空一词 | Suz31—38是句子级任务，不冒称十空共享篇章；意义/词形/初字母条件同时满足，合理其他词仍待裁决 |
| 短语词库 | 五项单词/短语各一次、正确形式，完整说明和图 | Suz39—43；plenty of/such as各是一个词库条目、两个词，不套前节一词限制；全组分配而非独立空 |
| 衔接 | 福建五空五选模式或苏州五空七选/两个多余项 | 标题层次、全文和所有选项保留；新题须明示复用，原键各一次不是原指令证明 |
| 阅读表达 | 完整文章＋事实、习惯、观点理由三问，参考2/2/3分 | Suz54—56；作者新题可选择明确工程分制，但不冒称官方分析分点；观点允许有理答案，必须保留理由要求 |
| 阅读后写作 | 依指定故事选择两个题名之一、约100词，要求理解/生活实例/启发并写题名 | Suz57与readingD同家族/曝光，不是独立隐藏题；官方参考略、无rubric/真人样例，此模式仅题面参考 |
| 质量 | 单选有唯一最佳；开放空完整回填，允许合理变体或修语境；事实与源主张分开 | 最高级/比较级不可由one of、the或地理范围自动强制；wide/wider、a/one、让步词、时态等候选需语境判断 |
| 展示 | 指令旁头像，无角色开场；不提前泄露标题题答案 | 原必要标题/段名/表头和强调保留，不能以“去标题”删除解题结构 |

每个模式分别记录正文、题干、选项/词库、图表与中文支架负荷，不由这三卷推出长度上限、长句比例、CEFR、学生分钟或升星节奏。新原创材料不得复制未授权小说/照片或沿用模糊源评分；可以保留任务结构并换成原创情境/图与新的逐项依据。

接续任务是为新增模式写完整原创和实际求解，再将所选锚、版本和风险登记纳入新的请求目录。当前机器检查只覆盖其声明的核心53和25原创；草案存在不表示扩展已生成、独立教研/学生、商业或生产验收通过。
