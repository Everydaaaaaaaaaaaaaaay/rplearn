# 高一阅读、完形与语法填空规格0.2

继承[0.1](grade10-v0.1.md)，加入[第二卷对照](../Comparisons/grade10-source-comparison-v0.1.md)。第一卷石景山，第二卷封面普通高中2024—2025高一质量监测、键页2025高一学年期末；学校/地区未知，不认证跨地区。允许教材/学期正常差异，不要求逐单元先修对齐。

| 模式/维度 | 可执行要求 | 锚组与质量边界 |
| --- | --- | --- |
| 阅读 | 四选单篇3或4题；可广告/项目报道/教育研究、人物发明报道、工具多简介、产业说明和文化保护论证 | 第一卷A/C/D及g10.2025yearend.readingA/B/C/D；不以单篇题量决定难度 |
| 阅读功能 | 条件/职责、细节、跨简介共性、人物品质、例证作用、作者目的、语境短语、限定推断/标题 | 本轮完整组实际操作；题干范围与材料证据必须精确对应 |
| 阶段/角色 | 现有版本与未来改进、当前效果与梦想分开；学校/科学家/机构/作者角色不混；计划不写成已实现 | 第二卷B/C/D；质量审核逐项检查时点、施受和视角 |
| 完形 | 单篇10空或15空四选；选择一种模式并配完整锚，不截取15空冒充原10空完整结构 | g10.2024.cloze与g10.2025yearend.cloze；后者43/54存在选项语义重叠待裁决 |
| 完形功能 | 情绪/评价改变、动作链、搭配/短语、回忆与后续揭示的认知差异；先后顺序与误解原因有全文支持 | 新卷回忆友情→误认泄密→多年后解释；事件中人物猜测不能自动当事实 |
| 语法结构 | 三篇4/3/3合计10空，或单篇10空；材料边界、提示与字数规则按选定模式保留 | g10.2024.grammar、g10.2025yearend.grammar |
| 响应/目标 | 无提示1词、给词可多词；可介词/冠词/复数/谓语/比较/副词/关系/动名词，加名词/形容词派生、分词、被动、完成时 | 实际形式集合；is enriched、have hosted说明给词不受一词限制 |
| 输入负荷 | 可以有分词修饰、关系从句、抽象名词、中文释义与引语；记录篇幅、选项、跨度及支架 | 源较长人物/说明/论证已见，不编造总体长度/长句比例/CEFR/学生用时 |
| 正确性 | 逐题依据、全部干扰项排除/开放替代；源有键不表示唯一性。错印set located或键重叠作为反例，不能当正向范句 | 工程硬规则；必须按原创实际语境再解答 |

生成同时使用本规格与匹配完整源组的结构/分析，复制、训练、向其他模型传原文等用途另核。原创人物/研究可明确虚构，宣传/科学数字不从原题自动升级事实。头像置指令旁，不加独立角色故事。

第一份三篇语法候选继续绑定0.1；新版本不覆盖历史摘要。第二卷身份仅成立到封面/题面/附加键所见程度，更多地区、独立教师、学生难度/用时、细档及商用仍待验证。
