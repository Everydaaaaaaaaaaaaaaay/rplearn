# 初二阅读与语言运用规格0.2

继承[0.1](grade8-v0.1.md)，加入[丰台第二卷对照](../Comparisons/grade8-source-comparison-v0.1.md)。西城/丰台均为北京普通初二期末，正文身份成立；机构转载原卷/附加解析的原始认证、商用与学生难度仍未知。

| 维度 | 可执行要求 | 依据与边界 |
| --- | --- | --- |
| 年级/情境 | 普通初二，以年级为主；可有校园/家庭关系、活动介绍、成长叙事及较简单研究/自然说明 | 用户接受教材/学期正常差异，不固定某册单元 |
| 阅读题量 | 四选单篇可为3题或4题；先选完整模式与匹配锚组，再创作全文/题干 | 西城B/C各4、丰台B/C各3，非全国统一题量 |
| 阅读操作 | 初始状态、原因/目的、阶段选择、局部细节、整篇意义；可加语境词义、主因与数字子集限定 | 丰台C区分所有种类/一般选择/特定区域子集；不能用一个数字替代所有对象 |
| 阅读结论 | 研究比较条件与结果分开、原型与最终版本分开；主因与其他原因分开；人物成长意义不同于只列活动 | 两卷观察；事实/营销主张不因源卷身份自动成立 |
| 匹配 | 4完整卡＋3完整人物需求＋1多余项；保留标题/标签/全部条件，不只匹配关键词 | 两卷实际结构；选项是否可复用按新题指令明示，不反推源规则 |
| 完形 | 四选，允许完整8空或10空叙事；动作、词义、搭配、心理、先后与跨段关系混合；全文结尾保留 | 西城10、丰台8；8空模式存在不表示丰台每题无错 |
| 语言形式 | 句子/对话级四选单项填空；保留完整对话和时点。可10题或12题按锚模式明确选择 | 西城13—22为10题，丰台1—12为12题；不能改名开放式短文语法填空 |
| 语言目标 | 代词/所有格、介词、疑问词、情态、比较级/最高级、现在/过去/进行时、一致、不定式、连接与条件 | 两卷所见目标集合，非必须同次全考；语法说明要服从实际情境 |
| 输入 | 可含从句、完成时、被动、分词、心理比喻与必要中文释义；空位形式与全文输入另记 | 不以年级标签机械删除源文已存在的复杂结构；学生词汇界限未标定 |
| 答案质量 | 单选唯一最佳、完整回填成立，所有干扰项逐一排除；语法正确性不能靠选“最接近作者意图”补救 | 丰台完形20句缺been，四选不能修复全文，列反例并排除正向评分示范 |
| 提示与展示 | 头像置答题要求旁；不加独立角色故事。必要释义不能泄露词义考点 | 产品要求与工程硬规则 |

原创阅读约250词为工程起点；真卷未完成统一校正转录统计，不填写初二长度分布、长句比例、CEFR或分钟阈值。不同题量/篇幅还要比较总输入、选项长度、跨段操作和提示。创作同时输入本规格与完整匹配锚，保留实际作者解题和反例检查。

现有午餐阅读继续绑定0.1，不能回写成第二来源校准后的作品。适用开放篇章形式仍缺配套锚；已有音标/给词候选缺键，不冒充正向评分材料。更多地区、独立教师、学生试做与商用继续待验证。
