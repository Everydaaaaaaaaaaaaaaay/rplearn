# 高一阅读、完形与语法填空规格0.1

参照[题组观察](../source-group-observations.json)的g10.2024.cloze、grammar、readingA/C/D。均为石景山同一卷，不当作五个独立卷源。版本/学期差异按用户接受口径保留。

| 项目 | 可执行要求 | 证据身份 |
| --- | --- | --- |
| 阅读体裁 | 可用招聘/活动广告、社会项目报道、教育研究说明；保留身份、条件、论据及限定结论 | readingA/C/D实际体裁，不只用校园叙事代表高一 |
| 阅读结构 | 当前分别3/3/4题四选，按文章可承载的信息设计，不强行每篇5题 | 源结构；不得缺后半页选项 |
| 阅读考点 | 广告区分首要职责和优先经验；报道区分例子作用与字面信息；说明保留因果、词义/比喻、关系和结论范围 | 三选定组，题型比例未统计 |
| 完形 | 10空四选作为当前默认；评价改变、情绪和事件顺序有完整链；可有词组，不用纯语法形式淘汰所有干扰项 | cloze源结构与功能；不是全国统一高一模式 |
| 语法结构 | 本轮默认3短文合计10空，分布4/3/3；每篇保留自己的语境、空号和材料边界 | grammar真实结构；不能合成单篇10空再声称同一锚题结构 |
| 响应规则 | 无给词空填1词；给词空用正确形式，可多词；参考源提供的规则，不把两种响应合并 | 题面说明；工程评分规则 |
| 语法考点 | 可用介词、复数、谓语、最高级、副词、并列连接、关系代词和动名词等；逐空写出句法/意义约束，不机械凑比例 | 源实际考点；不由课文输入倒推必测 |
| 多解处理 | 开放空位若有语法和语境均成立的响应，列完整允许变体或改写题面；不能仅用预写键排除其他答案 | 暂定工程硬规则；新编限定性关系空允许who/that |
| 源质量 | 原印set located异常留在源记录，不能被当生成范句；研究宣传和语言理解答案分层 | 实际原图；正文事实未全量外部验证 |

本版没有高一年级总体长度、词汇百分比或长句比例。生成默认从匹配体裁和完整任务结构开始，再记录实际词数/空位负荷。原型可有基础定位题，也可有跨句推断；不能因为年级较高就把每题写得更绕。

生成使用本规格＋对应完整锚组；先解题并检验合理替代响应，再提交作者审核证据。角色只以头像参与展示。第二来源、更多正常难度体裁、独立复核、学生难度/用时、产品细档与商业许可仍待成立。
