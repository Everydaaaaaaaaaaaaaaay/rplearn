# 初高中命题标准0.49：调查图写作、补件身份与给定文本

继承[0.48](PracticalAuthoringStandard-v0.48.md)。[成都初三调查发言稿补件](Sampling/writing-visual-supplements-v0.1.json)从新取得的公开重排页找到题干紧邻且实际链接的图，实看像素后绑定原冻结题干。没有从参考范文重画图、推断未印数据或增加源卷/题组计数。

| 同一完整任务的组成 | 样本实证 |
| --- | --- |
| 来源年级与调查对象 | 初三源卷；题干调查本校初二学生，不改判为初二写作 |
| 图表 | 四柱依序在本校62%、在家6%、在大学18%、其它14%，标签和数值逐对绑定 |
| 内容要求 | 描述及评析调查结果；陈述自己的选择及原因，两项要求合为一个发言稿任务 |
| 输出 | 一个作答区，80词左右，Hello, everyone.给定且不计入总词数 |
| 输入支架 | do scientific exploration为给定词汇；与固定开头和中文要求分别记录 |
| 源分值与参考 | 全任务15分；参考范文不能代替完整分析性评分标准 |

四柱完整保留在本校/在家/在大学/其它的原序，不按百分比排序后错配类别；“其它”不从范文例子改名为“博物馆/科技馆”。数值印有百分号，图未印数字纵轴刻度；不能自行补人数、样本量、调查日期、误差线或互斥单选方法。四值合100%只是算术一致，不能证明调查方法或代表性，也不是学生试做数据。题干“本校八年级”给出调查对象，不等来源试题适用年级。

本次发现旧写作分量将Hello, everyone.和参考词汇一起算作instruction，固定开头字段却为空。[写作视图0.2](Sampling/writing-material-views-v0.2.json)仅修正该任务的组件分配：说明3英语数字token/32汉字（含条目数字和80）、情境及内容要求4/85（含题号/分数/条目数字）、给定词汇3/10、固定开头2/0；图中类别另计10汉字、四数值及百分号另计。不要把印刷标签当英语词汇，也不把固定开头重复计入输出目标。原视图0.1和原文保留，其余25写作profile不变。

补件属于同一既有成都任务的另一路公开版本证据，不是新独立父卷、第二地区或原考试机构认证。重排页将两项内容要求自动编号82/83并混入孤立C，不能变成三道写作题或学生给定文本。原冻结文字缺图状态false保持；只有同时提供已核图和原题干的准备包才满足本次作者核读的完整输入要求。该区别由本机准备检查实测：缺图仍拒绝，给定补件后准备通过，41项控制中另有25前序profile一致和14错误请求拒绝。
