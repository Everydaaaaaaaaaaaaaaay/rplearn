# 六年级多题型效果0.3

继承[阅读/完形0.2](ShowcaseDelivery-v0.2.md)，本版在同一[效果页](../../../build/english-benchmark-showcase/index.html)增加六个已有完整语言任务。18完整组/158作答位/407逐题选项，另初一共享10词词库；其中50文本空只核对作者参考形式，其他108题是选择题。不是新增18作者家族或真实模型批次。

| 年级 | 新增完整任务 |
| --- | --- |
| 初一 | 10词/10空、每词一次、可变形和必要多词；第9保留found/had found |
| 初二 | 12道句子/完整问答四选；不是一篇短文的开放语法填空 |
| 初三 | 单篇10空、全部一词；给词与无给词保留 |
| 高一 | 三篇4/3/3空、无给词一词、给词用正确形式；第9同时显示who/that |
| 高二 | 单篇10空，one、has been increasing和preserving等作者核出的变体保留 |
| 高三 | 单篇10空，has been collecting、to have finished等多词形式保留 |

每组显示全材料/词库/全部作答位/指令，并能输入、提交、看解释、切回保留或重置。文本只做参考形式匹配，忽略大小写及空白差异；未匹配不直接判错，明示一词限制超出则提示修改形式。参考集合不冒充穷尽正确答案或独立评分。初一合法多词不被初三一词规则误拒，输入用时未标定。

[展示清单0.3](showcase-selection-v0.3.json)绑定当前作者摘要/规格/检查。原12阅读与完形的完整数据逐字段比对相同，作者53家族/338响应总量不变。新语言为既有六组展示，未重写题干或独立裁决；配对、开放短答、写作/续写仍通过[审阅包](ReviewPackage-v0.29.md)查看，尚未纳本页交互。当前样本标准为[0.24](PracticalAuthoringStandard-v0.24.md)，生产六题合同未接入。
