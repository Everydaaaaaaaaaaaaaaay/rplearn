# 初高中命题标准0.23：多题型的卷级组合

继承[0.22](PracticalAuthoringStandard-v0.22.md)的显式输入和年级模式约束。当前[三批结构](Sampling/current-batches-v0.2.json)检索277分层记录/37父卷/67年级任务家族单元；新160记录/988书面作答位另层，旧源117/722和作者53/338冻结。

## 新样本支持的具体细节

| 来源 | 观察与命题约束 |
| --- | --- |
| 中山初三上 | 10题语法选择与15题四选完形分开；两篇阅读各5选择，另5左项/7候选配对，不能统称15道阅读选择或五空七选衔接；10空/12词词库每空一词、每词一次、需变形 |
| 博兴初三上 | 10空四选、四篇各5选择、5空7项还原、10给词形态、5开放问答、80词左右发言；形态明确可加助动/情态词，必要诗图缺，不能确认完整输入 |
| 金华高一上 | 四篇阅读3/4/4/4，15空四选、10语法空；写作5整句翻译各3分+100词左右投稿25分，本卷没有两段续写；翻译有词/语法要求和多种参考表达，不按唯一原字符串判分 |
| 尉氏高一下 | 四篇3/4/4/4、五空七项、15空、10语法空、80词左右邮件+150词左右两给定段首续写；语言运用板块45分但两个分节仅15+15，不能静默认定整卷120分 |
| 菏泽高二上 | 15空完形、10语法空、10首字母/中文提示词、80词邮件、150词两段续写；七项衔接内容中A-F标签丢失，保留未知；听力第一节两遍，与其他样本的一遍不同 |
| 临沂高三上 | 15空、80词邮件、150词续写；听力/阅读都从1编号，独立命名空间；150分由分区相加、分钟未知，分配时间不作学生实测 |

五开放问答不必一律要求完整句：中山参考允许切题、语义完整的简答或整句，具体裁决由评卷组另定。写作给定开头/结尾是否计词仅按明示；“80左右”“至少80”不可互换，示例范文长度不修改指令。

## 输入计量与样本错误

新六完形正文/选项内容token分别247/40、249/64、232/64、223/60、239/64、307/64，空数10/15/15/15/15/15；除已定位空号与选项标签外保留源内容。19完形/17父卷171对局部筛查无精确重复或近似候选，旧13篇测量与摘要重放一致；全库去重仍未完成。

另[组件工具](../Tools/profile_school_nonreading_components.py)核12个选定视图：中山词库材料204与共享词12、开放问答材料239与题干40；金华/尉氏/菏泽/临沂给词材料224/181/184/212，原括号内给词保留；三续写材料280/362/345，与要求输出150词分开。金华翻译视图仅8个英文token，主要输入是中文，不能称低负荷。计数不是难度、认知负荷或用时标定。

题面和参考错误不继承为标准：缺思维导图/原诗/科学下标/下划线、相对月份等同固定30天、历史轶事、未经核实的书籍概要与研究结论、危险自我用药或维修区叙述分别记录。完整结构不等事实正确，示例范文不是安全或评分gold。
