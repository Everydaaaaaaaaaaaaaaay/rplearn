# 咕咕 Blender 重建统一管线

## 唯一总流程

`mascot-logo-reconstruction` 是唯一编排器；`quality-refinement-autoloop` 只负责失败冻结、诊断和重试门禁，不直接替代重建流程。

## 来源优先级

1. 正面图：品牌识别、X/Z 外轮廓、可见部件数、眼睛/喙/脸颊/围巾等地标。
2. 侧面图：Y/Z 深度、前后层叠、嘴喙和尾羽的纵深。
3. 背面图：背部、围巾结、尾羽和翅膀背面；不得反向修改正面锁定轮廓。
4. 用户反馈：禁止球体堆叠感、几何切面和粗糙过渡；必须以连续、可控的造型表面交付。

参考图属于美术概念转面，不视为严格 CAD 正交图。冲突时采用 `front_side_canonical`：正面品牌读图优先，侧面控制厚度，背面用于结构补全。

## 坐标与命名契约

- 正面：X/Z，角色朝向 -Y。
- 侧面：Y/Z。
- 背面：后侧 X/Z。
- 结构网格：`GEO_咕咕_<部件>`。
- 材质：`MAT_咕咕_<部件>`。
- 参考对象：`REF_咕咕_<视图>`，永不导出。
- 验证相机：`CAM_验证_<视图>`。

## 顺序门禁

1. 参考清单、部件库存、地标和多视图约束齐全。
2. 主体低模笼通过正/侧/背轮廓检查。
3. 完整结构部件数与清单一致。
4. 几何和地标通过后才做材质。
5. 静态模型通过最终 QA 后才进入绑定、动画和运行时导出。

## 并行规则

- 部件分割可以与验证脚本建设并行。
- 材质色板分析可以与几何修形并行，但材质赋值必须等待几何门禁。
- 任何验证工具改进不得直接改变产品几何。

## 交付门禁

- 正面全角色轮廓 IoU：最终目标不低于 0.82；完整部件就位前仅记录基线。
- 包围盒中心漂移：不超过画面宽度 1.5%。
- 正面包围盒尺寸误差：不超过 3%；侧面/背面首轮不超过 5%。
- 眼睛、嘴喙、围巾和脸颊地标漂移：不超过画面尺寸 2%。
- 结构部件数必须与清单完全一致。
- 最终必须有正面、侧面、背面、3/4、美术材质图和线框图，并给出明确 SHIP/NO-SHIP 结论。
