# 咕咕模型质量循环报告

## 用户反馈

- “精度太差、几何球面感严重。”
- 需要像角色艺术家一样逐级建立主形、次级形和完整部件，而不是把球体/椭球拼成吉祥物。

## 冻结证据

- 失败模型：`source/gugu-sculpt-v2-stage-04-transition-refine.blend`
- 正/侧/3/4 检查图：`renders/gugu-sculpt-v2-stage-04-*.png`
- 自动轮廓基线：`analysis/fit/stage04/fit-summary.json`
- 正面全角色基线 IoU：约 0.492。
- 三视图平均基线 IoU：约 0.604；由于当前只有主体坯体，该数值不能作为完整角色验收值。

stage04 保留为失败证据，不再覆盖或直接迭代。新的结构从参考清单与轮廓契约建立，并使用新的阶段编号。

## 主要失败维度

1. 几何/轮廓：主体呈块状花生形，头身节奏与参考不符。
2. 多视图深度：缺少由侧面约束的面部前凸、胸腹、尾部和配件层叠。
3. 流程编排：过去依赖界面目测，没有部件清单、地标和自动量化闭环。
4. 完整性：眼睛、喙、脸颊、头冠、翅膀、围巾、腹部、尾羽、脚和挎包尚未进入结构门禁。

## 技能缺口决定

现有技能栈已经覆盖本轮缺口：来源分割、轮廓建模、多视图约束、连续雕刻和 QA。当前不需要继续寻找新的 Blender MCP；需要严格执行已引入的确定性工具和顺序门禁。

## 修复策略

1. 正面参考锁定品牌轮廓和地标。
2. 为每个可见结构部件建立命名掩码和对象清单。
3. 先建立低模连续主体笼，再由侧面添加 Y 深度；不从 stage04 表面继续平滑。
4. 每批 BMesh/数据级修改后自动渲染三视图并生成误差叠加。
5. 完整结构通过后再进入材质、绑定前拓扑和导出。
