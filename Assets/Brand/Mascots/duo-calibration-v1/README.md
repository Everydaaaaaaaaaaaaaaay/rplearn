# 双人比例校准：局部配色修正版

用户指定以第一张双人比例校准图为基础，仅纠正嘎嘎眼周多出的奶油色。
这不是重新生成的角色，也不是应用内资源替换；修正版供视觉确认。

## 文件与来源

- `source.png`：不可变原图，来自 `exec-14d3fee4-0960-4c07-a8d8-1f09dc5f8aa6.png`。
- `corrected.png`：原尺寸 1668 × 943 的无损 PNG 修正版。
- `recolor-mask.png`：局部改色混合权重，黑色区域完全不改动。
- `recolor.py`：可复现的非生成式局部改色程序。
- `verification.json`：程序对保存后的图像重新读取并验证的结果。

原图 SHA-256：`286f7e68e866227119451a44aeb9fbf42fb8af66fb0add061cb99a94459d86ae`。

## 范围与方法

仅将嘎嘎眼睛周围上延的奶油色改为邻近羽毛的浅紫色，保留下方奶油色脸颊。
程序从原图附近浅紫色像素拟合平滑色场，用手工限定的局部蒙版改色。
眼睛内部、深色线条与嘴部设置保护；眼周交界使用抗锯齿混合。
没有调用生成模型，没有缩放、位移、重塑、全图滤镜或有损重新编码。
蒙版内部的目标色是重新计算的，并不宣称这些改色像素保留原来的纹理。

咕咕、嘎嘎身体、头部外轮廓、头身比例及改色区域之外的原图像素保持不变。
图中文字也保持原样，未顺带重绘。

## 复现与验证

依赖 Python 3、Pillow、NumPy（本次 Pillow 11.3.0 / NumPy 2.0.2）。

```sh
python3 Assets/Brand/Mascots/duo-calibration-v1/recolor.py
```

程序校验源图哈希与尺寸，验证输出蒙版外、咕咕区域、嘎嘎身体区域及保护区域的零像素变化。
另有限定坐标区域和深色线条的独立断言。视觉检查覆盖原尺寸全图与四倍眼周局部。
这些检查不等于用户已确认新配色；本目录不接入运行时，也不替换暂定软件图标。
