## 版本与来源

- 用户明确退回学习页复用消息页照片的方案。本版 `.learning` 映射为独立 `learning_<city>_glass`，十五城均重新选取摄影；消息页、联系人页的原摄影继续用于其原页面。
- 来源、作者、许可、下载尺寸、裁切及源图/运行图 SHA-256：[photos.json](photos.json)。下载参考本身即为被选用的真实摄影，原始下载与官方许可元数据保留于 `sources/`。没有生成式扩图、放大、虚化或美化编辑。
- 逐城题材与选取理由：[README.md](README.md)。已查看全部下载图、最终竖幅和原生像素细节；[细节证据](evidence/native-details.jpg)、[奥克兰/墨尔本重裁及金斯敦裁切](evidence/final-crop-examples.jpg)。
- 本轮不是合成室内或动态场景，G3/M1–M3 不适用；不添加背景手势、声音或运动。

## 测试与边界

- 标准屏六项 UI 检查均有通过证据，覆盖十五城及每城实际筛选操作、记录组合筛选/清除、锁定进度、学习进度入口、聊天草稿与左右分页。初跑四通过、两失败；新增角色信息为 SwiftUI 合并后的 StaticText，测试原先限定 Other。改为按标识查找任意类型，定向重跑两项通过；无需修改产品来适配测试。
- 小屏三项 UI 检查通过，覆盖十五城与每城筛选菜单、默认折叠/展开/收起，以及最大辅助字号深色页面。
- 城市资源映射三项 Xcode 托管 Swift 测试通过；包括十五城独立资源、未知值回退、大小写和空白标准化。
- 本次第一次混用 unit/UI scheme 的调用在执行测试前失败，后按 `Scripts/test-ui.sh` 与 `Scripts/test.sh` 分别运行。没有把无实际测试的调用计为通过。
- Computer Use 选中当前 Device Hub 后截图仍为空白；未循环重试，改用 XCTest 交互与原生截图。
- 免登录工程预览含“示例进度”提示，不是正式账号数据；未测真机、线上成绩或 App Store 发布。活动摄影及消息/联系人页面未改，未重做其完整验收。
- 详细命令和结果路径将记录于 `docs/verification/learning-layout-independent-cities-20261027.json`。
