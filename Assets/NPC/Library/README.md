# NPC 头像资产

唯一有效图录为 `v3/catalog.json`，有效图片必须同时具备 `status: accepted`、与图片 SHA 一致的验收记录、圆裁与背景检查，以及实际观察档案。正式数量见 `docs/npc-library/progress.md`。

- `v3/images`：生产候选与已验收图片；淘汰副本已删除，拒绝原因留在图录。
- `v3/style.txt`：统一美术规范。条目 `prompt` 是每张图片实际使用的完整提示词。
- `reviews`：初始去重、背景回修、各批灰度近邻比较记录。近邻分数仅用于辅助视觉审查。
- `reports`：真实服务链逐例测试、对应图录快照与缺口聚合。历史快照内的图片路径以原 v3 图录目录为基准，可能包含后来淘汰的图片；不能作为发布清单。
- `reference`：用户确认的风格参考。
- `experiments`：全身构图、背景与脸型的早期实验，不计正式数量。
- `v1`、`v2`：只读的早期规划与来源凭据，标签多为创作目标，部分图片已被淘汰或迁入 v3。禁止导入生产；旧生成规划脚本已移除，避免误用。

施工、审核、测试、导出步骤见 `Tools/ArtPipeline/README.md`。生成使用内置 imagegen，每幅一调用；原始输出路径保存在对应 `.receipt.json`，项目消费图片全部保存在本仓库。2026-09-06 已部署到线上 HTTPS 静态服务并导入数据库，部署与验证记录见 `docs/npc-library/deployment-2026-09-06.md`。
