## 动态与性能边界

- `ActivityAmbientLightLayer`只在标定的地面和空桌面接收区叠加很弱的树叶阴影；
  光影在所有入口和文字下方，照片及其建筑/物品完全不移动、不变形。
- 树影为代码绘制的透明矢量投影图形，不是生成式图像编辑。每块平面一次栅格化560²纹理，
  Core Animation仅合成其位置变化，边界径向羽化。没有视频、整屏模糊或生产逐帧SwiftUI更新。
- 阴影透明度0.12，纹理偏移最多±10/±6px，投影后更小。三个场景纹理种子不同。
  60秒连续正弦组合，同一周期首尾位置/速度一致；不是随机人流，也不宣称无限不重复。
- 关闭光影、减少动态、节能/高温、隐藏/后台均暂停动画。恢复从暂停相位继续，不重新从零闪回。
  对话期间保持动态；离开窗口也自动暂停。无音轨，不占用角色语音音频会话。
- DEBUG活动UI测试才启用1Hz相位读取，生产没有这个计时器。
- 原3段视频约66MB移出App，保存于`../RejectedRuntime-v3/`，没有删除历史证据。
