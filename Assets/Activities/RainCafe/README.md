## 选材结论

原片为 19.633 秒、1440 × 2560、30 fps 的固定竖屏机位。机位位于咖啡馆桌边，
窗外可见真实雨水和路面；近景同一条实拍中包含点心盘、纸巾容器和桌面。
因此无需把另一机位的视频嵌进生成背景，也无需生成独立前景。窗上的粉色手写字及窗外紫色活动招牌
属于拍摄现场；它们是否干扰最终 UI 必须以手机截图复核，不能仅凭原片放行。

筛选时另外实看并拒绝：Pexels 29636092（持续摇镜，桌面离开画面）、25724633（咖啡杯被拿走后
锚点长期缺失）、37451729（几乎没有可感知动态）和 34711743（缺少三个自然锚点）。

## 确定性处理

从仓库根目录运行：

```bash
bash Scripts/prepare-raincafe-activity-scene.sh /path/to/33741230.mp4
```

- 原片左侧裁切 `1181:2560:0:0`，缩放为 852 × 1848，保持人物、车辆和雨水的自然时间。
- 完整底板取源片 2 秒处；上方 800 像素的窗景使用源片 2.0...19.5 秒，尾部 2 秒与
  源片 0...2 秒作正向环境淡接，下缘有 32 像素羽化。
- 初版曾整帧淡接，应用动态截图中实际发现车辆双影，登记为 M-05 并立即退回。当前版只让
  没有人车穿越的上方窗面保持实拍雨水动态，桌面、物品和下方街景保持同源静帧；不是生成修补。
- 成片 17.5 秒、24 fps、静音 H.264；没有倒放、慢放或生成帧。底板静止是明确的合成边界，
  不能被写成整幅纯视频。
- 海报从最终编码视频首帧提取。应用共享 852 × 1847 坐标画布，在顶部/底部各裁约半个像素；
  静态和动态使用同一填充规则。
- App 使用 `AVPlayerLooper` 预排下一份解码，不在文件末尾通知后 seek。

## 互动锚点

- 窗面 → 聊聊雨天。
- 左侧点心盘 → 分享点心。
- 中下部纸巾容器 → 递张纸巾。

三项入口浮在对应物体附近并朝向观察者，不把文字压进陡峭桌面。最终位置、最小屏命中及
两个完整循环的连续视觉检查记录在 `Assets/Activities/RealMotion-v5/acceptance-v5.md`。
