## 界面规范

| 区域 | 本版设计 |
| --- | --- |
| 实景背景 | 当地照片铺满屏幕，沿用逐图构图，顶部和底部局部渐变承托文字 |
| 顶部导航 | 左右对称 28pt 边距，城市名居中，17pt 常规字重、2pt 字距。返回与更多图标 18pt，44pt 命中区域 |
| 地点标题 | 居中，语义 largeTitle、serif、常规字重，1.5pt 字距、8pt 行间距。距离主按钮 32pt，多行标题居中排列 |
| 主按钮 | 象牙白胶囊，固定墨色文字，body 中等字重、2pt 字距，最小 230×58pt，底部安全区内留 26pt。单一主要操作 |
| 侧箭头 | 20pt 细线图标、44×64pt 命中区域，轻微呼吸，边界停用。减少动态时停用呼吸 |
| 城市选择 | 暖白纸面、单列城市、宽松行距，当前城市用一个小对勾标识 |
| 摄影信息 | 同一暖白纸面与固定墨色，系统表单保留来源、许可和处理说明，固定浅色显示 |

象牙白为 `#F9F6F1`，固定墨色采用现有 `dsPaperInk`（`#091825`）。导航白字、标题白字与象牙白主按钮形成层级。按压继续使用既有共享反馈，原生分页承接手势速度。主界面文字上限为 accessibility2，二级滚动页面按系统字号显示。
