## 工程验证

- 采图优先使用标准 3840px 高清版本，竖图可用覆盖屏幕像素的 1920px 版本。源图与实际下载文件都按 1206×2622 的竖屏覆盖计算，放大上限 1.2。1280×720 和 1600×1200 的回归样本被拒绝。
- 编码采用 JPEG quality 92、4:4:4，最长输出框为 8192×3200，等比缩小。App 在后台验证字节指纹并按屏幕像素解码，背景保存可见区域位图，全图入口显示完整构图。
- `activity-scene-gallery.py --build` 与独立校验通过，确认十五城、54 个唯一照片、实际 JPEG 尺寸、许可、裁切及 App 清单一致。编译产物中的全部 54 个照片字节与清单再次核对通过。
- 世界草稿 CLI 校验通过。比对改动前版本，200 人的身份、原卡、新资料卡、头像、城市、故事 ID 及路径图一致。四个草稿地点绑定随查尔斯堡修订，所有角色配额通过结构检查。
- 三个 Python 文件语法检查、竖屏覆盖回归检查及 iOS 架构检查通过。相关 UI 测试清单同步新地点 ID，本轮采用 Computer Use 定向检查。
- `Scripts/preview.sh build scenes-preview` 构建通过并安装。复用同一产物完成小屏安装，当前小屏模拟器留在查尔斯堡供查看。构建日志位于 `build/activity-hd-20261115/preview-build.log`，小屏安装日志为 `preview-compact.log`。
