# 英语水平校准标准

## 使用边界

本应用的结果用于控制 NPC 对话、日常学习材料与讲解难度，不是学历判断或官方考试证书。14–20 道题只能给出学习起点估计，因此结果必须同时展示 90% 可信区间和判断稳定度。

中国课程标准的能力等级并不与每一个年级逐一对应。小学至高中各年级在产品中表示“人教版一年级起点教材进度里程碑”，不是教育部单独颁布的年级能力证书。中国英语能力等级量表（CSE）用作跨学段锚点：小学初学者从一级起步，初中以三级、高中以四级作为能力描述检索起点。

大学阶段采用“大学英语四级”和“大学英语六级”两个学习难度档。全国大学英语四、六级考试是常模参照考试，官方不设置及格线；应用显示的档位只表示题目与语言使用要求接近该阶段，不表示用户通过 CET。原有持久化 raw value `undergraduate` 与 `postgraduate` 为兼容已有数据而保留，对外名称分别改为“大学英语四级”和“大学英语六级”。

四六级之后统一称为“高级英语（专业与学术）”，以 CSE 七级及以上、CEFR C1+ 作为辅助描述。学历不是语言能力等级；英语专业考试也不存在“专业七级”这一正式档次，因此不使用“研究生级”或“英语专业七级”命名。

## 内部校准边界

自适应引擎使用带猜测修正的三参数逻辑斯蒂克模型和宽松贝叶斯先验。内部能力值仅用于排序与选题，不可解释为官方考试分数。

| 能力值上界 | 应用等级 |
| ---: | --- |
| -2.75 | 幼儿启蒙 |
| -2.45 | 小学一年级 |
| -2.15 | 小学二年级 |
| -1.85 | 小学三年级 |
| -1.55 | 小学四年级 |
| -1.25 | 小学五年级 |
| -0.95 | 小学六年级 |
| -0.60 | 初中一年级 |
| -0.25 | 初中二年级 |
| 0.10 | 初中三年级 |
| 0.45 | 高中一年级 |
| 0.80 | 高中二年级 |
| 1.15 | 高中三年级 |
| 1.55 | 大学英语四级 |
| 2.05 | 大学英语六级 |
| 以上 | 高级英语（专业与学术） |

这些切点是应用内部的等距初始标尺，并非官方换算表。题目难度与区分度目前由课程内容和专家规则预标定；上线后应使用匿名作答数据检查题目拟合、差异题项功能和年级外部效标，再冻结正式校准版本。

## 动态题量与抽题

- 至少作答 14 题、最多 20 题，每项能力至少覆盖 3 题。
- 第 14–16 题只有在标准误不高于 0.44、当前或相邻一级的后验质量不低于 72%，且答案倒置不超过 2 次时结束。
- 第 17 题起放宽至标准误 0.54、稳定度 58%；第 20 题无条件结束并诚实展示区间。
- 每轮先用后验期望信息量、能力覆盖、题型变化和难度跳幅筛选，再从得分接近最佳的最多 6 道题中随机抽取。
- 随包题库共 96 道原创题，词汇、语法与用法、阅读、听力各 24 道，覆盖幼儿启蒙到高级英语。
