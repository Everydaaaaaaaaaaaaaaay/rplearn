# 记忆更新与本地归档（2026-09-13）

## 行为

- 明确的个人事实、偏好、计划与取消，随既有关系／语法点评提取，每轮最多两条。普通寒暄不附加记忆提取说明；漏检仍由周期摘要兜底。
- 事实保存稳定键、用户原话证据、消息标识、观察时间与状态。同键较新的事实覆盖较旧版本；拒绝迟到结果和无用户原话支撑的提取。
- 计划与完成分开；今天／明天按原消息时间解析，未确认结果不推断成已发生。
- 活跃记忆超配额后本地归档，不再付费逐层改写或删除溢出历史。查询结合关键词与系统英文句向量；系统不提供向量时回退关键词。
- 设置 → 记忆中可纠正、标记过时、遗忘，并查看归档。移除注入调试样例入口。
- 记忆仍按角色隔离。元数据封装在现有同步 content 中，兼容旧纯文本记录，无数据库迁移。

## 额度边界

| 环节 | 之前 | 本次 |
| --- | --- | --- |
| 每轮新增独立记忆请求 | 0 | 0 |
| 明确事实的点评 | 原有请求 | 同一请求增加受限提取字段，最多 2 条 |
| 普通寒暄 | 原有点评 | 不增加记忆提取说明 |
| 周期摘要 | 24 条未摘要消息或约 2800 token，批量 16 条 | 不变 |
| 短层 14 条、Free 配额 8 条的溢出整理 | 1 次模型合并 | 0 次；8 条活跃、6 条归档 |
| 回复的记忆内容预算 | 约 520 token，加固定说明 | 不变；状态文字计入内容估算 |

这说明归档整理确实减少请求，但不代表总费用固定下降某一百分比：明确事实的联合点评会增加输入／输出 token。未进行线上付费 A/B 测量，不承诺净节省比例。系统句向量与检索不消耗模型额度。

## 数据与已知限制

- 用户编辑的同键事实优先，模型不能自动覆盖；以后变更可继续在记忆档案中编辑。
- 遗忘会清空该条正文／证据，并保留不可见标记，阻止旧结果恢复。为防旧摘要以另一种措辞带回事实，同角色既有非结构化摘要保留在档案中但一并停止提供给模型；旧聊天仍可回看，但不会再用于回复、主动问候和摘要。其他结构化事实保留。
- 用户编辑也设置旧聊天的使用截止时间，防止旧信息覆盖修正；不删除聊天记录。遗忘／纠正会丢弃未发送的主动问候。
- 自然语言提取依赖模型，证据匹配只能限制来源，不能证明模型对含义的理解完全正确；本地规则保守，部分事实需等待周期摘要。
- 本次未增加云端向量索引或新模型服务。归档数量增长后的大规模检索性能尚未做压力测试；跨设备并发修改仍使用现有同步冲突策略。
