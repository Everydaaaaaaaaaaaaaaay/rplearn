# AI 模型控制面

AI 控制面用于在不重新发布 App 或后端代码的情况下，按任务选择经过校验的 DeepSeek 或
OpenRouter 模型，并统一观察质量与成本信号。它只属于内部运维面，不是用户功能。

## 启用与访问

服务器密钥只写入未跟踪的运行环境或 Secret Manager：

```dotenv
ADMIN_API_ENABLED=true
ADMIN_API_KEYS=primary=<至少 32 个字符的随机管理员令牌>
OPENROUTER_API_KEY=<服务端 OpenRouter 密钥>
OPENROUTER_BASE_URL=https://openrouter.ai/api/v1
OPENROUTER_APP_NAME=LingoTrip
OPENROUTER_SITE_URL=https://rplearn.haruyuki.cn
OPENROUTER_USD_TO_CNY=<经审核并固定的小数汇率>
```

启动并完成数据库迁移后，通过同一 HTTPS 后端的 `/internal/admin/ai` 访问。页面要求输入
`ADMIN_API_KEYS` 中等号右侧的令牌，令牌只进入当前标签页的 `sessionStorage`。生产环境还应
限制运维入口的网络访问；不要把管理员令牌放进 URL、截图、聊天、源码或日志。

原生服务器部署将 `ADMIN_HOST`（当前为 `coovingo.com`）作为独立的 Caddy 站点，只代理
AI 控制台及其内部 API；主 API 域名继续拒绝全部 `/internal/*` 路径，管理域名的其他路径
返回 404。访问管理域名根路径会跳转到控制台。

只配置 OpenRouter 密钥而没有结算汇率会阻止服务启动。这样可以避免同一次模型调用在不同
时间按不同汇率回算，保证用户成本与总成本可复核。

## 上线路由

1. 在“模型目录”同步 OpenRouter。同步会固化模型 ID、上下文、能力和每 Token 美元价格，
   同时将上游已移除的条目标为不可用；非文本模型和无有效价格的模型不会进入可选列表。
2. 在“任务路由”选择一个任务，设置供应商、模型、温度、最大输出、超时和供应商参数。
   切换到 OpenRouter 会自动填入 `{"provider":{"require_parameters":true}}`；JSON 任务
   不能移除此约束，并且所选模型必须声明结构化输出能力。
3. 填写具体变更理由后发布。更新使用乐观锁和幂等键，其他管理员刚刚发布过同一路由时，
   旧页面不会覆盖新版本。
4. 观察请求成功率、P95 延迟、输出质量和实际成本。出现回归时，从版本记录创建一个新的
   回滚版本；历史记录不会被改写或删除。

路由修改立即影响新请求。当前没有自动流量分桶，因此高风险模型应先选低影响任务或测试
环境做真实提示词验收，再逐项切换生产任务。同步目录不会自动切换任何路由。

## 成本与用量口径

- “上游美元成本”优先使用 OpenRouter 响应中的 `usage.cost`，同时记录输入、输出和缓存
  Token；这最接近实际账单。
- “人民币成本”来自同一 AI 操作在积分账本中的最终 `settled_units`，按每人民币
  `1,000,000,000` 个账本单位显示。OpenRouter 返回实际成本时，按该请求保存的汇率换算；
  否则按请求时保存的模型目录价格与用量精确计算。
- 预留金额只在用户明确发起 AI 操作后、真正调用上游前短暂占用，成功后立即按实际用量
  结算；未发出上游即失败会释放，已发出但无法确认用量的请求进入待核对。学习辅助后台任务
  使用独立服务预算，不占用用户可见的每日额度。
- 成功但缺少可靠用量或结算记录的请求计入“成本待核对”，不能被汇总成零成本。
- 用户表最多返回所选时间窗内成本最高的 200 位用户；最近请求最多 100 条。用户 ID 在
  OpenRouter 请求中会先用服务端密钥做 HMAC 化，不把内部账号 ID 交给供应商。

时间窗支持 1、7、30、90 天，可按用户 UUID 过滤。总览、任务、模型、用户与请求明细使用
同一批 `ai_requests` 和 `credit_operations` 事实记录，便于从汇总下钻核对。

## 安全与故障处理

- 页面、模型目录、分析和路由 API 只在管理员接口开启时注册；所有数据接口使用 Bearer
  管理员鉴权。修改接口还要求 UUID 幂等键、当前配置版本和至少 8 个字符的理由。
- 控制台响应禁止缓存和嵌入，并使用收紧的 CSP。页面不会返回供应商密钥或管理员密钥。
- OpenRouter 路由在发布时校验凭据、汇率、目录可用性和 JSON 能力；已从目录下架的模型
  会在下一次调用计价时被拒绝，不会以未知价格继续消费。
- 生产就绪检查会对所有启用中的 OpenRouter 路由同时核对适配器配置、本地目录与实时上游
  目录；没有启用 OpenRouter 路由时不会因为该可选供应商增加外部就绪依赖。
- OpenRouter 不可用时不会自动偷偷改回 DeepSeek。应由管理员核对故障后发布新路由或使用
  版本回滚，确保供应商变化始终可审计。
- 对照 OpenRouter 账单定期抽查“上游美元成本”；如出现“成本待核对”，先保留原请求与
  账单证据，再使用既有账本核对流程处理，不要手工删除或改写请求记录。

## 发布验收

每次后端发布至少确认：迁移从空数据库和现有测试数据库均可执行；控制台未鉴权时数据接口
返回 401；同步后能筛掉非文本模型；文本与 JSON 任务各完成一次 OpenRouter 请求；响应中的
实际美元成本能按固定汇率进入人民币账本；按用户筛选能找到该请求；路由回滚后新请求重新
命中原供应商。线上真实模型调用和供应商账单核对属于单独授权的生产验收，不以本地替身测试
代替。
