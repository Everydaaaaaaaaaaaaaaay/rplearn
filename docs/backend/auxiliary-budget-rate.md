# 辅助任务预算倍率

在管理后台「积分倍率 → 辅助任务预算」中配置，与用户积分共用
`/internal/admin/ai/credit-rates`、倍率单位（10000 = 1 倍）、版本校验、幂等命令和变更审计。
请求使用 `scope: "auxiliary"`、空 `userIds`；读取字段为 `auxiliaryRateUnits`。
默认 1 倍；0.01 倍对应 `rateUnits: 100`。用户全局和个人覆盖互不影响。

预算准入复用 `applyCreditRate` 的整数向上取整规则，折算当前周期消耗、在途预留、待核账金额
及新请求预估费用。调整后下一次请求立即生效，已经达到原预算上限的账号也能按新倍率继续。
真实模型成本、历史账单、用户积分和辅助任务原始成本账本不改写；辅助预算恢复后按恢复的倍率
重新核算当前周期。0 倍跳过辅助预算限制。此设置不会改变模型输出 Token 上限或供应商超时。

迁移 `0022_auxiliary_budget_rate` 仅新增有默认值的配置列，旧程序仍可运行。
辅助倍率使用现有配置表读取，不使用独立环境变量或硬编码测试值。

测试期临时目标：辅助倍率 0.01；原值 1。恢复时在同一后台填入 1，并填写变更理由；
API 使用最新版本号和新的 UUID 幂等键。未指定自动恢复日期。

验证：隔离 PostgreSQL 集成测试覆盖原预算触顶后的放行、在途预留限制、恢复、零倍率、
参数校验、版本冲突、审计与幂等重放，以及用户积分和原始账本不变。
