# 角色关系算法校准记录

> 本文记录可复现的“测试 → 反思 → 优化 → 再测试”证据。它不是对真人情感的科学测量声明，
> 而是防止产品参数只凭直觉漂移的工程账本。

## 工作链与退出条件

每轮按同一顺序执行：先为一个产品命题写可失败的测试，再观察失败轨迹，区分模型语义缺陷与工程缺陷，
做最小修正，运行全部客户端测试，最后用调试实验室验证用户可观察结果。任何只让单个样例通过、却破坏
长期轨迹或伦理边界的改动都不接受。

本轮达到“可以进入下一次成熟迭代”的条件是：

1. 连续两次全量回归没有高优先级失败；
2. 10,000 次确定性随机输入始终满足数值不变量；
3. 十年失联轨迹单调且不低于长期纽带；
4. 对抗信号、修复刷取、乱序并发、旧数据迁移和无信息重复都有固定回归用例；
5. Debug 实验室能够不污染真实数据地复现关键结论，Release 不包含实验入口。

## 第一轮：长期纽带、冲突优先级与并发

### 测试发现

- 一次普通但不愉快、没有越界的交流会轻微侵蚀长期下限；这会把“今天聊得不愉快”错误解释为共同历史消失。
- 当审阅模型同时给出满值温暖和严重越界时，正向权重可能抵消伤害，甚至增加好感、信任和尊重。
- 当日普通收益达到 4 后，真诚道歉完全无法恢复任何好感，产品行为会显得机械。
- 用单一“最后消息”游标去重会直接丢弃较早发出、较晚完成的另一条有效审阅。

### 反思与优化

- 把“当前亲近度”和“沉淀纽带”分开：普通摩擦只改变前者，明确越界或极端重要敌意才伤及后者。
- 为越界建立不可被正向字段抵消的伤害项，并限制矛盾信号下的五个关系维度目标。
- 将每日预算拆为普通收益 4 和修复收益 2；修复仍受重复衰减，避免道歉刷分。
- 以最近 64 个消息 ID 建立有界去重账本；不同消息可乱序结算，最新游标只向前移动。

### 再测试结果

四个原始失败全部通过；10,000 次越界随机输入和十年时间轨迹同时通过，说明修复没有破坏范围、单调性和
长期下限。

## 第二轮：修复滥用、公平性与兼容性

### 测试发现与结论

- 连续 20 次修复始终受每日 2 点修复预算约束，不能以冲突—道歉循环刷取关系。
- 礼貌拒绝和尊重分歧不会被当成关系伤害；英语错误仍不进入关系评价。
- 低置信度极端负面判断仍保留谨慎影响，但明显小于高置信度伤害，避免模型不确定时过度惩罚。
- 一个月每日一次有意义交流能形成明显关系，普通寒暄明显更慢，两者都不会快速达到满值。
- 缺少新增可选字段的首版 JSON 可以读取，并在下一次结算时自然补齐。

这一轮未出现新的高优先级失败，但暴露了尚未测试的语义问题：熟悉度仍可能只是“发生过多少次接触”。

## 第三轮：熟悉度语义与结算一致性

### 测试发现

- 1,000 次完全无信息量的重复消息会把熟悉度从初始值推到很高。
- 严重越界中只要夹杂大量披露，熟悉度仍会微增；这会把伤害错误描述成关系进展。

### 反思与优化

熟悉度应表达“获得了多少可信、可用的相互信息”，而不是曝光次数。增长现在同时需要：

- 披露、回应或投入形成的信息量；
- 事件重要性和模型置信度；
- 没有越界、敌意足够低的安全门；
- 同日重复衰减。

因此空洞重复和严重伤害不再增加熟悉度，安全的互惠披露仍会渐进增长。两条结算路径也共用同一个游标与
去重账本更新函数，降低未来演化时出现行为分叉的风险。

### 再测试结果

空洞重复、越界披露、有效披露、乱序游标、模型失败后的迟到结果和账本容量测试全部通过；随后全量客户端
测试通过。

## 下一次成熟迭代的输入

现有模型已足以进入下一轮，但下一轮不应继续凭感觉微调全局系数。优先积累以下证据：

1. 建立去身份化、人工标注的多轮对话评测集，覆盖不同文化表达、讽刺、含蓄拒绝、修复和边界语言；
2. 让角色人格只改变表达和互动偏好，不改变尊重边界与反操纵规则；
3. 校准“模型社会信号”的一致性、置信度可靠性和跨模型漂移，再讨论个性化参数；
4. 对多设备同步采用服务端权威事件或可合并事件日志，64 条客户端账本只是当前并发窗口，不是永久审计；
5. 通过明确的用户反馈评估角色是否自然，不使用提高留存或消息量作为亲密算法的替代目标。

只有新数据证明某条轨迹系统性失真时才调整参数，并为该失真先增加回归测试。

## 第二代工作链：从样例回归升级为成熟度门禁

第一代工作链证明了基本范围、抗刷取、时间衰减和冲突边界，但仍偏重单点样例。第二代在原有全量测试
之前增加五类门禁：

1. **人工标注轨迹语料**：建设性回应、礼貌拒绝、停顿、轻视和严重越界分别验证方向及允许幅度；
2. **变形性质**：逐级改变置信度或越界强度，验证影响单调；在阈值附近微调输入，验证输出连续；
3. **公平与隐私**：互动来源不得改变计算，事件账本不保存用户原始消息；
4. **模型漂移**：缺损 JSON 必须原子失败，范围外数值必须被确定性引擎收敛，角色档案必须作为不可信数据；
5. **并发与重放**：不同消息并发不丢失，同一消息并发只结算一次，持久化检查点与连续计算保持一致。

`Scripts/test-relationship.sh` 是第二代专项入口，默认连续运行两遍 `RelationshipServiceTests`、
`RelationshipEngineStressTests` 和 `RelationshipMaturityTests`。它是快速门禁，不替代完整客户端、后端和
Release 构建验证。

## 第四轮：轨迹语料、零证据与高并发

首轮第二代测试产生三个失败：

- 20 条并发离线结算只保存 3 条。三次乐观重试在大量任务同时读取同一修订号时只能让少数任务成功，
  其余任务会静默返回；
- 全零、置信度为零的审阅虽然不改变总分，却把信任从 0.1200 推到 0.1214，说明维度更新使用了默认目标，
  没有验证是否确实观察到社会信号；
- 礼貌拒绝得到约 +0.46，但测试错误地要求绝对中性。这不是算法缺陷：清楚回应、尊重边界本身可以带来
  温和正向变化，正确约束是“不受罚且不产生夸张奖励”。

优化后，五个关系维度只有在至少一个社会信号提供实际证据时才移动；关系更新改为在 `RosterStore` actor
内原子读取—变换—保存，不再依靠有限次数竞争重试；礼貌拒绝的人工标签改成有上限的安全非负区间。
修正后的轨迹语料、单调性、连续性、来源公平、自然日预算和并发 20 条用例全部通过。

## 第五轮：模型漂移与提示词数据边界

范围外的模型数值被引擎钳制，损坏 JSON 在写关系前失败，这两项原本已经安全。新测试发现角色姓名、性格
和兴趣会原样拼入 system prompt，档案中的换行可以伪装成新指令。现在档案字段会先压平空白、限制长度，
再编码为 JSON，并被明确标记为“不可信数据而非指令”；角色个性只能影响偏好和幽默，永远不能削弱同意、
尊重、安全或反操纵边界。对抗档案复测通过。

## 第六轮：重放、检查点和异步完成顺序

- 同一消息由 20 个任务并发重放，最终互动数和修订号都只增加一次；
- 500 步混合关系轨迹每 17 步编码并解码一次，与不中断计算的全部核心数值一致；
- 正向互动和后续伤害以相反的任务完成顺序结算时，最终总分和维度只产生受限的小漂移，最新消息游标和
  对用户可见的最近事件仍按语义时间指向后发生的互动。

连续专项复验和全量回归均通过后，第二代工作链才视为达到下一次成熟迭代门槛。下一轮需要真实、经同意且
去身份化的人工标注对话来校准模型信号；继续添加合成权重组合的边际价值已经低于采集高质量评测证据。

## 第三代工作链：证据—机制—边界—反例

第三代不再把“找到一篇支持方向的论文”当成完成。每个候选机制必须依次通过：

1. **证据定位**：优先读取原始纵向、日记或实验研究，记录样本关系类型、文化与年龄边界；
2. **机制翻译**：只把方向翻译成最小产品假设，不复制论文效应量为游戏系数；
3. **反例先行**：先写应该失败的配对测试，例如“同样披露但是否被承接”“同样修复标签但是否承担影响”；
4. **轨迹验证**：同时检查单次、重复、冲突后恢复、长期沉默和乱序重放，避免只修一个截面；
5. **公平与反操纵**：文化表达、语言水平、简短回复和设立边界不得因新机制受罚；
6. **三轮稳定门禁**：专项默认连续三轮，每轮包含 10,000 次确定性随机输入；之后才运行全量客户端、后端与
   Release 构建。任何一轮失败都回到“反思—最小修正”，不能只重跑碰运气。

### 证据—机制—限制矩阵

| 研究方向 | 产品机制 | 明确不做的推断 |
| --- | --- | --- |
| 披露与亲密受被感知回应性中介 | 披露—回应耦合提高长期沉淀；披露本身仍只提供有限熟悉信息 | 不把长消息、情绪强烈或披露隐私自动当亲密 |
| 新生友谊中互动质量解释数量之外的差异 | 空洞接触不能刷新有效联系时钟；少量优质互动可以超过大量空洞互动 | 不把消息数、在线时长或留存当关系质量 |
| 对好消息的主动建设性回应更有利 | 共鸣 × 回应 × 投入形成小幅协同证据 | 不要求夸张兴奋，也不把低情绪表达视为冷漠 |
| 回应性可以形成逐渐累积的双向循环 | 以指数平滑维护互动质量预期；只有稳定且既往正向才温和帮助信任增长 | 不用一次互动诊断人格，不把稳定敌意误当可靠，不覆盖明确伤害 |
| 长期关系可以低频或休眠 | 衰减只接近历史下限；轻量但有内容的联系可维护锚点 | 不声称沉默完全无代价，也不把老年样本系数用于所有人 |
| 道歉与补偿促进修复 | 修复必须由回应、同理、尊重支持，且保留每日上限 | 不让单个“sorry”标签清空伤害或刷分 |
| 冲突、退缩与不稳定感存在纵向关联 | 未修复张力温和放大后续同类伤害 | 不把伴侣冲突效应量直接套到朋友或所有文化 |
| 回应性的作用强度存在跨文化差异 | 提示词明确禁止国籍系数，并把简短、含蓄、间接表达默认视为中性 | 不建立文化刻板印象表或按国籍校准亲密阈值 |

## 第七轮：有效联系与迁移歧义

### 初始失败

首轮第三代专项 55 项中通过 54 项。连续空洞消息没有建立稳定性或增加关系，但第二条消息把第一条消息时间
误当成“旧快照最后联系”，从而错误建立了有效联系锚点。原因不是阈值，而是新增可选字段无法区分“v1 字段
缺失”和“v2 尚无有效互动”。

### 优化与再测试

关系快照升级到 v2。只有 v1 在第一次结算时允许用旧 `lastInteractionAt` 回填；v2 明确保留“技术接触时间”
与“有效互动时间”的差异。后端同步同时接受 v1/v2，直接构造带历史时间的测试/调试快照仍默认该时间有效。
修复后 55/55 通过。

## 第八轮：回应耦合、积极事件与互动一致性

配对测试固定了三条新性质：被理解和承接的披露比单方面倾诉产生更多信任和长期沉淀；主动建设性回应好消息
明显优于礼貌但被动的回复；稳定性需要多次一致证据逐步形成，突然的质量反转会降低稳定性。稳定性对正向信任
增量的影响被限制在温和范围，不能改变同一证据的正负方向。反思阶段又加入“稳定敌意”反例：可预测性必须
与既往正向质量相乘，否则持续恶劣的互动会被错误当作可靠历史；修正后的敌意轨迹不会加速信任恢复。

## 第九轮：冲突累积、可信修复与文化表达

同样的后续轻视在未修复张力较高时产生更大伤害，但仍受单次 −18 上限约束。只带 `repair` 标签而缺少回应、
同理与尊重的道歉，恢复显著低于承认影响并承担责任的修复。模型提示新增文化表达护栏：不把篇幅、直接程度、
emoji、敬语、热烈程度等同于关心或真诚，也不允许国籍刻板印象。

## 第三代成熟度门禁结果（2026-08-29）

- 初轮 54/55 暴露迁移歧义；版本化修正后 55/55；反思新增“稳定敌意”反例后为 56/56；
- 最终专项连续三轮均为 56/56，每轮含 10,000 次确定性随机轨迹，共 30,000 次不变量检查；
- 客户端全量 360 个测试项通过，动态参数计入设备侧共执行 411 次，无失败或跳过；
- 后端 70 个启用测试通过，lint 与 TypeScript typecheck 通过；v2 关系同步载荷进入集成用例；
- Release 模拟器构建通过，Debug 版本安装并启动到绑定的 iPhone 17 Pro，临时“测试”Tab 可见。

本轮满足“进入下一次成熟迭代”的工程门槛，但没有满足“系数已科学定标”的证据门槛。下一轮最有价值的输入
不再是更多合成组合，而是经明确同意、去身份化并由多人标注的真实多轮对话，尤其包括文化含蓄表达、讽刺、
敷衍式道歉、长期低频友谊和冲突后数周轨迹；在这类数据出现前，不继续扩大新状态或提高惩罚强度。

## 第四代工作链：反事实配对、恢复轨迹与关系自身节律

第四代继续使用“证据—机制—边界—反例”，并增加三项退出条件：同一输入只改变一个机制的反事实配对、
冲突后至少跨五个时间点的恢复轨迹，以及任何个体化时间参数必须有最低样本数、异常值缓冲和硬上限。通信
频率、人格或文化只允许解释差异，不能成为奖惩标签。

### 第四代证据—机制—限制矩阵

| 原始研究观察 | 最小产品机制 | 防止的错误推断 |
| --- | --- | --- |
| 双人日记中每日回应性稳定关联满意度，而每日披露本身没有独立显著效应 | 披露从亲近度直接正向项移到“披露 × 被理解/回应”耦合；安全披露仍可增加有限熟悉度 | 不把字数、隐私深度或情绪强度自动当亲密 |
| 人际关系中的互惠意义随关系类别而变化，严格交换取向甚至可能损害关系质量 | 审阅器禁止要求即时、等额回报，只在上下文明确显示持续利用或漠视时给负互惠 | 不把忙碌、需要帮助、一次没回礼或关系文化差异判为不在乎 |
| 冲突后主动修复有利于恢复；和解行动的效果与降低再次被利用风险有关 | 直接修复和后续可靠行动共享每日恢复信用；同日重复道歉不能继续清空张力 | 不把一句 sorry、表演性道歉或高频消息等同于行为改变 |
| 个体和关系的通信投入模式存在稳定差异，低频关系也可能长期存在 | 学习跨会话有效联系间隔；至少两个样本后才有限调整宽限和半衰期 | 不设统一“几天不聊就掉分”，不让一次长失联永久改写节律 |
| 关系回忆可服务于连接，但伙伴给出的错误推断也会污染记忆 | 分数只调节语气；具体共同经历和个人事实必须有对话或记忆证据 | 不让高好感角色凭空声称一起去过某处或记得不存在的秘密 |

## 第十轮：披露与记忆证据边界

### 初始失败

在保持温暖、礼貌、投入完全相同的配对中，仅把披露从 0 提高到 0.9，会额外增加约 0.182 好感；关系连续性
提示也没有禁止模型用高分补写共同经历。两项都说明第三代虽然增强了“承接”，但仍保留了披露直接奖励和
关系分数替代事实记忆的通道。

### 优化与再测试

披露的正向项改为披露—回应耦合；缺少理解、同理和回应时不会自动增加亲近度，但仍能有限增加“彼此了解”。
关系提示新增事实边界：共同经历和个人事实只能来自实际对话或已提供记忆。配对反例和提示词固定测试通过。

## 第十一轮：互惠边界与冲突恢复轨迹

### 初始失败

从 0.9 未修复张力开始，同一天连续 20 次高质量道歉可把张力降到约 0.00001；相反，一次可信道歉后的五天
稳定、尊重且充分回应的行动完全不会继续修复。算法奖励了“重复声明”，却忽略“后续表现”。

### 反思、优化与第二次失败

修复改为每日最多 2 的恢复信用，直接道歉与后续行动共用。第一次修正后，同日重复道歉保留约 0.722 张力，
方向正确；但五天跟进只把张力恢复到初次道歉后的约 87%，没有达到预设的至少 15% 继续改善门槛。对安全
条件和日额度保持不变，仅温和调整跟进信用强度；第二次复测通过。没有回应、仅语气友好的接触仍不能自动
消除张力。

互惠提示同时改为非即时记账：临时不对称、普通需要和可用性差异不算失败，只有上下文明确显示单方面利用
或持续漠视时才允许负向评价。这一限制比新增“互惠余额”更稳妥，因为现阶段没有双方真实投入的可靠观测。

## 第十二轮：关系自身联系节律

### 初始失败

在最终好感、下限、熟悉度和最后有效联系完全相同的条件下，过去稳定每日联系和稳定每两周联系的关系在
第 18 天投影完全一致，说明时间模型仍把所有关系当成同一节奏。

### 优化与边界

v3 只从相邻有效互动学习跨会话间隔：小于 12 小时的同会话消息不采样；至少两个间隔后才参与投影；间隔
限制在 0.5…120 天，对数空间指数平滑避免单个异常值主导；实际参与宽限的节律上限为 45 天。个体化只增加
有限宽限与半衰期，不直接加分，一年后仍会衰减，十年轨迹仍需单调趋近长期下限。v1 继续一次性迁移旧锚点，
v2 明确保留“没有有效锚点”的语义。

### 第四代循环记录

1. 反例初测：61 项中 55 通过、6 失败，六项均与预先登记的机制缺口一致；
2. 最小修正复测：59/61，通过裸披露、节律、提示和重复道歉，暴露一个旧测试结论过时及跟进恢复略弱；
3. 反思修正复测：61/61；随后补入单次长间隔、同会话消息、v2 空锚点、节律持久化和普通友好不等于跟进等
   反例，再进入三轮稳定门禁。

本轮仍不声称得到真人好感的精确公式。联系节律和恢复系数是有边界的产品参数；在获得经同意、去身份化、
多人标注的真实纵向轨迹以前，不把这些数值用于主动催促、通知优先级、付费转化或用户人格判断。

- 扩充后专项为 64 项，连续三轮均 64/64；每轮包含 10,000 次确定性随机轨迹，共 30,000 次不变量检查；
- 客户端全量 368 个逻辑测试通过，动态参数计入设备侧共执行 419 次，无失败或跳过；
- 后端 70 个启用测试通过、23 个依赖外部集成环境的测试跳过，ESLint 与 TypeScript typecheck 通过；
- v3 严格同步载荷进入后端集成夹具，Release 模拟器构建通过；Debug 已安装并启动到绑定的 iPhone 17 Pro，
  临时“测试”Tab 保留并展示联系节律、恢复信用和新增反例矩阵。

第四代达到下一次成熟迭代的工程门槛。下一轮不应继续凭合成测试无限增加状态维度；优先工作仍是建立经
明确同意、去身份化、多人独立标注的真实多轮与跨周轨迹，并分别测量社会信号一致性、置信度校准、文化
表达误差和长期节律漂移。真实证据出现前，新的个体化只能保持可解释、可删除、有上限且不驱动催促。

## 第五代工作链：认识不确定性、可信修复与支持自主

第五代保留反事实配对和跨日轨迹，同时增加“认识不确定性”门禁：正向推断和修复不得在置信度为零时保留
最低收益；伤害信号则允许有上限的谨慎非对称，但必须明显小于高置信度伤害。新机制仍不得诊断依恋类型、
人格或宽恕倾向，也不把伴侣研究的效应量直接复制为朋友关系系数。

### 第五代证据—机制—限制矩阵

| 原始研究观察 | 最小产品机制 | 防止的错误推断 |
| --- | --- | --- |
| 道歉通过违背后的可信度影响信任，高负面情绪时效果更弱，且不能完全恢复到无违背水平 | 即时修复由既往信任/尊重和未修复张力共同限幅；行为跟进继续走独立、跨日恢复通道 | 不让一句可信措辞重置严重伤害，也不要求角色立即原谅 |
| 违背越频繁、越像会复发，道歉和直接修复越不被认为有用 | 重复伤害降低信任与尊重，从而让之后同样道歉获得更少恢复信用 | 不新增“道歉次数”道德标签，不惩罚没有新伤害的重复说明 |
| 支持的不足和过度提供都可能错配需要；情绪披露后的匹配支持更易被感知为敏感 | 审阅提示明确区分匹配需要的回应与强行解决、淡化、施压或接管 | 不把建议数量、解决速度或替对方做决定当关心 |
| 自主与联结共同有利于建设性关系维护 | 尊重拒绝、先询问需要和不提供解决方案的倾听也可得到正向回应评价 | 不把设立边界、拒绝建议或暂时不求助判为疏远 |
| 模型输出置信度是对社会信号认识不确定性的唯一当前代理 | 正向、维度提升、修复、重要互动和事件叙事按置信度门控；零置信度只记录技术接触 | 不从不确定输出制造共同历史，也不声称置信度已被真实语料校准 |
| 同一互动可能同时包含热情与轻视，简单净分会掩盖安全信号 | 明确轻视拥有独立、有限的成本，并给信任目标设置安全上限 | 不把冷淡语气、不同意见、简短或直接表达误当轻视 |

## 第十三轮：不确定性泄漏与修复可信度

### 初始失败

新增反例首测 71 项通过 64 项，7 项失败且全部对应预先登记缺口：置信度为零的高正向误报仍增加约 0.82
好感；零置信度修复仍增加约 1.15；低信任与高信任快照得到相同的约 1.98 修复信用；严重张力下即时道歉
反而比轻度张力恢复更多（2.00 对 1.10）。跨日重复“伤害—道歉”五轮后，末次道歉信用约 2.00，甚至高于
首次约 1.27。

### 反思与最小修正

最低置信度保护只应保留给明确伤害，不能用于制造亲近或相信修复。正向总分、五个关系维度的上升、修复和
后续行动改为严格乘以置信度；重要互动和事件叙事也必须有实际证据。道歉恢复改为“修复内容 × 历史可信度 ×
当前伤害门 × 置信度”，其中历史可信度由快照中已有的信任和尊重构成，不新增不可解释的人格状态；伤害越
严重，单次言语修复越克制，后续可靠行为仍可跨日继续恢复。

## 第十四轮：混合信号与支持匹配

初测中，一条温暖、投入、富有共鸣但明确轻视的消息仍把好感从 58 提高到约 59.06，说明净分允许“魅力包装”
掩盖不尊重。现在明确轻视具有独立有限成本，并限制当次信任目标；普通分歧和文化表达不受影响。审阅提示也
加入支持匹配和自主边界：支持必须回应实际表达或请求的需要，强行解决、施压、淡化和接管不自动算回应；
倾听、询问需要和尊重拒绝可以是正向行为。

## 第十五轮：节律漂移与异常值复核

在先建立十个接近日频的有效间隔后插入一次 60 天异常空档，典型节律仍保持在 3 天以内；之后连续六次月度
联系才逐步向低频关系适应，且继续受 45 天投影上限约束。该反例在初测即通过，因此没有为了“本轮必须改
参数”而调整 v3 节律算法。当前限制仍是客户端缺少明确会话 ID，只能用 12 小时间隔近似跨会话；未来只有
真实纵向数据或会话语义证明系统性偏差时再升级状态。

## 第五代成熟度门禁结果（2026-08-29）

- 首轮 64/71 的七项预注册失败经最小修正后为 71/71；最终专项连续三轮均 71/71，每轮包含 10,000 次
  确定性随机轨迹，共 30,000 次不变量检查；
- 客户端全量 375 个逻辑测试通过，动态参数计入设备侧共执行 426 次，无失败或跳过；
- 后端 70 个启用测试通过、23 个依赖外部集成环境的测试跳过，ESLint 与 TypeScript typecheck 通过；
- Release 模拟器构建通过；Debug 已安装并启动到绑定的 iPhone 17 Pro，临时“测试”Tab 已加入零置信度
  误报、温暖包装轻视和历史可信度修复反例。

第五代达到下一次成熟迭代的工程门槛，但仍没有取得真实对话上的概率校准。下一轮优先建设经明确同意、
去身份化、多人独立标注且包含上下文的评测集，分别测量“模型说置信度为 0.7 时实际判断正确率”、支持错配、
反讽、修复意图与后续行为的一致性；在获得这类数据前，不把置信度解释成人的诚实程度，也不继续增加依恋、
人格或所谓宽恕能力等不可验证标签。

## 第六代工作链：不确定伤害、叙事证据与行为性修复

第六代把第五代的“伤害侧谨慎非对称”拆细：谨慎下限只属于明确越界与清晰轻视，不能扩散到冷淡、低共鸣、
低互惠等高度依赖语境的普通负面判断。同时复核关系事件与长期纽带，避免无证据的重要性标签制造共同历史，
也避免一次措辞完善的道歉比后续可靠行动更快沉淀成长期关系事实。

### 第六代证据—机制—限制矩阵

| 原始研究观察 | 最小产品机制 | 适用限制 |
| --- | --- | --- |
| [自然情境中的判断信心与准确度可能分离](https://pmc.ncbi.nlm.nih.gov/articles/PMC13280941/)，语境与唤醒会分别影响两者 | 当前 `confidence` 只作为有界认识不确定性代理；普通正负变化都严格缩放 | 不把模型置信度称为真实概率，也不推断用户诚实或人格 |
| [冲突责任归因会影响冲突过程](https://pubmed.ncbi.nlm.nih.gov/11770477/)，关系中的[元知觉准确性](https://pmc.ncbi.nlm.nih.gov/articles/PMC4956493/)具有明显语境差异 | 模糊冷淡在零置信度下不产生伤害；仅明确越界/轻视保留有限谨慎 | 不把不同意见、直接、简短、拒绝建议或文化表达判成伤害 |
| 道歉能促进信任与宽恕，却不能恢复到无违背水平；后续行为是独立可观察阶段 | 道歉继续即时降低张力和恢复部分好感，但长期下限沉淀按修复强度限幅；跨日可靠行为正常沉淀 | 该系数是产品安全边界，不是从实验效应量复制的真人公式 |
| 自主支持与指令式支持不同；指令式帮助可有实际价值但不自动提高关系质量 | 审阅提示明确要求协作帮助保留对方选择，并允许尊重地分歧或拒绝建议 | 不否定实用建议，只禁止把“替对方决定”自动算高回应性 |
| 短期支持方式波动可能反映适应，而非关系不稳定 | 反例交替两种合宜支持方式，并与正向/轻视反复轨迹配对 | 不新增固定支持风格或人格标签 |

## 第十六轮：安全非对称的作用域

### 初始失败与反思

预注册的零置信度冷淡反例仍把好感从 10 降至约 9.43，原因是普通负向总分、五维负向更新和张力都共享了
0.35 的安全下限。另一个全零社会信号虽然不改变分数，却因 `significance = 1` 写入一条关系事件。两者分别
把认识不确定性误作伤害、把标签误作事实。

### 最小修正

普通负面总分现在严格按置信度缩放；关系维度只按“真实置信度”与“明确越界/轻视的有限谨慎量”两者较大值
更新；张力拆为普通负面、明确越界和清晰轻视三条通道。关系叙事则必须先通过实际证据门。高置信度真实伤害
与低置信度明确越界原有安全测试继续通过。

## 第十七轮：即时修复与长期纽带的时序

### 初始失败与反思

在同一受损快照和完全相同的正向社会质量下，带道歉的消息将长期下限提高约 0.275，不带道歉但代表可靠
行为的互动只提高约 0.214。即时修复额外收益被完整写入长期纽带，等于把一句话过早当成已经兑现的改变。

### 最小修正

保留道歉对当前好感和张力的作用，但长期沉淀额外乘以随有效修复强度下降的门。可信道歉仍传达关系价值，
不会被归零；之后可观察、跨日、无新增伤害且充分回应的行动继续通过既有通道恢复张力并正常沉淀。没有新增
“是否原谅”或人格状态。

## 第十八轮：支持自主与适应性波动复核

审阅提示补充三个边界：指令式建议可能实用但不自动等于关系回应；协作帮助应保留对方能动性和选择；尊重地
分歧或拒绝建议仍可支持自主。交替“倾听陪伴”和“征得同意后协作解决”的跨日轨迹，其稳定性和好感均高于
交替正向与轻视的轨迹；该反例初测即通过，因此没有修改稳定性权重或强迫每段关系保持同一种支持风格。

## 第六代成熟度门禁结果（2026-08-29）

- 预注册首轮为 71/75，四项失败分别对应模糊负面误伤、无证据关系事件、道歉过早沉淀和支持自主提示缺口；
  最小修正后专项连续三轮均为 75/75，每轮仍包含 10,000 条确定性随机轨迹，共完成 30,000 次不变量检查；
- 客户端全量 379 个逻辑测试通过，动态参数计入设备侧共执行 430 次，无失败或跳过；
- 后端 ESLint、TypeScript typecheck 通过，70 个启用测试通过、23 个依赖外部集成环境的测试按预期跳过；
- Release 模拟器构建通过；Debug 已安装并启动到绑定的 iPhone 17 Pro。临时“测试”Tab 已增加不确定冷淡、
  无证据重要性和言语/行为长期沉淀反例，并将对应断言纳入一键回归矩阵。

第六代达到下一次成熟迭代的合成证据门槛，但仍不能声称模型置信度已经校准，也不能把伴侣、实验博弈或临床
情境中的系数直接外推到旅行中形成的友谊。下一轮优先级保持不变：在明确同意、可撤回、去身份化的前提下，
建立由多人独立标注的真实上下文对话与跨周行为跟进数据，分别测量普通冷淡/明确轻视的区分、建议与自主支持、
道歉意图与后续履行；真实数据未到位前不新增依恋类型、宽恕能力或人格诊断状态。
