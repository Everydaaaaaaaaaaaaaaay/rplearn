# “我的”页场景图片生成约束

## 唯一母版

所有后续图片优化必须始终使用以下无 UI 原图作为唯一编辑目标：

`App/Assets.xcassets/profile_modern_travel_desk.imageset/profile_modern_travel_desk.png`

禁止以上一轮生成图作为下一轮输入。每次修改都应回到母版，并把已经确认的设计要求重新写入完整提示词，避免桌面纹理、地图、物品轮廓和光照发生代际漂移。

## 必须保持的内容

- 825 × 1906 的构图、裁切与视角。
- 桌面木纹、世界地图、路线、纸张和全部物品的几何与材质。
- 原有物体位置、比例、阴影、皮革纹理、缝线和纸面图表。
- 左上角相片圆圈内的头像必须平面嵌合，不能作为全息入口处理。

## 当前 UI 方向

- 图标和文字使用克制的冷白全息投影，仅带极轻冰蓝色偏。
- 不使用石墨、金属或其他现实固体材质。
- 全息层与承载物保持相同透视，但悬浮约 20–25 mm。
- 通过清晰全息层与承载物表面失焦光迹的视差表现高度。
- 不生成按钮底板、发光矩形、边框、光柱或强烈霓虹效果。
