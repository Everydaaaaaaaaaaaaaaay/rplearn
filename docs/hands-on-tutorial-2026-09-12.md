# 选角后的上手练习

选定初始旅伴 → 长按气泡翻译 → 点词查义 → 公园相遇、分支与加好友/道别 → 简短探索提示 → 保存正式旅伴并结束首启。可以跳过单步或整个教程。正式选人保存失败时保留教程并提供重试，不重复创建练习好友。

设置 → 上手练习可随时重玩；完成和跳过只关闭展示，不重新选角。新手教程聊天使用用户选择的旅伴，重玩使用本地目录中的初始旅伴。

教程仅持有 CharacterDTO、只读词典与语法库、完成回调。没有聊天、好友、资产命令接口，没有后端或 AI 依赖。整句翻译、对话及相遇分支预置在代码中；相遇没有十五秒等待，所有临时状态随着视图销毁丢弃。唯一持久化动作是首启结束回调保存用户选定的正式旅伴，重玩回调不写入账号。

复用 DesignSystem MessageBubble 原生长按菜单、TappableText 和 DictKit 词典浮窗。禁用词典 AI 回退、在线例句翻译、系统翻译回退和收藏写入。可选朗读使用设备系统 TTS，不调用云端；它是教程的即时朗读，正式聊天的语音引擎不变。教程只展示翻译和播放菜单，不开放需要付费请求的语法解析。

咕咕温和引导、句尾带“咕”，嘎嘎轻松接话、句尾带“嘎”。不指导用户该如何聊天。剧情选择配中文释义，地图机票和更多剧情留给用户探索。

验证：新手完整练习（真实长按菜单、词典弹窗、分支、练习加好友）、整段跳过和保存失败重试均通过 Xcode UI 测试；重玩与最终视觉验证见本轮 xcresult。

最终验证：iPhone 17 Pro 重玩与完整练习通过（20260912T131806Z-26665）；iPhone SE 深色完整练习通过（20260912T131947Z-27165），截图确认气泡、双语相遇和底部按钮可用。真机签名构建与覆盖安装成功。仅客户端变化，无后端部署。
