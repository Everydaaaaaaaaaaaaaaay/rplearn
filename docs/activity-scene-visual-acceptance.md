### 已发生问题的复核重点

- **S1 临窗视角**：室内外属于同一观察者；按近中远距离检查人物尺度、地面和窗沿遮挡。
  裁切不能修复机位高差，不能一律露脚或截腿。
- **S2 摊位与住宅出入**：桌台、顾客、摊主、人行道及车道关系可理解；住宅从门槛到街道
  有正常落脚与通行空间。不能假定画外有平台，也不强制所有场景加前院。
- **M1 自然速度**：不靠慢放、倒放、冻结或复制人物延长视频。有慢放疑问时比较原片、
  输出与 App 中同一动作的耗时并查时间映射；播放器 rate=1 不是自然步态证据。
- **M2 稳定性**：固定视点下建筑、路缘稳定，无抖动、呼吸缩放和形变。有疑问时跟踪不同
  位置的固定参照，比较原片与稳像结果；不能用模糊盖掉问题。
- **M3 循环**：无黑帧/冻结与无瞬移/叠化/环境跳变分别判断。报告重复周期，达到记录中的
  观察窗口；不能事后缩短窗口或把可见接缝改称“已知限制”放行。
- **U1 入口**：最小支持屏幕上可发现、可读、可点；投影不压扁字形，命中区域至少
  44×44pt 且相邻不误触。检查裁切、大字和减少动态；沿用共享按压反馈，不额外增加等待。

## 生成、修复与结论

- 母版采用独立生成；失败后修订构图重新生成，不连续图生图或生成式局部修补。
  保留完整提示词、源图和哈希。确定性裁切、调色、编码可用，但不代表结构已修复。
- 定位问题所在的母版、素材、合成或 UI 层，修复后逐项复核开放用户问题及受影响范围。
  换母版重新看完整新图。同类错误连续出现时补实拍参照或简化构图，不盲目重抽。
- 记录“通过 / 失败 / 待证实”，不适用项合并说明即可。空间、用途、许可、动态或交互
  存在未解缺陷或关键未知时不放行；纯审美建议不要求反复重做。
- 用户拒收即撤销对应版本放行；未经复核不关闭问题。拒收/未验证资源不作为最终交付，
  暂用原型需明确标注。自动测试通过不能替代真实性和视觉检查。
