历史首页拒收记录（2026-09-10，已由上述独立重制闭环）：伦敦 H-01、开普敦 H-02 退回，其余 13 城待证实；详见 [15 城真实性复核](home-city-scene-realism-audit-2026-09-10.md)。首页相关施工仍须读取历史问题和新版本验收记录；旧点击/投影测试不能恢复旧图放行。

适用城市活动及后续照片式情景母版、视频合成、物体锚定 UI。
每版填写 [验收记录模板](templates/activity-scene-acceptance-record.md)。
这是制作和放行规范，不是自动图像校验器，不代表当前母版已经通过。

## 每次施工必须执行

开始设计、选素材、生成、合成、调整入口或验收前，先完整阅读本规范、末尾拒收登记和
该场景最新验收记录。新任务不能只沿用上一轮“已通过”的口头结论。
先把仍开放的问题编号带入本轮记录，再按G0→G4执行；完成时逐项提供修正证据。
本规则不授权顺手改动未被本次任务要求修改的画面、素材或交互。

## 不可妥协的原则

- 先有正常、可理解、可使用的场所，再安排入口。不能为凑三个按钮增加三件奇怪物品，
  不能为视频窗口杜撰建筑；减少入口、换锚点或素材优于扭曲现实。
- 真实参照必须实际看过，记录观察证据；搜索摘要、提示词、生成器自述都不算证据。
- “现实中可能存在”不等于画面能清楚说明。需要补充隐形通道、隐藏房间或特殊家具
  才能解释的构图，按表达失败退回。没有看见柜门不等于必定没有，但也不能直接放行。
- 单张图不能证明所有隐藏结构。允许“无法判断”；关键结构无法判断即阻止放行。
  不伪造精确尺寸，不用自信口吻掩盖不确定性，也不承诺一次自检能保证绝对真实。
- 母版只用一次性独立生成。失败后修订构图再全新生成，不用旧稿图生图、生成式局部修补、
  去 UI 或连续重绘。保留每版图、完整提示词和哈希，防止材质漂移及版本混淆。
- 漂亮材质、虚化、透视特效、构建成功均不能抵消逻辑错误。用户不是首次质检员。
- 真实视频只证明原拍摄内容来自现实，不证明把它放进另一张图后的机位、空间和速度合理。
- 功能入口首先必须可发现、可读、可点，其次才是透视贴合。不能用“数学共面”抵消压扁的小字。

## 状态与硬门禁

草案 → 参照/空间通过 → 原图待审 → 原图通过 → 合成通过 → 应用通过 → 可交付。
任何阶段可退回或待证实；不能跳关。换母版必须重新走原图及后续检查。

| 等级 | 判定 | 处理 |
| --- | --- | --- |
| 阻断 | 空间矛盾、尺度/用途不成立、无法操作、关键关系无法判断、来源许可不清 | 禁止进入下一阶段 |
| 待修 | 局部结构/反射失真、接缝跳变、焦点不一致、入口错位或不可读 | 修正复验，不作为完成稿交付 |
| 可选 | 不影响真实性和使用的审美偏好 | 记录，不以此反复盲目重生成 |

不以平均分抵消错误。每个必查项填写“通过 / 失败 / 无法判断 / 不适用”并附证据；
不适用要解释，未查不等于通过。零阻断、零待修且证据完整才可放行。
用户明确拒收立即撤销通过状态，不得继续作为最终资源安装或提交。
撤销总放行，不只是把新的缺陷写成“已知限制”同时保留“可交付”。
局部清晰度或代码测试曾通过可以保留为历史事实，但不能代表整景通过。
原型暂用拒收图必须标为未验收，原型截图不能作为交付证据。

## G0：完整真实场所与物品参照

- 至少查看一张完整真实场所照片，覆盖主要空间关系；有疑问则补相应角度直到关键关系明确，
  不用大量无关照片凑数。商品图只补物件结构，不替代场所参照。
- 每件清晰核心物品有实物结构依据，特别看大小比例、支撑、开合和拿取方式。
- 记录原始页面、所看图片/角度、观察事实与设计推断的区别。参考不等于可转载；
  实际进入应用的媒体另存许可依据。生成图不能当真实参照。

## G1：先做空间方案与使用演练

先写简短空间说明，必要时画平面/侧面草图，而不是直接生成效果图：

- 相机站位、朝向、视线高度；顾客、店员、桌台、墙体、街道的相对位置。
- 地面连续性与动线；门通哪里、窗属于哪面墙、窗台/墙厚/室外地面如何对应。
- 视平线、主要透视方向及遮挡。平行关系本身不是错误，应结合机位、道路和窗台高度判断。
- 尺寸是有出处的值或明确的设计假设，不能从未知照片假装精确测量。
  交叉检查近远书籍、袋子与柜台、柜台与人行空间的比例。
  不要求四条桌腿全部可见，但承重和接地关系必须可理解。
- 对每件近景物品回答：是什么、为何在此、谁用、如何取放/打开/清洁、用完放哪里。
- 演练顾客走近、浏览、取物、付款、离开，店员服务与补货。
  若需要穿柜、越墙、悬空或穿玻璃，重做布局；不能为了社交强迫不自然的站位。
- 提前核对动态素材与机位/光线/地面是否相容。窗户不是固定必需结构；
  不为嵌入视频发明高门槛、悬空档口和无法解释的附属房间。

输出允许生成的构图约束及禁用元素。此前被指出的问题逐项转成反例检查。

### S1：室内视线与窗外视角必须属于同一个观察者

- 明确坐着还是站着、眼睛相对桌面/窗台的位置、室内外地面高差、街道与窗户的距离。
  为临窗场景画简短侧视关系，并用相近机位的真实场所照片支持；杯盘参考不能代替机位参考。
- 至少选近、中、远三个人物位置检查：头部高度、全身尺度、脚下地面、应被窗台/墙体遮掉的部位。
  坐姿场景不能配低贴地仰拍的街景，让近处路人的全身反复暴露，产生室内下沉到地下的感觉。
- 不是“一律截掉所有小腿”：远处全身可见可能正常，遮挡必须由距离、视线及窗台共同决定。
  不能为了修正上一次“丢路面”而要求所有路人的脚都可见。
- 窗口下沿不是室外地面的标定线；看见路面不等于高度正确。检查视平线和遮挡，而非只对齐矩形。
- 裁切/单应性变换不能把贴地机位变成坐姿机位，也不能恢复新的三维遮挡。
  不相容就换相近眼高的固定机位素材或重做场景，不用拉伸、移动窗底、加墙来补谎。

### S2：摊位必须有可理解的站位与正常通行空间

- 先标出桌台、用户、摊主、近侧地面、路缘、人行区、机动车道及过街区域的相对位置。
  桌台与人行空间必须属于同一个可信场所，不得像悬在路上或摆在十字路口中央。
- 有车或斑马线本身不是错误；关键是它们是否把近景桌台定位到了车道/过街动线上。
  “其实在近侧人行道”必须由画面或同机位参照支持，不能只写一句话当证据。
- 按整个片段检查车辆经过、近处行人绕行和遮挡，不能只挑无车首帧通过。
  桌台支撑和顾客站立处不一定全入镜，但不能依赖虚构的画外平台才成立。
- 选择有明确步行区、店前退让空间或正常市场摊位关系的素材；如果无法证明当前组合的站位，退回选材。

## G2：无 UI 母版两遍检查

### 住宅入口专项：从门内一直演练到街道

- 必须分别核对本住宅的门槛、落脚平台或门前铺地、人行路线、路缘与车道；对街台阶/前院正确不能代替近侧正确。
- 临街、无前院并非天然错误；具体住宅类型需要完整实景参照。不得为了“显得真实”给所有城市硬加同一套前院。
- 闭门遮住地面不是证明空间成立的方法。廊柱、栏杆位于视口中央时，核对平台深度、门扇扫掠和实际出口，不假定画外总有路。
- 门脸特写、风格旅游页、模型提示词不证明室内与街道属于同一机位；真实参照须覆盖所争议的空间关系。

第一遍不靠提示词补充解释，只看整图和手机尺寸：

- 能否迅速理解场所、自己站位、桌面与地面、门与窗？
- 物品是否普通且有用途，是否像为了按钮摆的巨大道具？
- 不看提示词也要能认出物品。写了“菜单”但画面像支起来的书仍算失败；
  同类道具反复出现先检查是否为凑入口。入口可以锚定正常空间，不必一按钮强配一件道具。
- 顾客和工作人员是否有可理解的站立与通行空间？

第二遍按上左、上右、中左、中右、下部固定顺序，原生分辨率检查并保存问题区域：

- 建筑：墙体连续性，门窗/台阶/窗台/道路高度，旁门、后室与临街面的关系。
- 家具：桌沿、厚度、支撑、接地、可达性；不能融进台面、无支撑悬空。
- 物品：书页/书脊、卡片与容器的用途、纸袋折边/提手、夹具连接、面包尺度。
- 操作：柜门、滑轨或开放背面是否可识别，店员能否接近取物；不能只猜背后有门。
- 光学：玻璃透明性、反射方向/内容、遮挡和光源是否一致，有无重复物品或假开口。
- 透视尺度：同类远近物件无矛盾，共面边线与接触关系合理，不用 UI 遮错误。

关键近景保留全图位置及局部截图。“说不出的怪”先登记待证实，再与实拍对照，
拆成尺度、支撑、用途、透视、光照问题；不能因为暂时说不清原因而略过。

### 焦点与虚化

- 近景交互物品清晰；中景保留解释通道、桌台和墙体的结构。远景不默认失焦。
  若整个远景来自实拍视频，应先保留原生清晰度；不为掩盖不存在的生成错误统一模糊。
- 记录生成器实际输出尺寸、有效物体占像素、运行图尺寸和目标屏幕像素。
  大面积透明留白会挤占细节预算；高清请求或文件体积不能证明书封清晰。
  以原生局部和最终屏幕检查轮廓，禁止先缩小后放大并称“高清修复”。
- 这是选择性的摄影表达，不宣称人眼具有固定焦深，不预设万能模糊半径。
- 虚化随深度与焦平面变化，窗框/近景边缘不能一起糊掉；同深度静态与动态清晰度一致。
- 建筑大轮廓、地面高度和人物尺度仍须正确。检查原视频和合成前的结构依据；
  本就失焦且不能辨认之处标未知，不虚构一张清晰版本证明它正确。
- 禁止用虚化掩盖取物口缺失、悬空、身体消失、物件融化、瞬移或房间矛盾。

## G3：动态合成

- 原图通过才制作最终合成。核对原图远景、玻璃倒影与替换视频，
  不得直视与倒影出现两条不相容的街；无法合理融合就换构图/素材。
- 查机位、视平线、人物大小、步行地面、曝光、色温、景深、玻璃反光及窗框遮挡。
- 换窗户宽高比必须同步调整视频裁切和静态底板；保持人物比例及符合S1的地面/遮挡关系，
  不把更宽的窗户当作拉伸旧视频的理由。去掉模糊后重查接缝，旧模糊版验收不继承。
- 正常速度完整看至少两个循环，另慢看接缝。覆盖人物过边缘、多人交叉、车辆与阴影经过。
  记录真实片长、观察时长与接缝时刻。播放器未中断不代表画面自然。
- 不冻结等待、倒放、复制人物，不以变速或随机跳片伪装多样性。
  有限片段会重复，必须报告周期；目标观察窗口内重复出戏就换更丰富/更长素材，
  不能宣称无限随机。目标观察窗口在制作前写入记录，不事后缩短以通过测试。

### M1：自然时间，不用慢放换时长

- 禁止为了延长循环而故意慢放；不能靠插帧、重复帧或拉长时间戳变相延长人物动作。
- 分别核对原片、处理后文件和App实际播放。记录源片起止PTS/时长、输出时长、
  帧率/时间基、转码时间映射、播放器速率。说明裁掉和衔接的区间为何导致时长变化。
  帧率转换应保留原始时间；不是把相同帧数改用较低fps播放。
- 24fps、播放器rate=1、没有显式setpts放慢，均不能单独证明真人自然速度：
  原片可能已慢放，解码/编码时间基也可能改错；播放掉帧/卡顿是另一类问题。
- 用同一可识别人物走过固定参照物的片段对比三个版本的真实耗时，同时看步频、摆臂及重心变化。
  远处人物屏幕位移小不一定慢放；不能只凭像素速度判定，也不能以距离为由忽略异常步态。
- 原因未确定时写“用户报告慢放感，原因待查”，不能承认或否认故意变速。
  原片本身动作不自然也不能因为原样播放就放行，应换素材。

### M2：固定视点，不接受背景地震

- 静态前景搭配固定观察者时，视频中的建筑、路缘、窗线应稳定；自然人流不等于镜头乱动。
  不得存在持续平移/旋转抖动、呼吸式缩放、局部波浪形变，或接缝处建筑跳位。
- 原片与稳定处理结果并排看。至少跟踪两个不同位置/深度的静态参照，区分相机运动、
  移动物体、配准误差和播放器卡顿；记录明显抖动的时间点，不能把行人当固定参照。
- 先选固定机位素材。需要稳定时复查裁切余量、边缘露底、视差和局部形变；
  “用了防抖算法”不是通过证据，稳像后变形或更抖就退回，不用模糊盖掉。
- 在最终手机显示尺寸正常播放检查整体稳定性，并逐帧看疑点。
  数值误差低但肉眼仍明显抖动，仍不通过；若刻意设计镜头运动，须先另行确定前后景一致运动方案。

### M3：循环自然性与播放连续性分开验收

- 第一项查是否冻结、黑帧、停顿；第二项查是否有人瞬移、重影淡出、动作重复和环境跳变。
  第一项通过不得替代第二项，已声明有限循环也不能豁免可见不自然接缝。
- 全程至少覆盖两个实际循环，另查接缝与最拥挤/近距离运动段，不能只看首尾静帧。
  工具只能抽帧时如实注明未完成连续视觉审看，不把录了视频或计时等待写成看完视频。
- 自动播放状态测试、抽帧和原速观看分别记录。明显叠化人影属于待修，不改名为“能力边界”放行。
  无法自然衔接就换更合适素材或重新设计动态范围，不冻结、不倒放、不靠慢放拖长。

## G4：本工作树应用验收

- 对照无 UI 原图、静态合成、动态合成、最终 UI 四层，明确问题在哪一层产生。
- 只操作本工作树模拟器，记录设备/尺寸/构建。模拟器检查不能写成手机实测。
- 图文整体贴合物品平面、投影居中、大小合理、阴影/溢光克制，不改坏物品来迁就入口。
- 检查裁切后关键桌沿或通道是否消失，覆盖主要支持尺寸和最易裁切的尺寸。
- 查点击、按压、切场景、返回、对话期间动态、前后台恢复、静态/减少动态及失败降级。
- 自动测试验证资源、路由、几何及播放状态，不能证明现实逻辑或视觉自然。
- 保存最终截图和含接缝的正常速度录屏，列通过及未测项目；未完成的验证不能写成完成。

### U1：投影之后仍然是清楚、可发现的按钮

- 复用首页/我的的材质和交互路径，不等于复制任意四边形。先审最终屏幕上的字形、图标和尺寸，
  再审与物体共面；正确的四角映射不能证明视觉可用。
- 每个入口与同样图文的正视版本对照，检查图标轮廓、中文字形、纵横压缩、倾斜、笔画和间距。
  明显压扁、扭曲、挤成细条或需要放大才能读，直接退回；不能靠加粗、加溢光掩盖。
- 图标和文字保持统一视觉中心及比例，尺寸跟物体适配但不能无下限缩小。
  必须按最小支持手机的最终显示大小检查，不能拿高分辨率放大图证明好读。
- 本项目触控检查底线：屏幕坐标中的有效命中区域至少44×44pt，边缘能点、相邻入口不误触；
  这只是命中底线，不是可辨识性证明。巨大透明热区也救不了看起来像装饰的小图案。
- 未触摸时就应能辨认“这里能做什么、这是入口而非印在物体上的装饰”。
  结合清晰行动文本、合理大小、对比和适度层次判断；按下后才有反馈不能代替首次可发现性。
- 过陡平面或过小物体承载不了图文，就换更正面的锚点、扩大可用区域或减少入口。
  如需改为更朝向镜头的悬浮面片，应明确其空间方案并验收，不悄悄退化成随屏幕漂浮的2D标签。
- 在实际轻点、长按、取消、返回中复查反馈；沿用已确认的共享0.12秒按压流程及交替隐现，
  不为弥补视觉不明显私自延长跳转等待。大字/减少动态模式仍保留可读、可操作的入口。

## 发现问题 → 修正 → 复验

1. 登记问题编号、版本哈希、区域/时间点、观察事实、违反规则、严重度和证据。
2. 定位是母版结构、素材选择、投影遮罩、焦点调色还是 UI；不直接猜加模糊能修复。
3. 母版空间/物件错：回 G1，修订结构约束后独立全新生成。
   素材不相容：换素材并复核 G1。代码裁切/遮罩/UI 错：确定性改代码，复验受影响阶段。
   非生成裁切/调色/编码可用，但不能冒充原图结构修复。
4. 不覆盖拒收版，记录新旧差异和为何有效；提示词与图的哈希必须对应。
5. 逐项复验旧问题，并重新扫查完整新图，避免修窗户却新增家具错误。
   受影响的动态、反射、裁切、入口全部重验，旧截图不能证明新图通过。
6. 同类结构错误连续两版出现，停止堆提示词重抽：补完整实拍参照、简化构图、减少道具，
   或放弃该场景/素材组合。若需改变用户确定的范围，先说明并请求方向。
7. 有修正证据及回归结果才关闭问题。保留未解项，不能以用户尚未反馈视为认可。
