# 五城回声：旅程与角色解锁设计

> 状态：当前实现（2026-07-26）。运行时配置以
> `Packages/LingoKit/Sources/DomainKit/Story/MainlineCatalog.swift` 为准，本文记录产品意图和改动入口。

## 核心设定

玩家在一段跨越年代的录音中发现“声音地图”。地图记录的不是景点，而是陌生人如何在不同语言和生活背景中听见彼此。玩家与三位原有主角沿线收集城市回声，在新加坡把三份线索拼成完整录音，并为下一位旅行者留下自己的声音。

主线固定经过 5 座城市：

| 城市 | 剧情作用 | 关键场景 |
|---|---|---|
| 伦敦 | Oliver 与旧旅行札记的线索 | 雨中旧书店 |
| 墨尔本 | Ruby 与来自海岸的录音 | 清晨海岸 |
| 纽约 | Marcus 拍到声音地图符号 | 街头与地铁 |
| 开普敦 | 汇合前期线索、确认跨洋广播 | 信号山与桌山 |
| 新加坡 | 三位伙伴会合、完成声音地图 | 雨后街区与超级树 |

主线章节必须按路线顺序完成；只有玩家身处当前目标城市时，主线入口才可打开该章节。

## 初始选择与三条路线

初始选择同时确定第一位伙伴、初始城市、前期章节和后续两位伙伴的相遇顺序。

| 初始伙伴 | 路线 |
|---|---|
| Oliver | 伦敦 → 开普敦 → 纽约（Marcus）→ 墨尔本（Ruby）→ 新加坡 |
| Ruby | 墨尔本 → 开普敦 → 伦敦（Oliver）→ 纽约（Marcus）→ 新加坡 |
| Marcus | 纽约 → 开普敦 → 墨尔本（Ruby）→ 伦敦（Oliver）→ 新加坡 |

首选角色在引导完成时立即加入好友；其余两位角色在抵达对应城市并完成主线章节后加入。主角色仍只有 Oliver、Ruby、Marcus 三位，开普敦的 Amara 是剧情引导者，不进入主角色名册。

## 支线城市

主线之外配置 8 座城市：

- 都柏林：文学、现场音乐与海岸小火车
- 爱丁堡：古城、城堡与山丘
- 温哥华：海港、森林与多元街区
- 奥克兰：火山地貌、海湾与岛屿
- 内罗毕：城市生活、国家公园与创意社区
- 雷克雅未克：地热、北大西洋与极光
- 里斯本：电车、山城与法朵
- 东京：街区文化、庭园与夜间城市

所有 13 座城市均不在中国，并拥有 `city_backdrop_<regionID>` 场景素材或既有同规格素材。

## 剧情入口与城市故事

首页统一使用“剧情”入口，进入后再选择两类内容：

- **主线剧情**：五城连续旅程，按当前角色路线顺序推进；
- **城市剧情**：13 座城市各一篇独立在地故事，首次抵达对应城市后解锁，需身处当地开展或重温。

城市剧情不参与主线路线判定，也不改变三位主角的解锁顺序。伦敦、墨尔本、纽约沿用已有进度 ID，避免升级后丢失玩家完成记录；其余十城使用 `city_<regionID>` ID。全部城市剧情完成后奖励 120 金币，客户端脚本与后端奖励白名单必须同步登记。

## 地图引导规则

地图底部不再投影“当前选中的城市”，而是投影旅程状态：

1. 玩家身处当前必经城市：显示“继续主线”，跳转对应章节。
2. 玩家不在当前必经城市：只显示下一座指定主线城市。
3. 主线完成但仍有未解锁支线：按路线配置优先级显示最多 4 座未到访城市。
4. 所有城市已解锁：显示可免费重访的支线城市。
5. 没有可推荐城市：显示完成回退文案，引导返回主线或等待新内容。

`JourneyMapGuidance.travel.regionIDs` 是布局的唯一输入：

- 1 个地区：全宽单卡；
- 2 个地区：等宽双卡；
- 3 个及以上地区：紧凑横向吸附滚动。

未到访城市首次前往需要机票，并签发一张该目的地唯一的首次抵达纪念票根；已解锁城市往返免费且不再重复生成票根。地图初始视野会同时容纳当前城市和引导目的地。
点击任意城市标记后，操作按钮在标记下方原位展开：已解锁城市显示“前往”，未解锁且没有可用机票时显示“购买机票”，已有适用机票时显示“使用机票”，当前城市显示不可点击的“已在这里”。

## 开发者配置入口

- 城市角色、坐标、活动：`App/Resources/regions.json`
- 主线路线、目标文案、支线推荐顺序：`MainlineCatalog.journeys`
- 主线脚本：`App/Resources/Stories/mainline_*.json`
- 城市剧情目录：`CityStoryCatalog.chapters`
- 城市剧情脚本：`App/Resources/Stories/city_*.json`（三篇兼容旧进度的脚本仍使用 `mainline_*_2.json`）
- 城市活动：`regions.json` 中每城固定配置 5 条路线；每条路线包含类型、预计时长、独立邂逅率与普通探索见闻
- 城市主题色：`DSScenePalette.city(_:)`
- 城市背景：`App/Assets.xcassets/city_backdrop_<regionID>.imageset`
- 首页入口：`App/Assets.xcassets/home_mainline_<regionID>.imageset` 与
  `home_activity_<regionID>.imageset`
- 地图布局演示：启动环境变量 `UI_TEST_MAP_GUIDE=single|two|multiple|complete`

调整路线时必须保持每条路线恰好包含 5 个不重复的主线城市，并同步更新 `MainlineCatalogTests`。
