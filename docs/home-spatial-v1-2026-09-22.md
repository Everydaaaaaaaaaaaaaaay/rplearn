# 活动首页空间拖动 v1（2026-09-22）

用户确认“我的”页效果后，要求扩展到活动页。本版沿用相同的直接拖动、非线性阻力、
松手回弹和中途重新抓取，将活动首页转换为人工深度标定的 2.5D 视差。

## 素材与实现

- 原有十五城 JPEG 均未修改，来源、版本、哈希及母版验收沿用
  [首页背景重制记录](home-city-scene-replacement-2026-09-10.md)。没有新增生成图片。
- 对照当前十五城整图，分别记录门内远景矩形和室内地面起点，参数位于
  `HomeSpatialGeometry.calibrations`。它们是小幅视差的人工近似，不是三维测绘或空间照片数据。
- 门外远景深度系数最低，门框/墙面居中，地板向观察者渐近；过渡使用平滑函数，避免撕裂。
  原图、入口文字、每层投影光效和命中四角使用同一深度函数。静止时保留原构图与点击范围。
- 相机控制与背景纹理网格下沉到 DesignSystem；两个 Feature 不互相导入。
  “我的”页原深度参数不变，只调用共享实现，专项测试同时回归。
- 城市切换通过资产标识重建纹理/网格并复位视点；短屏仍采用原有统一画布适配。
  减少动态、退出页面、后台及 Metal 初始化失败继续使用原有静止降级。

## 结论与未测范围

可供用户体验的试验版。沿用本会话已确认的 Device Hub Computer Use 连接超时限制，
以专项交互测试和模拟器截图补充验证，不声称人工连续拖动审看通过。
其他城市的运行时逐城视觉、真实小屏、真机帧率及减少动态系统开关操作仍待复核。
不把所有城市的数学验证写成全部视觉验收；不支持大角度绕看或恢复照片中被遮挡的内容。
