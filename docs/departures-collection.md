## 英语与声音

- 全篇英文台词配逐框中文辅助，单框上限 65 字符，实际 Core ML 输入上限 70，表达标签计入上限。
- 玩家回应和选项无配音，避免替玩家指定声线。旁白只配英文，中文可显示或隐藏。
- 固定人物选角；根据已写出的场景配置速度和停顿，不在孤立关键词上随机猜情绪。
- 各句制作四个候选，先检查文本完整与波形，再选择节奏、响度居中且避免过高瞬时峰值的候选。自动筛选不等于人类情感评分。
- 轻微角色增益和全局恒定增益保留动态，目标约 −22 LUFS；避免为了“情绪”普遍加混响、变调或假笑。
- 查词、历史、后台暂停；恢复预制音频时继续中断位置。完成的句子不重播，换页和退出不会留下旧完成回调。

制作方法、真实统计和验证证据见 `verification/departures-voices.md`。

## 接入与未宣称的能力

入口为首页 → 剧情 → 出发之后。新目录沿用游客仅起始城市、城市篇到访范围等规则；不添加开发期无限权限。旧内容 ID、已完成记录、奖励与联系人不被新篇映射覆盖。新篇先使用独立、本设备、按用户命名空间隔离的进度；此轮不宣称跨设备同步、长期关系写入或新增正式奖励。

伦敦保留专属美术。其余十九篇本轮是**完整双语分支、声音及可玩接入**，画面使用已有城市背景；没有把通用城市背景冒充专属人物立绘或完成的逐场分镜。新增角色、室内机位、动作插画、表情母版与真机性能验收属于后续独立美术制作，不在这轮“按声音样板完成其余剧情”的交付里虚报完成。
