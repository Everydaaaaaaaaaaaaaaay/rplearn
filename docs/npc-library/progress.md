## 资产与背景修正

初始 81 张旧候选审查后保留 21 张，移除 60 张相似或不适合头像的图。v5 共生成 216 张，逐图查看圆形裁切和灰度近邻后保留 179 张、淘汰 37 张，总计 200 张。97 张旧图及新候选被排除，项目中的淘汰副本已删除，来源和理由保留。原始生成文件仍在工具原始输出位置。

11 张早期纯底图已回修为明亮主题底色加更深同色块面，沿用人物 ID，不增加身份数量。200 张均有与实际 PNG SHA 绑定的圆裁和背景验收记录。背景允许大弧面、斜切和宽色带；“纯粹”指单色系与简洁形状，不是完全单色平涂。

词库含 60 组面部结构、80 组表情、80 种发形、60 组动作、15 种镜头、60 组服装轮廓。参数用于创作规划，实际图像另行标注；不以组合数量充当视觉覆盖，也不以换色、镜像作为独立人物。近邻算法仅筛选可疑对，逐图视觉比较和全库高相似候选复核记录在 `reviews` 中，不能据此宣称数学意义上绝无相似人物。

## 尚存缺口

200 张仍无法覆盖任意硬约束组合。最终报告中的缺口包括 45–54 岁 other 创作性别／青绿／宽体态、75–85 岁 other／宽体态、青少年女性正面、成年女性宽体态、年长 other 平静表情等。青少年红色女性、紫色男性、黄色 other 等组合候选深度仍薄。下一轮应从 `gaps-200.json` 定向扩充，同时维持主题配额。

年龄区间、体态、表情、朝向按图像实际表现标注，性别为创作设定。不可通过放宽图片标签、改写人物年龄或缩窄随机请求制造成功率。公开 API 允许年龄 14–100；本次图库和测试夹具为 14–85，86–100 岁仍会如实报告缺图。

## 缺图自动补齐闭环（2026-09-06 后续实现）

用户确认后新增 PostgreSQL `npc_pending_avatars` 队列，保留原始叙事、硬条件、用户与角色 ID 和哈希；409 缺图响应现在表示需求已持久保存。新图库导入与队列唤醒在同一事务中提交，Worker 每分钟领取最多 20 个到期请求，预约 5 分钟重试窗口。进程重启或中途失败后仍可恢复；匹配成功沿用原角色 ID，事务内永久绑定并移除待匹配请求。同一用户的并发请求继续排除已见头像，创建过的公共人物不会被重新分配。

iOS 显示统一蓝色剪影；登录后进入前台立即尝试补登记／领取结果，前台期间每 60 秒再试，后台、退出账号或切换账号时取消循环。缺图与单角色冲突不会堵住整个列表。网络失败保留本地角色和待登记状态，好友关联成功后才回填头像。持久化通知刷新当前页面，保留已有聊天和私人关系。已绑定本地头像也拒绝被替换。

后端、迁移、Worker 和 HTTPS 图库已部署并验证真实自动补齐；客户端仍需要安装新版 App 才能启用前台自动领取。iOS 领取发生在前台，不宣称 App 被系统挂起时也持续联网。持续缺图仍待补充图库，不保证等待时长。
