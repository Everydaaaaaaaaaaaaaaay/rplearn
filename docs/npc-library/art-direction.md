# NPC 头像美术规范与差异组合 v5

状态：200 张已逐图验收，五主题各 40 张；已完成 7 轮、6,960 次真实服务链用例。详细结果见 progress.md。未上传生产服务器，测试范围不包含生产 CDN 或实时 LLM。

## 用户确认的约束

- 统一 P3R 启发的图形化动漫语言：一种主题色系、近黑、中性白；大色块、少量明确线条，五官与手部抽象简洁。
- 明亮主题色底 + 少量同色系深色块（最新修正）。允许大弧面、斜切面、宽色带提供层次与动势；不使用近黑背景、透明背景、暗色晕染、渐变或复杂装饰。此前“新增优先纯底”是误读，已撤销。背景大部分仍明亮，深色区域约占背景 15–30%，不与人物争夺焦点。
- 使用场景为圆形头像。全身图属于角色卡素材，不计头像覆盖数。正面圆脸实验保留，但不作为所有圆脸的模板。
- 不默认添加白色额发、眼角痣、耳饰；这些是角色可选属性，不是风格不变量。
- 五套主题蓝、红、黄、紫、青绿，首个正式 100 张发布集各 20 张，最终 200 张各 40 张。旧蓝色富余存为候选，不为凑数继续扩大偏差。
- 画法统一；人物应在五官、神态、姿势、视角和穿着上有显著个人差异。不得把换色当成不同角色。

## 分层参数：目标描述与实际观测必须分开

| 层 | 独立维度 | 候选变化 | 复核重点 |
|---|---|---|---|
| 脸部比例 | 长宽、上中下庭、颧骨、下颌、下巴、耳廓 | 长窄、短圆、宽方、柔和矩形、菱形、宽额窄颌、窄额宽颌、长椭圆；短/中/长下巴 | 靠轮廓识别，不靠增添写实细节；不夸张丑化 |
| 五官配置 | 眼距、眼裂、眼皮、眉高低粗细、鼻轮廓、嘴宽 | 宽/近眼距、圆眼/狭眼/下垂眼/厚眼皮、平眉/挑眉/弯眉、短宽鼻/长直鼻/弧鼻、宽嘴/短嘴 | 细节简化后仍可见；不是同一组杏眼尖下巴 |
| 头发 | 发际线、长度、直卷、体积、分缝、收束、明暗处理 | 光头、寸头、后移发际线、紧卷、蓬松卷、齐刘海、偏分、背梳、短波波、长直、发辫、低扎、丸子头 | 不总在额前出现同位置白色高光 |
| 年龄体态 | 年龄段、颈部、肩宽、体量、姿态 | 青少年、青年、成年、中年、长者；纤细、普通、宽肩、丰满、敦实 | 年龄不只靠白发；体态不靠脸宽单一代表 |
| 表情 | 眉、眼、嘴、脸颊、非对称程度 | 开怀笑、憋笑、露齿笑、得意、质疑、专注、认真、恼火、惊讶、好奇、困倦、疲惫、腼腆、犹疑、担忧、泰然 | 把词翻译成可画动作；不能全部退化为浅笑 |
| 动作 | 头转向、俯仰、侧倾、肩线、手部 | 回望、探头、缩肩、扬下巴、低头抬眼、侧耳、托腮、扶领、捏下巴、手抵太阳穴、抱臂上缘、拉肩带 | 手不能盖住核心五官；缩圆后仍读得出动作 |
| 镜头 | 正/左右三分之二/左右侧面、俯/平/仰、微倾镜头 | 将角度与动作交叉，不让某种脸永远同一角度 | 朝向依据画面鼻尖和耳位标注，不能直接复制 prompt 标签 |
| 景别 | 近脸、头肩、上胸、带手的胸像 | 头部高度约画面 50–65%；中心圆内保住眼鼻嘴下巴和主要发形 | 64/96/160 px 的实际圆形遮罩检查 |
| 穿着 | 轮廓、领口、层次、服装类型、配件 | 西装、针织、工装、连帽、立领、围巾、衬衫、宽松外套、运动夹克、围裙、背心、户外衣 | 不人人都是黑内搭配翻领外套；避免小碎细节 |
| 配色 | 主色、同色阴影、黑白比 | 见下表 | 色彩不参与身份差异得分 |

性格、国籍、职业、价值观来自叙事，不从面相推断。表情是画面的瞬时状态，不意味着永久性格。性别为角色创作设定，不是看图推断的身份事实。

## 组合与去同质化

1. 独立建立候选维度与配额，用固定种子生成生产简报，保留可复现记录；不是自由抽签后只看张数。
2. 对每个方案，与已有方案比较年龄体态、面部结构、发形、表情、头肩手动作、镜头、服装轮廓 7 组，不包含颜色。规划签名 6 项中至少 4 项不同才值得出图；这只是生产前筛选，不能证明实际视觉差异。
3. 不固定捆绑：老人不全是白发微笑，圆脸不全是正面，年轻人不全是大眼，红色不全是愤怒，工装不只给某一性别。
4. 生产以小批次为单位，批次之间读取最新规范和停止标志，禁止预先捕获整批 prompt 后无视用户修订继续跑。
5. 生成后先检查圈裁可用、实际朝向、表情、脸型和发形，再记录 observed。实际不符就重标、重绘或拒绝，绝不拿 target 冒充 observed。
6. 并排检查近邻圆形头像：遮掉颜色和文字仍明显同脸者进入复核队列。哈希只能查重复文件，不能证明不同脸；自动相似度仅做候选排序，最终需视觉复核。
7. 同一人物的镜像、换色、重绘版本共享 identityGroup，不计为新增独立形象。

## 视觉验收记录

每张记录 reviewer、时间、图像 SHA-256、圆裁与背景结果、最相似候选和判断依据。observed 结构化保存年龄范围、创作性别、主题、实际朝向、表情、体态、appearance 与标签；景别、脸型、发形、动作和重复装饰的判断保存在画像描述或评审备注中，并非各自独立字段。结论由 review.status 保存。年龄段以可合理适配范围标注，不把提示词中的精确年龄当作已验证事实。

近脸图不能声称核验了全身体型。相关字段允许 unknown；硬性要求不可使用 unknown 充当匹配。图中穿着与最终 appearance 一致。评审后锁定像素内容及对应元数据，已经绑定角色的资产更新必须新增 ID。

## 五倍差异词库与背景修正

`Tools/ArtPipeline/npc-diversity-vocabulary.mjs` 已建立 60 组脸型与五官结构、80 组表情动作、80 种发形、60 组姿势、15 种镜头组合、60 组服装轮廓。它们是可画的生产参数，仍须检查实际输出，不能以标签数冒充视觉多样性。

背景的“纯”指单一主题色系、没有杂色和繁杂装饰，不指完全没有明暗色块。背景选项包括单个大弧面、斜切色面、贴边宽色带、偏心圆弧、下缘深色平面；按脸部留白和身体动势选择。禁止固定重复同一条弧线，但不以背景差异计入人物独立身份。
