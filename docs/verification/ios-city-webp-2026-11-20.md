# iOS 城市摄影 WebP 验收 · 2026-11-20

使用 Google 官方 `cwebp`（libwebp 1.6.0，libsharpyuv 0.4.2），启用 `sharp_yuv` 并保留色彩描述和方向。每张候选均保留原图尺寸，用 1170×2532 手机等比填充画面、变化最大的 390 像素区块及全图三种视角筛选，至少节省 12% 才替换。页面背景分别尝试质量 90、93、95，活动实景分别尝试 93、95、97，达到门槛后的首选档位入包。37 张沿用已审 JPEG。原图哈希、显示文件哈希、尺寸、体积和选档见[逐图记录](../../Assets/CityBackdropSources/display-encoding-v1.json)。

重点检查中央车站窗格和暗部人群、波卡普建筑边缘和植被、纽约个人页秋叶。使用原图裁切锚点审看手机全屏及差异最大的局部。照片来源、许可、地点和构图沿用[实景 v7](../../Assets/Activities/CityPlaces-v2/acceptance-v7.md)和[页面背景 v1](../../Assets/TabHubScenes/2026-11-16-v1/acceptance-v1.md)。

iPhone 18 Pro 模拟器通过三项检查，包含伦敦本地实景滑动、开普敦远端 WebP 下载和「查看全图」、开普敦剧情的背景与立绘。静态源为 Mac 的本地 HTTP 服务。Mac ImageIO 抽样中 WebP 比同分辨率 JPEG 解码耗时更长，界面后台解码，沿用场景预取并先展示页面背景缩略图。iPhone 真机的解码耗时待测。
