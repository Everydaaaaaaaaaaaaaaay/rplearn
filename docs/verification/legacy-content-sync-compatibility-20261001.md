# 旧端普通聊天同步临时兼容

日期：2026-10-01。修复提交与发布版本：`762d7114859e`。

## 问题与临时修复

此前已修复用户资料快照缺少 `quizGloballyEnabled`。进一步检查确认普通会话同步也存在
双向不兼容：旧端上传的 `quizOptOut`、`turnsSinceQuiz` 被严格 Schema 拒绝；下载时这两个
旧端非可选字段缺失。线上 22 条有效会话均缺少它们。前一修复上线后的日志仍出现 39 次
内容同步 HTTP 400，诊断为未知字段；日志不包含具体字段名，不能将全部错误都归因于此问题。

临时兼容限定在普通聊天接口：

- 会话响应补齐 `quizOptOut: true`、`turnsSinceQuiz: 0`，保持小测关闭。
- 补齐范围覆盖内容分页、增量同步、应用回执和版本冲突详情；兼容投影不写入数据库。
- 上传入口接受并验证旧会话字段，以及普通消息附带的 `quizJson`、`quizChosenIndex`。
  服务层按原请求计算幂等哈希，再在事务前剥离这些字段，保留旧回执重放能力。
- 其他未知字段、错误类型、`kind: quiz` 和 `quiz_record` 仍被拒绝。旧学习服务不恢复。

没有修改 iOS、数据库查询、迁移、账号归属或资源权限。此兼容层可在确认旧端退出使用后移除。
