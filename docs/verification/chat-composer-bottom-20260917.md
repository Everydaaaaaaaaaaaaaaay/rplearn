# 聊天输入栏底部缝隙 — 2026-09-17

## 现象

真机截图（iPhone 13，1170×2532）显示：输入栏下方还有一条约 50pt 的区域，能看到聊天内容
（消息气泡文字），像是输入栏浮在屏幕底边之上。用户问这是 bug 还是设计：正常聊天输入栏应贴住
屏幕底边。

## 结论与机制

输入栏本身是 `ChatView` 的 `safeAreaInset(edge: .bottom)`，消息列表在它下方仍然铺满整个视图。
正常情况下输入栏材质一直铺到屏幕底边，看不到任何东西；当容器把额外的底部安全区留在输入栏
之外（隐藏标签栏、收起键盘后的残留安全区）时，输入栏被顶到安全区上沿，而消息列表依旧铺到
屏幕底边，于是那条安全区里露出了消息内容。

本地无法 1:1 复现：可用模拟器只有 iPhone 17 Pro（iOS 26.1 / 27.0）与 iPhone SE（无 home
indicator），推送聊天时标签栏干净隐藏、输入栏正常贴底。为了验证修复，用测试钩子在输入栏下方
注入 60pt 空隙来模拟残留安全区。

## 修复

`ChatComposerSection.inputBar` 在材质背景之下再铺一段同材质（高度 `composerBottomBleed = 160`，
向下偏移并 `ignoresSafeArea(edges: .bottom)`）：输入栏正常贴底时它落在屏幕外，视觉零变化；
一旦输入栏被残留安全区顶起来，它就把下方区域补成同样的材质，不再露出消息内容。
材质仍走 `dsMaterial`，开启“降低透明度”时保持不透明降级。

## 验证

- 注入 60pt 空隙、关闭补铺：截图中输入栏下方出现约 60pt 的空带（复现用户现象）。
- 注入 60pt 空隙、开启补铺：该空带被同材质覆盖，输入栏重新贴底。
- 不注入空隙（正常状态）：与修复前一致，输入栏材质仍到屏幕底边，消息列表不被遮挡。
- `OnboardingWelcomeTests/testHandsOnTutorialUsesLocalTranslationDictionaryAndEncounter` 通过：
  教程里输入栏下方是教程自己的操作栏（跳过这一步 / 继续），补铺材质在它后面，外观无变化。
- 最新构建已用 `Scripts/preview.sh build messages` 装入 iPhone 17 Pro 模拟器
  `47DD7BF7-5378-47D7-ACC3-792EF8AAFF11`。
