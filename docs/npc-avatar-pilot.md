# NPC 头像采集试运行（2026-09-05 至 2026-09-06）

这是本地试运行记录，不是 5,000 张图库验收，也未发布到服务器。

## 实际结果

- 检索计划：54 个种子主题，覆盖运动、游戏、音乐、手工艺、生活、饮食、自然等领域。
- 发现 1281 条来源记录，下载 178 个不同字节的图片文件。
- 769 条记录因许可不在自动清单、权利信息或来源条件不足而留待核查；不等于这些图片不可使用。
- 4 条未成功重试的搜索错误、80 条下载错误被保留。Art Institute 图片端点的 403 是主要访问障碍之一。
- 11 张样本完成 Codex 来源与视觉审核：8 张通过、3 张本批不采用。尚未进行人工专家复核。
- 第一轮 111 张；扩展来源后新增 67 张，其中 Openverse/Flickr 46 张、Met 3 张，其余来自继续检索 Commons。

## 审核样本与真实覆盖

通过的 8 张分别表达羽毛球、国际象棋、韩国陶瓷、天文、观鸟、猫、烘焙与日本茶器兴趣。
它们只覆盖 8 个文化兴趣标签，其中茶器也标注陶艺。单类普遍只有 1 个家族，尚不能支持连续大量偶遇。
地区与年代标签描述素材来源，不能据此推断 NPC 应有什么爱好。

本批不采用：雷鬼音响活动照片尚需人物及画面内图形权利核查；合成器线缆和深色刺绣在 40px 下辨识不足。
审核记录、署名、许可链接、字节指纹、家族编号与具体理由见 `Backend/npc-avatar-pilot-review.json`。
本地工作目录另有全部来源证据与原始下载文件；它们未进入 Git。

新增来源使全部 54 个主题都有下载线索，但**不表示 54 个主题已被真实覆盖**。例如围棋查询返回了
Monopoly 和 LEGO；版画查询返回了油画；网络幽默用猫图搜索也不能证明图片表达某种网络社群文化。
不得从检索标题或主题关联直接生成审核后的文化标签。

## 下一批素材应解决什么

1. 先审核新增的围棋、麻将、甘美兰、弗拉门戈、街头食物和铁路样本，剔除错题材、活动照和小尺寸不清楚的图。
2. 补充独立游戏、桌游社群、音乐细分流派、地方手艺、互联网创作等当代小众兴趣，避免博物馆收藏和摄影素材主导全部审美。
3. 每个主题同时寻找日常器物、场景、原创插画、抽象表达等不同用图方式；同一主体的版本不能充当多个可分配家族。
4. 对找不到许可适合素材的缺口形成原创生成题单。不能把“AI 生成”当作仿造特定游戏角色、运动员照片或品牌的许可。
5. 将新增图与累计图库核查相似家族，再用跨语言、交叉兴趣角色卡测试匹配与耗尽；以审核后家族数决定扩库，不能只追下载总数。

## 可复现与发布状态

在 Backend 运行 `pnpm npc-avatars:collect -- --pages 0 --downloads 0` 重建采集报告；
运行 `pnpm npc-avatars:prepare -- --dir .avatar-workbench --review npc-avatar-pilot-review.json --review-only`
校验已审核字节并生成 `reviewed-report.json` 和 `reviewed.html`。采集报告的 approved=0 表示采集本身不授予批准，
审核数量来自单独的审核报告。

候选文件在 `.avatar-workbench/images/`，整体审核页在 `.avatar-workbench/review.html`。
上传工具已实现且用模拟 S3 响应测试了不可覆盖、字节核验和重试；尚缺专用公开头像桶及 CDN 映射，未执行实际上传、
数据库导入或部署，也没有使用私有语音桶。

## 来源依据

- [Commons 重用说明](https://commons.wikimedia.org/wiki/Commons:Reusing_content_outside_Wikimedia)：需核查每张文件的许可和额外权利。
- [Cleveland Open Access](https://www.clevelandart.org/open-access)：单件开放图片 CC0；首批核对了 API 中的单件许可字段。
- [Openverse API 文档](https://docs.openverse.org/api/)：用于发现索引条目；本实现要求批准前另核对原作者页。
- [Met 官方开放数据说明](https://github.com/metmuseum/openaccess)：明确数据集开放不包含所有图片，作品页 CC0 标记才与图像政策对应。
- [Art Institute API](https://api.artic.edu/docs/)：单件作品公有领域标记用于初筛；本环境图片获取失败不计作下载。

iNaturalist 观察 API 也已探测可用，但个别照片页在本环境返回 403，无法核对照片的完整许可版本；
Museum Victoria 的 API 返回 403。这两者本批未作为已接入来源，不扩大来源数量来虚报结果。
