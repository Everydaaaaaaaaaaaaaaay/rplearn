## 确认的问题与处理

| 问题 | 复现 / 证据 | 处理 |
| --- | --- | --- |
| 发送前清空草稿，未加载会话或本地保存失败时输入消失 | `ChatWorkflowTests` 的未加载/无效会话故障断言均先失败 | 保存失败恢复原草稿，保留期间新输入并提示错误 |
| 重试前删除中断回复；重试再次失败后已有内容消失 | 先保存中断片段，注入重试网络失败，重新进入查不到原消息 | 新回复保存成功后才删除旧片段，重试请求历史排除旧片段 |
| 重试入口没有验证目标是否为当前会话的中断助手消息 | 将正常消息 ID 传入后错误启动新生成 | 仅接受当前消息列表内的中断助手消息 |
| 空模型输出被视为正常完成，没有回复也没有错误 | 空流正常结束后 `errorMessage` 为 nil | 空白输出明确提示失败，不继续额外质量重试 |
| 同步回执异常后 Outbox 可能永久处于发送中；仅核对数量无法识别错误 ID | 注入未知状态、错误 command ID、错误 resource ID 后，不能正常重传或误确认 | 核对操作 ID 集合和资源身份；传输、解码、回执及应用失败均恢复未确认项 |
| 进程退出后持久化的发送中标记缺少恢复路径 | 使用磁盘数据库领取待上传项，重新创建容器与 Store 后读取结果为空；断言已复现 | 首次激活存储实例时恢复该账号的未确认项，保留原 ID；同实例重复激活不重置正在发送的操作 |
| 部分集成测试回退开发库，另一些才读取测试环境变量 | 审阅 `loadConfig({ NODE_ENV: "test" })` 调用和默认数据库地址 | 统一测试配置，拒绝缺省/远程/普通开发数据库；独立创建本地服务 |
| 普通测试宿主和 UI 测试可能使用线上网关 | 原 AppEnvironment 使用 `.live`，后台刷新开关未改变网关 | 测试 scheme 与 UI 启动显式设置本地不可用地址；实际在线测试仍独立注入客户端 |
| Xcode 没有匹配到测试也返回成功 | 首次使用方法级筛选时结果包实际为 0 项，结果为 unknown；已排除该次结果 | 公共 iOS 入口检查结果包数量，零执行和全跳过均返回失败；改用测试组验证 |

修复不会自动补回历史上已经被删掉的回复。重试中途失败可能同时保留旧片段与新收到的中断片段，
这些片段继续保留中断标记。
