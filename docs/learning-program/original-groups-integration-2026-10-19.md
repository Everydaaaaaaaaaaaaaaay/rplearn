# 真题规则驱动的原创题组接入

本轮将既有真题研究形成的原创完整题组接入学习系统。真题保留为题型、材料配置和判分规则的依据；正式供题输入是独立原创稿，不把原卷正文或参考键批量导入。幼儿启蒙、主观题和已移出常见题范围的研究参考稿继续排除。

当前冻结批次为 **15 档、141 个档位/题型格、634 个完整原创组、5,090 个回应**，每个适用格至少3个完整组，来自原有772组作者稿中的当前主范围；138组参考稿排除。不是634组新创作，也不代表全国题型、全年课程、独立教研或学生效度已经穷尽。发布和原生验收结果见[本轮验证记录](../verification/learning-originals-integration-20261019.json)。

## 供题与输入

每个完整组是一个不可拆散的正式单元，不进入6/18独立题抽取器。后端按完整组创建正常学习挑战，使用现有答题、保存、历史、补答和奖励事务。已开始的旧挑战不变。普通同行者和预设旅伴均可获得这些组；按账号避免跨旅伴重复抽到同组。

客户端声明 `x-learning-complete-groups: 1` 后可抽取；旧端不会新抽到完整组，旧端读取已存在的新组收到明确升级提示。`GET /v1/learning/originals?level=...` 仅返回正式发布的标题、题型和回应数，不下发作者答案。实测入口增加题型和具体题组选择，仍需真实登录。

材料全文、全部子题、共享候选、词库、给词与限词要求保持绑定。表格按行列呈现；图形由原有自有SVG离线栅格化，保留画布。547段自有音轨保留完整内容、复现次数和停顿，解码为24kHz单声道PCM，按实际文件检查长度、时长、峰值与SHA。203个PNG对象与音轨均须先进入已校验对象存储，缺少输入时不发布。原音轨和冻结作者稿不覆盖。

同一挑战的多道子题共享音轨时，只要求实际完整播放一次；中断不能冒作听完，跨挑战重新解锁。音频和图片仍通过挑战归属鉴权申请短期地址，资源下载不携带账号令牌。

## 判分与审核边界

每个已核合法答案变体同等接受，不限制只能一解或最多三解。限词、给定关键词和初始字母按各题具体协议处理；不使用词根近似匹配。明确的错误形式或明确违反约束可判错；未列入已核形式的表达返回 `LEARNING_ANSWER_REVIEW_REQUIRED`，不写成错答、不加分、不消耗本题提交机会，也不声称已经排入人工审核队列。

完整学生输入摘要和逐回应作者正反样例独立绑定。只修改单元并重算其内容哈希不能掩盖材料或答案改变。既有作者逐题依据得到复用，程序校验不替代教师语义审核、难度标定、学生试测、自然听感或商业使用确认。

## 可重现发布

`Research/GuYouJi-English-Benchmark/Tools/export_learning_originals.py` 读取冻结审阅数据，核对作者稿与审核SHA，拒绝缺少完整交互的整组，不静默省略子题。正式输入位于 `Backend/config/learning/originals/catalog.json`；媒体不入Git。来源、作者稿、输入摘要、作者样例和资源SHA随元数据保留。

`Scripts/prepare-original-learning-assets.py` 仅归档新增SHA对象并实测恢复，不新增整库快照。部署传输包是临时产物，不当恢复点。媒体从程序发布包排除，按有界资产包单独安装。线上仍遵守256MiB维护内存、128MiB Node堆、2MB/s磁盘限制与原有健康观察，不通过放宽资源限制强行发布。

长音轨从磁盘按64KiB分块校验和上传，保留全文件SHA、RIFF/PCM格式、时长和峰值检查；单次音频请求最多等待90秒，签名有效期120秒，整批维护任务仍限600秒。43.2MB磁盘音轨的真实HTTP回归包含32秒延迟响应，核对长度与SHA，并拒绝退回整段Buffer加载。资源不足、超时或上传失败时停止该批；已提交批次保留，可按原版本和哈希接续。发布确认同时核对逐批提交回执和数据库内容，不能只看维护进程的退出状态。

```sh
# Backend 目录；本机可验证全批，线上只运行有界批次。
pnpm exec tsx src/cli/learning-originals.ts validate
node dist/cli/learning-originals.js validate b000
# 线上通过统一维护入口，使用该批刚验证的完整哈希。
sudo /opt/lingotrip/ops/native-server/maintenance.sh originals-publish <hash> b000
```

每批资源和单元发布独立原子提交；失败批不冒成功，已成功批可按相同版本幂等恢复。已有用户数据、已得奖励和历史单元不删除。回退内容应下架本批单元，保留版本和历史挑战；发布新合同后，程序回滚必须使用能解析这些冻结完整组的兼容版本，不能直接退回不认识此合同的旧服务。
