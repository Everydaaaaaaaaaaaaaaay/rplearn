# 对话成长原型：扩展场景与回归协议

## 预期先于运行

评价对象是本轮当前仍成立的英语选择与理由，不是查找历史里任意一句合格文本。短句、语法错误、没有 because、提出第三种方案均可完成；明确撤回的内容不能单独证明当前完成。引用他人观点须明确认同，中文可以混用，但用于达成目标的选择与理由须能从英语中理解。无关后续消息不撤销已有答案。

明确请求停止时，本轮不继续判完成、不给新练习建议；历史经验不扣回。这是原型的交互规则，不代表用户之前没有展示能力。停止与普通改口分开检查，不能按 stop 等单个关键词判断。不得为提高通过率而事后改写错例预期。

## 覆盖矩阵

| 层面 | 已编写场景 | 检查方式 |
| --- | --- | --- |
| 基础语义 | 14 类：三个情境正反例、小语法错、离题、全中文、拒绝、注入、自选方案 | 真机账户模型 |
| 多轮与语言边界 | 32 类：跨轮理由、先理由后选择、改口、撤回、引用/认同、假设、隐含因果、同义反复、表情、缩写、自纠错、两种选择、情绪性拒绝、混合语言、短句 | 真机账户模型；保留原始回答 |
| 未用于修正规则的检验集 | 24 类：预算、无障碍、儿童短句、天气、撤回再恢复、无关理由、提问、求助、第三人称、共同选择、否定停止、地点 stop、历史停止、间接拒绝、礼貌假设、Unicode、列表和长历史 | 修正后首次运行；出现偏差即成为下一轮回归项 |
| 扩展发现的邻接边界 | 10 类：带/不带理由的多个选项、全部拒绝后未选择、犹豫后决定、暂停/否定暂停、中文/日文地名、中文书名、带重音地名 | 定向真机回归；不将非拉丁专名误当中文表达 |

| 故障及引用 | 格式损坏、围栏、伪造/重复/窗口外 ID、过长/空白反馈、空/超长窗口、取消、权限、额度、限流、上游失败 | 注入模型客户端；断言调用次数和不发奖 |

保留原有 180 天、4320 次尝试的日上限与重复规则仿真，以及已通过的其他原生 UI 路径。新增 96 组合不是 96 个真实用户，真机预置多轮文本也不是真人对话或完整 NPC 会话质量实验。

## 运行与自查

1. 固定输入、预期、规则版本；记录本次代码版本。先跑故障/状态测试，再进行必要的真机模型测试。
2. `LINGOTRIP_LEARNING_LIVE_EVAL=1` 显式开启付费批次；普通启动不运行。`LINGOTRIP_LEARNING_LIVE_CASES` 逗号分隔名称用于失败邻域回归。样本位于 `App/ConversationLearningPrototypeView.swift` 的测试入口，只有 Debug 编译。
3. 每例最多两次客户端请求；基础设施错误立即停止整批，不把未运行记成失败或通过。先复制 `Documents/learning-live-evaluation.json` 到本地证据目录再启动下一批，避免覆盖证据。
4. 先检查匹配数，再逐项看反馈与引用，检查误夸语法、给拒绝用户布置任务、引用被撤回的旧句。布尔匹配率不能代替人工语义审阅。
5. 修复后回归错例、相邻正反例及未见检验集。网络偶发故障单列；不能通过无限重试把模型质量包装成百分百。
6. 原始报告仅含预置输入，不导出账户令牌或私人聊天。报告含运行 ID、样本版本、时间、原始响应、调用数。每轮结果另存，文档记录差异和未验证边界。

自动报告核验：`python3 Scripts/verify-learning-evaluation.py <report.json> --expected-count <本批计划数>`。批次不完整、重复名称、混合版本/运行、判定不匹配、错误、缺反馈/原响应、调用次数越界均返回非零。实际已用第一轮三个错例和未完成批次验证其拒绝路径；人工审阅仍不可省略。

完成返回额外要求 `choiceEnglish`、`reasonEnglish`，分别是被引用消息内的原文片段。客户端拒绝凭空翻译出来的英文、没有英文实质内容或缺失的片段，并最多重试一次；英文句子中可保留非拉丁专名，不能粗暴排除所有汉字。独立 `wantsToStop` 字段由客户端优先处理，电量低/疲劳等事实本身不代表请求结束。此校验强化原文依据，但不等于一个确定性的英语语义分类器：是否确实构成选择与理由、是否表达结束意愿仍由模型判断。

## 边界

此矩阵验证的是当前三个练习情境的评价与本地状态流程。真实语音识别错误、翻译工具端到端、不同年龄真人的理解成本、长周期学习迁移、生产多设备记账仍需相应实验。不能将规则组合或 80 类语义样本称为所有真实使用场景，也不能由本轮无误判推出模型今后永不误判。
