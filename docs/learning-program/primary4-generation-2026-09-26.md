## 范围

四年级只使用已核读 PEP、译林旧版四下的正文页。九个目标覆盖钟点、日常活动、天气、许可、所有格、衣物、价格、季节和能力；每个生成单元限定一至两个目标，六道题至少三种文字题型，当前待补目标至少三题。每个角色仍有自己的公开设定、情景和去重池。

规范区分允许结构与禁止范围：具体钟点、常见时段、time to/for、I/you/we 一般现在时、can 许可与能力、单复数问价等可以使用；不进入过去时、将来时、完成时、被动、复杂从句、比较级、开放作文，也不以地理气候或价格运算替代语言练习。

每题给定全部条件，明确人称、所有者、数量、币种与价格范围。填空指定目标并接收合理变体；组句登记全部合理词序或明确句首限制。提示不能泄露答案，解析须区别“不合本题语境”和“语法错误”。同一目标可用不同语言操作复现，不能只换词换名字冒充新单元。

模型仍为现有 DeepSeek `deepseek-flash` 高档推理；本批不改变供应商、模型、每日六次租约、单次 16000 token 或 120 秒上限。上线前查询生产当日已有 4 次租约，剩余 2 次；不会通过改写预算或历史记录绕过上限。
