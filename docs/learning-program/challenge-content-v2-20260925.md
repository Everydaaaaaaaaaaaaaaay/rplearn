# 角色单元挑战 v2 内容库（2026-09-25）

## 当前状态

服务端内置 **144 个原创单元挑战**：Oliver、Ruby、Marcus 各覆盖小学一年级至高中三年级，每个年级四个不同情境。每个挑战有三至四段连续剧情，以及“信息判断 → 排句回应 → 控制性短写”三道题；答题解释指出线索。服务端只抽取版本 2 内容；旧版预设题源码和客户端版本选择参数已移除。数据库中的历史作答与旧模板行不删除，但旧模板不再进入新挑战抽取。聊天页现有左滑学习页入口，但客户端尚未发布新版；内容部署不等于客户端发布或教学效果验收。

此库是**内部试用题库**。题干、剧情和答案由本项目原创。已参考官方教材目录、出版社对单元活动的介绍与部分公开样页；没有取得并逐页校对全套学生用书，也没有教师逐题审校或真实学习者难度校准。因此“教材参考”表示主题、任务方法和大致进阶参考，**不表示逐课同步、教材授权内容转载或学校年级能力认证**。

## 覆盖与年级进阶

| 年级 | 代表任务 | 主要语言与思维要求 |
| --- | --- | --- |
| 小一 | 问候、颜色、数量、礼貌请求 | 短句识别和简单回应；出版社确认一二年级有可选预备级，但逐册内容未核对 |
| 小二 | 家人、位置、日常安排、简短指示 | 两处简单信息合并，读懂人物与位置 |
| 小三 | 交友、家庭关系、动物、植物 | 用线索完成称呼、分类和观察记录 |
| 小四 | 家庭帮助、居住方位、购物、天气 | 在生活场景中选行动和核对条件 |
| 小五 | 朋友差异、情绪、健康习惯、旅行 | 说明原因、建议和先后顺序 |
| 小六 | 路线、聚会、预算、自然资源 | 比较限制和可行方案 |
| 初一 | 健康、学校、兴趣、公共规则 | 结合时间、原因和规则回应他人 |
| 初二 | 观点比较、计划变化、阅读选择、误会澄清 | 辨别不同立场与信息条件 |
| 初三 | 记忆记录、前后对照、事实与推测、方案修正 | 控制结论范围，说明证据不足 |
| 高一 | 青少年活动、旅行行程、文化遗产、道德选择 | 综合多条约束，解释选择后果 |
| 高二 | 未来预测、身体语言、跨文化解释、应急沟通 | 区分观察与推断，核对一手来源 |
| 高三 | 环境权衡、文本阐释、海洋利益、职业沟通 | 比较多方需求，明确证据边界和目标受众 |

各角色有独立任务：Oliver 围绕书店与阅读，Ruby 围绕咖啡馆、海岸和海龟保护，Marcus 围绕摄影与展览。同一角色同一年级四题的剧情和任务不同。单元号与官方资料库中的册次、题目主题已核对；题目并不复制教材原文。

## 来源等级和使用边界

每题记录册次 ID、单元号、公开来源、设计关注点与证据等级。`sample-page` 表示见到官方展示的样页或缩图；`publisher-activity-index` 表示参考出版社公开的目录及活动介绍；`official-lesson-index` 表示参考教育部公开的高中单元目录；`curriculum-introduction` 仅支持一二年级预备级存在及入门方向。来源级别不能互相冒充。参考入口包括[人教社小学新教材简介](https://www.pep.com.cn/xw/zt/hd/12/xjcjs/xx/202409/t20240920_1995564.html)、[人教社初中新教材介绍](https://www.pep.com.cn/xw/zt/hd/12/xjcjs/cz/202510/t20251024_2004130.html)和[教育部高中教材单元目录](https://www.moe.gov.cn/jyb_xxgk/s5743/s5744/202304/W020230420309231498801.pdf)。逐册证据及缺口见[教材库](textbooks/pep/README.md)和[研读记录](textbooks/pep/volume-study-notes-20260925.md)。

服务端生成题继续沿用角色、年级、来源和质量约束，只有预设库在当前角色与年级用尽时才生成。生成题写入共享题库前仍须内容审查机制验证；当前自动检查不能替代教师审查。

## 本轮检查与待验证处

结构检查覆盖 144 个唯一 ID、每角色每年级四个独立剧情、三种题型、选择题唯一答案、排序题词块可还原、高中短写至少两个词，以及可核验册次的单元号存在。手工复核修正了购物单元号、新闻主题单元号、一个“清晰”被误当“可靠”的推断，以及数道高中填空的答案与原句不一致问题。

当前引擎只支持单选、词块排序、精确匹配短写。高年级真实表达能力不能只凭这三题推断；多种合理答案、自由写作、听力和跨日迁移尚未纳入这一批。正式恢复学习入口前需要教师逐题审核、低年级无中文首答可理解性试测、实际作答数据和跨日新题复测，再校准难度与等级阈值。客户端在一轮作答完成前隐藏剧情中文，完成后可回看中文与解释。

后续[短写质量核查](unit-content-quality-audit-20260925.md)发现 121 / 144 道短写题的完整标准答案可在英文剧情中连续定位，初中至高中为 54 / 72。此指标不能直接代替教师判题，但暴露了高年级表达任务过多依赖摘抄的问题；现有预设仍是内部试用内容，尚未达到“丰富且难度已匹配”的验收标准。
