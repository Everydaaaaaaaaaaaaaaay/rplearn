# 单元挑战内容改进：首批 15 个原创模板（2026-09-25）

## 状态与边界

原有 `unit-v1-*` 144 个模板和历史作答保持原样。新增 `unit-v2-*` 15 个模板，分别覆盖小学三年级、初一、初二、初三和高一；Oliver、Ruby、Marcus 每人在这些年级各有一个独立情境。服务端按模板版本优先抽取未做过的 v2 内容，之后才使用旧模板。当前正常客户端的对话学习入口仍按[进度账本](status.md)保持撤下状态；此批内容不会自行恢复入口。

这批模板是**内部试用内容**。已用人教社公开教材页样本确认主题及活动方式，题干和剧情由本项目原创；尚未经过英语教师逐题审校、完整学生用书核对或真实学习者难度校准，不称为正式教材级题库。具体参照页的证据边界见[逐册研读记录](textbooks/pep/volume-study-notes-20260925.md)。

每个模板在服务端保留 `volumeId`、单元号、公开证据链接、设计重点和证据层级。英文材料及中文译文一起保存；**本次更新的客户端**在 v2 首次作答结束前只显示英文，完成后显示中文供回看。旧客户端仍按旧界面显示译文，不能用其答对数评价英语理解。选择题的解释指出所用线索，排序句须服务于当前角色的任务。高一短写答案均为两个词以上，避免单词抄写伪装成综合表达。

## 复核结果与后续准入

- 结构检查覆盖：15 个新 ID 均唯一、每个目标年级三位角色各一题、情境和第一题答案不相同；题目顺序与词块答案匹配；教材 `volumeId` 和单元号能在资料库中找到。
- 服务端生成新题的要求同步改为至少三拍、角色有真实任务、情境题结合多处信息；初高中阅读量设下限，高中短写不再接受单词答案。生成题仍需第二轮模型审题，不能替代教师审核。
- 当前引擎依然只有选择、词块排序和精确短写三种交互。复杂的开放写作、听力、图表操作及多种合理答案尚未实现；不得把这 15 个模板的答对数解释成真实学校年级水平。
- 恢复正常入口前，需要教师逐题审查答案变体、年龄适宜性与语言自然度；检查低年级不显示译文时的可理解性，并用真实学习者首答和跨日新题复测数据重新设定难度与进阶阈值。接下来扩充其他年级与每级题量时应沿用本记录的证据和审题字段。
