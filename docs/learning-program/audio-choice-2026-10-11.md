# 独立声音选项交付

新增 `audioChoice`：每题2–5段独立音频，选择仍提交稳定的选项ID。客户端逐段播放、慢速重播、独立改选；完整听过全部选项后才开放检查，播放本身不选答案。切换只停止正在播放的另一段，保留已听完记录；中断和旧回调不能假报听完。界面采用紧凑分隔行，图标保持可辨尺寸、44pt以上触控区域，文字支持辅助字号。

服务端公开响应仅包含素材ID，不含原文、声线、答案或解析。音频请求以可选assetId明确选段，核验本人冻结挑战中的引用；多段题遗漏身份不默认返回第一段，非法、跨题或跨账号访问拒绝。显示顺序由挑战身份稳定打散，重进和补答不换编号；不修改原题及既有数据库合同。正确奖励和补答继续走原幂等判题路径。

发布、目录审核、后台素材预览及题库修订统一识别所有音轨。后台可查看原文、试听、改正确项，不能直接改已审核声音；纯文字模型生成仍拒绝音频题。未增加数据库迁移，未向正式题库导入工程夹具。
