# 九年级长题面：原生交互与辅助字号

本批接续九年级题库上线，检查正式题面在原生挑战中的布局。服务器内容与判题链路见[九年级内容验收](junior3-content-2026-09-26.md)，本记录不替代该证据。

## 样本与预览边界

四份题面快照来自三个已发布 version 1 单元，经服务端 `publicUnit` 白名单导出，并保存原单元内容哈希：

- Oliver `bookclub-enquiries / ask-room`：三个长英文选项。
- Marcus `neighbourhood-invitations / if-two-jobs`：三组完整句配对。
- Ruby `reusable-cafe / purpose-labels`：含多词块的长句组句。
- Ruby `reusable-cafe / purpose-note`：中文说明、英文句架与双词输入。

快照位于 UI 测试包 `Tests/LingoTripUITests/Fixtures/learning-junior3-preview.json`，未作为 App 资源分发；不含答案、解析或审核报告。已逐份比对源内容哈希与公开题目字段。新增的 JSON 预览参数仅在 Debug 免登录工作区中解析，正式账户与 Release 没有该入口；提交不会判分、发奖或写入学习记录。

## 发现与修改

普通字号下，长选项、配对和词块未发现截字。最大辅助字号下，原本固定的“检查＋跳过”两项占去大量正文空间，两列卡片也不适合长句阅读。本批调整：

1. 辅助字号的底栏只保留主要操作；跳过题目和跳过剧情随对应正文滚动。普通字号的布局保持原交互。
2. 辅助字号的配对题按第一组、第二组展示全宽卡片，并同步调整说明；配对编号和改配行为沿用原状态模型。
3. 题目状态与年级在辅助字号下纵向排列，避免两个短标签被横向挤压。
4. 不压缩用户设定的正文字号，仍通过滚动阅读全部内容。
5. 三个角色强调色增加深色变体，选项、词块及配对编号在暗色背景下保持明亮；实心主按钮改用随模式变化的文字与加载指示颜色。按已定义色值计算，三个深色强调色相对深色卡片的对比分别约为 8.71、9.31、8.87；这是色值检查，不是全界面无障碍认证。

测试自身也修正了两点：SwiftUI 多行输入框的辅助功能类型是 TextField；滑动起终点应根据固定栏之间的实际区域计算，不能用整个屏幕的固定比例。

## 验收范围

使用专用 iPhone 18 Pro / iOS 27 模拟器 `5B0646E5-11D1-449C-962A-6C79B32D05A6` 和既有 `build/DerivedData`。Computer Use 直连 Device Hub 超时，从 Xcode 菜单重试后仍超时；因此交互证据来自 Xcode UI 测试及实际模拟器截图，不宣称完成 Computer Use 人工操作。

定向测试分别检查默认字号浅色、最大辅助字号深色的四题型：三个选择项可选中，全部配对后主要按钮才启用，词块可选入和移回，双词输入保留空格且键盘不覆盖主要按钮，退出始终可达。两条定向 UI 路径通过，证据 `build/junior3-layout-adaptive.xcresult`。更换深色强调色后，仅重跑受影响的最大辅助字号深色路径，1 项通过，证据 `build/junior3-layout-final.xcresult`。没有重复跑整套 UI 测试。

实际截图导出到 `build/learning-verification/junior3-layout-adaptive/` 与 `junior3-layout-final/`；已查看普通字号各题型、键盘输入，以及最终深色选中选项、配对编号、词块和输入状态。超出视口的正文仍可滚动阅读，没有据此声称整道长题能同时放在一屏。

完成后使用 `Scripts/preview.sh preview unit-challenge` 复用最新构建，已重新安装并停在普通字号浅色的九年级完整句配对预览，供用户查看。

这四道代表性题面的验收不等于所有九年级题、全部设备宽度、横屏、VoiceOver 朗读或真实硬件已经覆盖。未增加后端改动、题目版本或模型调用。
