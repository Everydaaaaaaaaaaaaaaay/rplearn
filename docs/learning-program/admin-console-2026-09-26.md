# 挑战内容管理工作台

入口为现有模型控制台的“挑战内容管理”，地址为 [coovingo.com/internal/admin/learning](https://coovingo.com/internal/admin/learning)。挑战管理使用已有管理域名；保留线上 `/console` 模型后台和公开介绍站点的路由，主 API 域名继续拒绝全部内部路径。复用已有管理员凭据与当前浏览器会话。静态登录页公开，所有题库、答案、生成记录和写操作均由管理员接口保护。

## 已实现范围

- 正式单元按角色、水平分页筛选；查看剧情、六种题型、答案、提示、解析、课程来源、审核者与不可变历史版本。听力显示审核原文并可按需试听；图片选项直接展示登记的插图。
- 生成与待审按角色、水平、状态筛选；显示模型、用量、失败原因、独立审题结论和编辑修订链。刚提交的修订也能预览，明确标为等待复审。
- 有效候选提供逐题表单：剧情位置与对白、题干、提示、解析、学习目标、选择题选项及答案、填空答案、词块及可接受顺序、配对及对应关系。
- 保存修订创建新任务，保留原稿及失败证据；重新盲审只调用审核阶段，仍受原有预算约束。原稿已有后继修订时，引导继续处理新稿。
- 只有独立审题通过的当前候选可以人工发布。要求具体说明与逐题核对确认，内容指纹防止陈旧页面覆盖变更。审核者来自管理员鉴权身份，不信任客户端提交姓名。可将待审候选退回并记录理由。
- 未提交修改有离开确认；写操作期间禁用编辑，避免响应覆盖正在输入的内容。动态文本通过 DOM 文本接口呈现，不执行模型输出中的 HTML。

正式版本在页面中只读；本轮没有加入正式单元编辑、撤回、删除或手动批量生成。已有用户的挑战快照及奖励记录不受后台候选操作影响。后台具有管理能力不等于课程内容已达标，仍适用[模型评估结论](model-evaluation-2026-09-26.md)。

- 8 项生成协议和编辑单元检查通过；TypeScript、改动文件 ESLint、依赖架构检查通过（244 模块、655 依赖）。全仓 ESLint 另有既存 build 临时脚本与 encounter-weights 测试告警，本次没有改动这些文件。
- Computer Use 在独立本地数据库实操：登录、9 单元列表、正式预览、失败稿编辑、修改提示和解析、提交修订、等待复审时预览已保存稿件、追溯原稿及禁止重复修订。桌面与 390 像素宽屏检查完成，窄屏无横向溢出，浏览器没有脚本错误。

## 素材预览与试听（2026-09-26）

- 正式单元和有效候选预览展示已登记图片、听力播放器、正常/0.8 倍速，以及折叠的素材来源、审核说明和摘要；未登记素材明确显示不可预览。素材审核说明保留原始质量边界，不把机器识别改写成人耳审听。
- 素材通过后台鉴权同源接口读取。请求绑定单元版本或候选内容指纹，只能读取该版本引用的已登记资源；服务端核对 HTTPS、类型、长度、文件格式及 SHA-256，客户端再次核对摘要。管理员凭据不发送到对象存储，签名下载地址不暴露给播放器和图片元素。
- 相同素材合并请求，失败可重试；切换单元、版本或内容来源时停止播放、取消请求并释放临时地址。审核/编辑视图不会因之前的延迟响应而开始播放。
- 5 项新增测试通过：2 项素材完整性及错误清理单元测试，3 项隔离 PostgreSQL 鉴权/历史版本/候选指纹检查。类型、定向 ESLint、架构检查通过。工程测试使用独立测试资产，不修改正式课程。
- Computer Use 以正式课程和隔离数据库实际操作：人为注入首次图片/音频失败，重试成功；18 个图片元素均解码为 512 像素资源，以 190×190 比例呈现；音频 readyState=4、时长 1.254125 秒，切换 0.8 倍速有效。桌面及 390×844 窄屏实看，窄屏无横向溢出。
- 额外注入 2 秒录音延迟，加载期间进入审核页，加载后保持暂停且播放时间为 0；返回预览后加载并切换到另一单元，新单元所有录音均未播放。浏览器无脚本错误。实操验证播放机制，不构成人耳音色与教学效果审定。

此批没有新增正式课程或开放自动升级，也未调用真实模型；完整课程与正式进阶内容仍按总纲继续建设。
