# 挑战内容管理工作台

入口为现有模型控制台的“挑战内容管理”，地址为 [coovingo.com/internal/admin/learning](https://coovingo.com/internal/admin/learning)。独立管理域名只代理模型与挑战管理，主 API 域名继续拒绝全部内部路径。复用已有管理员凭据与当前浏览器会话。静态登录页公开，所有题库、答案、生成记录和写操作均由管理员接口保护。

## 已实现范围

- 正式单元按角色、水平分页筛选；查看剧情、六种题型、答案、提示、解析、课程来源、审核者与不可变历史版本。听力目前显示审核原文，不提供后台播放。
- 生成与待审按角色、水平、状态筛选；显示模型、用量、失败原因、独立审题结论和编辑修订链。刚提交的修订也能预览，明确标为等待复审。
- 有效候选提供逐题表单：剧情位置与对白、题干、提示、解析、学习目标、选择题选项及答案、填空答案、词块及可接受顺序、配对及对应关系。
- 保存修订创建新任务，保留原稿及失败证据；重新盲审只调用审核阶段，仍受原有预算约束。原稿已有后继修订时，引导继续处理新稿。
- 只有独立审题通过的当前候选可以人工发布。要求具体说明与逐题核对确认，内容指纹防止陈旧页面覆盖变更。审核者来自管理员鉴权身份，不信任客户端提交姓名。可将待审候选退回并记录理由。
- 未提交修改有离开确认；写操作期间禁用编辑，避免响应覆盖正在输入的内容。动态文本通过 DOM 文本接口呈现，不执行模型输出中的 HTML。

正式版本在页面中只读；本轮没有加入正式单元编辑、撤回、删除或手动批量生成。已有用户的挑战快照及奖励记录不受后台候选操作影响。后台具有管理能力不等于课程内容已达标，仍适用[模型评估结论](model-evaluation-2026-09-26.md)。

## 验证

- 13 项隔离数据库检查通过：后台鉴权、参数边界、不可变版本查询、确认与指纹保护、并发发布唯一版本、审核者防伪、修订幂等、原稿保留、重新独立审题及退回。证据 `build/learning-engine-db-1790405118/result.json`。
- 8 项生成协议和编辑单元检查通过；TypeScript、改动文件 ESLint、依赖架构检查通过（244 模块、655 依赖）。全仓 ESLint 另有既存 build 临时脚本与 encounter-weights 测试告警，本次没有改动这些文件。
- Computer Use 在独立本地数据库实操：登录、9 单元列表、正式预览、失败稿编辑、修改提示和解析、提交修订、等待复审时预览已保存稿件、追溯原稿及禁止重复修订。桌面与 390 像素宽屏检查完成，窄屏无横向溢出，浏览器没有脚本错误。
- 本地交互检查没有调用真实模型，也没有将测试候选发布到生产。真实模型能力证据单独保存在模型评估报告中。
