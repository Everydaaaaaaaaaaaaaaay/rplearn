# 听力笔记短答合同

`listeningCompletion` 用于听完整材料后提取短答案。与全文听写分别记录；题目保留自己的完整语境，不能依赖开场故事。雅思作者稿的 `ielts.proposed.listening-note` 是后续适用对象，本次未将其转成正式题或伪造音频。

## 数据与判题

- 作者字段为音频、明确的 `acceptedAnswers`、规范化规则和 `wordLimit`（1—8）。作者答案超限拒绝入库，公开题只给 `audio.assetId` 与词限，不给脚本、声线、答案或判题配置。
- 以原始输入按固定 ECMAScript 空白集合计词，包括换行、NBSP、BOM；连字符和撇号不拆词，零宽非空白不是分隔符。这是产品操作规则，不声称适用于所有官方考试。
- 提交复用 `kind:text`；符合规范化的明确变体可通过，干扰项、整段抄录或超限答案不得通过。超限由服务端判错，客户端提前显示词数并禁用检查。空白不可提交，跳过沿用既有合同。
- 复用挑战快照内的媒体授权，不引入公开脚本接口。题库插槽与后台筛选识别新类型；自动生成尚未开放该题型。

## 原生交互与发布边界

沿用紧凑播放器；笔记空位下方是短答输入线和词数。首次音频不可用或未完整听过时禁用检查；已完整听过后的重播失败保留原先的听完证据，不清空答案。普通填空与听写的输入规则不变。

旧版 `LearningQuestion.Kind` 是封闭枚举，不能解码新类型。本次只交付代码支持，正式库不新增此类题。实际投放前必须同时处理开始、活动恢复、历史补答和同账号旧设备的版本兼容，不能只在首次抽题过滤。考试题还需要独立的尝试、进度和产出反馈合同，不能直接用普通星星奖励代替。
