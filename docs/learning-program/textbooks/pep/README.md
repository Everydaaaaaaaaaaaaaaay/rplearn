# 人教版英语教材参考库

更新时间：2026-09-25。机器可读入口为 [catalog.json](catalog.json)。

本库收录当前可核实的人教版初中英语（按 2022 年课程标准修订）和普通高中英语（2019 版）的**册次、单元题名、官方电子教材阅读入口及配套资源入口**。它供教学研究与后续原创挑战设计时定位资料；仓库没有复制电子教材全文，也不是可直接用于出题的完整知识库。

## 覆盖范围

| 学段 | 已登记册次 | 来源和核对深度 |
| --- | --- | --- |
| 初中 | 七上、七下、八上、八下、九上，共 5 册 | [人教社新版英语配套资源目录](https://www.pep.com.cn/zslth/yyptzy/)及各册页面；42 个单元（含 3 个预备单元）、288 个官方音频入口。已核对单元题名和页面列出的音频位置，未逐篇核对学生用书正文。 |
| 高中 | 2019 版必修第一至三册、选择性必修第一至四册，共 7 册 | [教育部 2022 年精品课课例目录](https://www.moe.gov.cn/jyb_xxgk/s5743/s5744/202304/W020230420309231498801.pdf)确认大多数单元题名；必修二 Unit 2 另由[教育部 2023 年课例目录](https://www.moe.gov.cn/jyb_xxgk/s5743/s5744/A06/202404/W020240402490580211463.pdf)确认。共登记 36 个单元（含 Welcome Unit），每单元列一个目录中的活动样本。课例目录只列部分活动，未核对教材完整课文与练习。 |

新版九年级下册未列在上述人教社配套资源目录中，因此放在 `knownGaps`，不混入旧版“九年级全一册”。当前目录也不包含 2013 年前后旧版初中系列或高中旧课标系列；后续若需兼容旧教材，应另建版次，避免同名年级误配。

12 册均已关联[人教社教材电子版目录](https://jc.pep.com.cn/)列出的阅读入口，`readerUrl` 使用其 HTML5 阅读页。已实际打开七年级上册的教材页面样本：该册《致同学》说明单元分 Section A、Section B，前三册有语音板块，全套有语法板块，部分项目与拓展阅读以星号标记。这属于一页实物核对，**其余页面和其余 11 册尚未逐页研读**；`contentReview` 与 `fullTextReviewed` 分别记录这两个边界。官方阅读服务可能限制自动请求，链接可用性应在人工阅读时再次核对。

## 使用规则

1. 先按 `edition` 和 `id` 选册，再按 `number`、`starter` 或题名选单元；不能只用“七年级上册”匹配不同版次。
2. `coverage` 表示**实际核对的范围**。`fullTextReviewed: false` 的单元只能用于选题方向、定位音频和寻找原书，不能由单元题名推断具体词汇、语法、课文体裁或年级难度。
3. 出正式挑战前，须从合法取得的学生用书与教师用书逐页记录语篇、练习、交际目标、语言知识、前置知识和页码，再由人工审校原创题；沿用[教材内容核对要求](../../textbook-content-audit-20260925.md)。
4. 电子教材和音频链接仅指向人教社官方资源；不要复制音轨、课文、图片或整册 PDF 到仓库或生产服务，也不要把官方页面允许浏览理解为可商业再分发。获得教材文件使用许可后可另建受控素材存储和授权记录。

## 数据维护

`catalog.json` 保留原始官方链接和核对日期。更新单元题名或资源链接时重新访问对应来源，保留明确的版次。运行：

```sh
python3 Scripts/verify-pep-textbook-library.py
```

当前库与 App/服务端的正式题库没有自动连接；它是编题前的来源登记和版本边界。完整教材页、可使用的权利范围和逐单元内容笔记仍需补齐。
