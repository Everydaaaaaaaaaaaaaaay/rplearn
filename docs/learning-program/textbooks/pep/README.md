# 人教版英语教材参考库

更新时间：2026-09-25。机器可读入口为 [catalog.json](catalog.json)。

本库收录当前可核实的人教版小学英语 PEP（三年级起点，按 2022 年课程标准修订）、初中英语（按 2022 年课程标准修订）和普通高中英语（2019 版）的**册次、单元题名、官方电子教材阅读入口及配套资源入口**。每册的首轮观察和挑战设计参考见[逐册研读记录](volume-study-notes-20260925.md)。仓库没有复制电子教材全文，也不是可直接用于出题的完整知识库。

新版六年级下册、九年级下册未列在上述人教社配套资源目录中，因此放在 `knownGaps`，不混入旧版册次。人教社还说明小学新版设有一、二年级预备级教材，供地方选用；目前未核实其逐册目录、具体册数与电子教材入口，同样记为缺口。当前目录不包含旧版小学、初中或高中系列；后续若需兼容旧教材，应另建版次，避免同名年级误配。

19 册均已关联[人教社教材电子版目录](https://jc.pep.com.cn/)列出的阅读入口，`readerUrl` 使用其 HTML5 阅读页。已实际打开七年级上册《致同学》的页面样本；另研读了人教社公开展示的小学、初中和高中教材内页样本，以及三下 Unit 1 的项目听力文本。**尚未逐页研读 19 册学生用书**；`contentReview` 与 `fullTextReviewed` 分别记录直接阅读与全文核对的边界。官方阅读服务可能限制自动请求，链接可用性应在人工阅读时再次核对。

## 使用规则

1. 先按 `edition` 和 `id` 选册，再按 `number`、`starter` 或题名选单元；不能只用“七年级上册”匹配不同版次。
2. `coverage` 表示**实际核对的范围**。`fullTextReviewed: false` 的单元只能用于选题方向、定位音频和寻找原书，不能由单元题名推断具体词汇、语法、课文体裁或年级难度。
3. 出正式挑战前，须从合法取得的学生用书与教师用书逐页记录语篇、练习、交际目标、语言知识、前置知识和页码，再由人工审校原创题；沿用[教材内容核对要求](../../textbook-content-audit-20260925.md)。
4. 电子教材和音频链接仅指向人教社官方资源；不要复制音轨、课文、图片或整册 PDF 到仓库或生产服务，也不要把官方页面允许浏览理解为可商业再分发。获得教材文件使用许可后可另建受控素材存储和授权记录。

## 数据维护

`catalog.json` 保留原始官方链接和核对日期。更新单元题名或资源链接时重新访问对应来源，保留明确的版次。运行：

```sh
python3 Scripts/verify-pep-textbook-library.py
```

当前库与 App/服务端的正式题库没有自动连接；它是编题前的来源登记和版本边界。逐册研读记录已有第一轮，但完整教材页、可使用的权利范围和逐单元内容笔记仍需补齐。
