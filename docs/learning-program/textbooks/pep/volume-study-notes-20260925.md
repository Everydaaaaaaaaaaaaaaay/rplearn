# 人教版英语教材逐册首轮研读记录（2026-09-25）

本记录用于以后编写**原创**单元挑战。它区分了「看过教材页面或公开的实际内容」和「核对了人教社单元、活动目录」：19 册均核对了册次和单元结构；小学、初中部分核对了公开配套活动索引；其中 8 册核对了公开的学生用书页面样本，三下另核对了实际项目听力文本。高中课例目录只提供部分活动，不等于已读完整课文。每册的版本、单元和链接在 [catalog.json](catalog.json)；本记录没有复制教材全文或图片。

## 资料与核对深度

- [小体例](https://www.pep.com.cn/xw/zt/hd/12/xjcjs/xx/202409/t20240920_1995564.html)：人教社小学英语新版介绍及三上 Unit 2 教材内页。它说明三至六年级 8 册共 54 单元；每单元由问题牵引，Part A/B 必学、Part C 选学，并逐步增加读写和项目活动。当前公开资源尚缺六下。
- [初体例](https://www.pep.com.cn/xw/zt/hd/12/xjcjs/cz/202510/t20251024_2004130.html)：人教社初中英语新版介绍及七至九年级多个教材内页样本。它说明正式单元共 44 个，七上另有 3 个预备单元；七年级重读写结合，八上起增加单独写作页，Section A 侧重听说、Section B 侧重读写，Project 为选学。当前公开资源尚缺九下。
- [高体例](https://www.pep.com.cn/ebook/rjs11gzjksjsyy/)：人教社 2019 版高中英语教材介绍第 44–49 页。展示必修一 Unit 1 和必修三 Unit 4 的页面缩图，并说明增加语音、视频、拓展阅读及策略提示，活动强调理解、分析、评价与表达。
- [小学及初中官方音频目录](https://www.pep.com.cn/zslth/yyptzy/)：逐册核对所有单元题名、听力位置与公开活动名称。只有列在页面上的栏目可确认为目录事实；不能从栏目名推断语篇内容。
- [教育部课例目录](https://www.moe.gov.cn/jyb_xxgk/s5743/s5744/202304/W020230420309231498801.pdf)、[必修二补充课例目录](https://www.moe.gov.cn/jyb_xxgk/s5743/s5744/A06/202404/W020240402490580211463.pdf)：核对高中七册单元题名及至少一个公开课例活动；这些不是课文或习题全文。
- [人教社电子教材目录](https://jc.pep.com.cn/)：核对每册对应的官方阅读入口。七上《致同学》页面已直接查看；其他各册的电子教材页面仍需要后续逐页核对。

## 编写单元挑战时的用法

1. **定范围**：先确定版次、册次、单元和正式出版页码。若本库只到目录或课例层级，先打开对应电子教材及教师用书，补足语篇、练习、语言目标、前置知识和选学/必学属性。
2. **定可测能力**：为一段原创剧情选一个真实任务，例如获取信息、比较证据、给建议或写回应；再安排理解、应用、反馈。题型随能力走，避免单词选择题覆盖全学段。
3. **写原创材料**：借鉴教材的主题、任务结构与难度，不移植课文、插图、音频或原题；每题记录来源单元与改写理由。人物关系、线索和后果应贴合 App 角色设定。
4. **审答案与进度**：闭合题核查唯一答案、可接受变体与语篇证据；开放题用内容、语言、任务完成度分项判断。完整中文译文若会泄露答案，应调整呈现。答对数量只能累计应用内练习进度，升级为学校年级水平前需独立效度验证。

建议为每个候选挑战保存 `sourceVolumeId`、`sourceUnitNumber`、`sourcePage`、`evidenceUrl`、`requiredOrOptional`、`languageObjective`、`discourseType`、`prerequisites`、`originalScene`、`questionEvidence`、`answerVariants`、`reviewer`。其中 `sourcePage` 和具体教学目标不能从当前目录自动生成。

**下一轮必须补足：** 小学一、二年级预备级和新版六下、初中新版九下的逐册资料；其余册次每单元的原书页码、语篇与练习分析；高中七册的完整活动链及难度审校。本记录可指导编题研究，尚不能将现有 144 个挑战判为教材级题库。
