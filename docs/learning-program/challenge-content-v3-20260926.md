# 单元挑战 v3：逐题编写批次（2026-09-26）

## 本批内容与上线口径

本批重写 72 个角色单元挑战：Oliver、Ruby、Marcus 各覆盖小学一年级到高中三年级，每角色每水平 **2 个不同情境**，每单元 **6 道题**，共 432 道。题干、选项、标准答案、解释和剧情均逐条写在 `Backend/src/modules/learning/unit-seeds-v3.ts`；构造函数只负责编号、教材引用和数据形状，没有自动生成题干或反转词块。正式抽题池只选 v3，已开始或完成的 v2 挑战继续使用数据库中原模板判分和回看，不改写历史作答。

每单元至少包含单选、多选、词块排序和控制性短写四种交互。六题围绕同一个任务，从信息提取、条件判断、语言组织逐步走向回应或迁移；题目不需要每道都直接问剧情事实。低年级短写保留姓名、数量、方位等可直接定位任务；初中至高中短写需至少两词或四词，标准答案不能整段从英文剧情连续抄出。对明显存在等价表达的 30 个高年级单元，逐单元记录可接受答案变体，服务端按等价答案判分。

代表单元：三年级《窗边的植物照片》让学生同时核对光照、叶色和数量；八年级《两份读书报告》让学生区分相反评价和目标读者需求；高三《夜间海滩的两种方案》要求区别调查范围、生态保护与渔民的夜间安全。场景和人物事件为本项目原创，未复制教材课文或原题。

## 教材依据与难度边界

编写前使用[人教版逐册首轮研读记录](textbooks/pep/volume-study-notes-20260925.md)与[教材目录](textbooks/pep/catalog.json)定位主题和活动方式，并复核人教社[小学新教材介绍](https://www.pep.com.cn/xw/zt/hd/12/xjcjs/xx/202409/t20240920_1995564.html)、[初中新教材介绍](https://www.pep.com.cn/xw/zt/hd/12/xjcjs/cz/202510/t20251024_2004130.html)。小学以生活场景、问题链和逐步表达为参考；初中增加多材料、理由比较和项目回应；高中加入来源范围、利益冲突与有界限的表达。这是课程设计参考，并非逐课同步。

小学一、二年级只有预备级方向资料，尚无逐册页码核对；小学三至六年级和初中部分单元有公开教材样页，其余不少引用仍只有出版社目录或活动介绍；高中主要依据公开课例目录。现有题目不能宣称经过全套教材逐页比对，也不能仅凭应用内正确数认定学校年级能力。

## 核查结果与未完成的审校

- 72 个 ID 唯一；每角色每水平 2 个不同剧情；全部为六题且覆盖四种交互。选择题答案唯一，多选答案为原选项的两个不同值，排序词块可还原，所有标准短写答案符合长度限制。
- 自动短写扫描：初一至高三 **0/36** 道标准答案连续出现在对应英文剧情；小学一年级至六年级为 **28/36**，主要承担定位、拼写或计算后的记录任务。扫描不能证明高年级答案唯一、表达自然或题目有真实区分度。
- 定向内容测试、TypeScript 类型检查、独立临时 PostgreSQL 的六题结算/补答/等价答案测试通过；iOS Debug 产物已构建并安装。真实账号下的服务端生成入库和长期学习效果尚未验证。

本批仍需教师逐题审校和真实学习者试测，尤其是题干能否独立理解、多选干扰项是否公平、短写可接受表达是否遗漏。当前短写只支持标准答案及有限人工列出的等价答案，不适合以一次精确判分代表自由写作能力。每角色每水平目前只有 2 个预设单元；预设用尽时仍按服务端规范生成六题并审查入库，预设量后续还需继续增加。
