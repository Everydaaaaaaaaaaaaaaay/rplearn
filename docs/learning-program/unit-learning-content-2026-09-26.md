## 2. 教材映射方式

建立“能力目标—教材证据—角色情景—独立练习”链条，不复制课文，也不把题库做成某教材目录镜像。

每个参考记录包含出版社、系列、起点年级、学制、版次、册次、ISBN（可取得时）、单元、印刷页码、电子页码、原始链接、读取日期、具体依据、是否已核读。新版旧版并存时独立记录；不能拿旧版单元号给新版挂名。

每个产品档位维护：

- 能做什么：如介绍物品、表达时间、提出请求、描述经历、解释理由、澄清误解。
- 目标词汇与先修词汇、词块、语法结构、语用要求和可接受变体。
- 题干阅读负担、语音长度/语速/口音、视觉支持、输出长度与干扰项强度。
- 跨教材一致目标、只在部分版本出现的目标、具体产品排序决策。
- 九星目标矩阵，包含多次间隔复现和不同语境迁移；不是九个难度完全相同的计分桶。

词频只能帮助找超纲词，不能证明年级匹配；高中教材的必修/选必册次也不与高一/高二/高三机械一一对应。学段 StudyStage 是用户背景，不得覆盖英语难度 DifficultyLevel。

## 3. 十二档内容骨架

以下是待教材逐册验证的创作方向，不是已完成的教学大纲。

| 档位 | 任务方向 | 主要交互与支架 |
| --- | --- | --- |
| 小一 | 问候、颜色、数量、身边事物辨认 | 视听为主、图片支持、很短的回应，不要求长句拼写 |
| 小二 | 简短需求、喜欢与不喜欢、位置与日常动作 | 听辨和指认、简单词块、短句选择 |
| 小三 | 自我介绍、朋友家庭、物品与基础描述 | 简短交际、图片配对、少量句子构建 |
| 小四 | 日常安排、天气、衣物、购物基础沟通 | 时间/地点表达、完整短句、逐步减少提示 |
| 小五 | 活动计划、人物比较、规则与请求 | 句子补全、语境选句、基础主动输出 |
| 小六 | 简短经历与未来安排、多步生活任务 | 时态对比、指令理解、短语境迁移 |
| 初一 | 人与社区、习惯、能力与活动 | 结构化交际、简短信息表达；不以名词识别充当整档练习 |
| 初二 | 经历、比较、计划、建议与因果 | 混合句式、自然短对话、减少词库支架 |
| 初三 | 更完整的理由、变化、条件、观点 | 在新情景中选择/构建合适表达，强调常见语法误区 |
| 高一 | 独立安排生活/旅行、清楚叙述和澄清 | 词块搭配、语体与语义区分、较复杂但自足的句子 |
| 高二 | 合作、环保、文化等议题的解释与论证 | 从句与信息组织、语用适切、短答案变体 |
| 高三 | 综合迁移、改述、语气与逻辑精确性 | 更少提示、多目标整合；不以生僻词或偏题制造难度 |

同一主题可以出现在多个档位，但任务必须变化。例如“Ruby 的海岸活动”：小一辨认物品，小四安排时间，初三提出环保建议，高二协调意见并解释限制。不会复用同一题库只改变长度或分值。

## 5. 单元创作合同

单元头部：稳定 ID、内容版本、角色蓝图版本、level_key、九星目标阶段、先修目标、主要/复现目标、场景、预计时长、作者、参考记录、审核状态、内容指纹。

剧情：开场、少量中段推进、收束，短句分镜；每幕包含说话人、正文、可选翻译、舞台动作、音频与配图引用。剧情不能提前逐字喂出后续题目的正确答案。

每题必须写齐：

| 字段 | 要求 |
| --- | --- |
| 稳定题目 ID / 类型版本 | 与排序和显示位置无关；补答始终认同一题 |
| 能力目标与难度理由 | 明确到底测什么，以及为何属于该档 |
| 独立题干 | 完整包含情境和必要信息；不写“刚才她说了什么” |
| 选项 / 词块 / 媒体 | 稳定 ID，允许乱序；图片不能歧义；音频与文本一致 |
| 答案 / 变体 / 判分配置 | 正确答案、替代拼法、标点大小写策略、非答案反例 |
| 干扰项理由 | 是学习者可能犯的具体错误，不是明显胡话凑数 |
| 解析 | 用中文解释为什么，点出误区，配不同例句；不只重复正确答案 |
| 提示 | 提供方法，标记是否揭示答案 |
| 可访问性 | 朗读顺序、操作说明与图像描述；无障碍文本不能意外泄露答案 |
| 复核结果 | 无剧情盲做、答案歧义、难度检查、音频实听、界面实做 |

首版每单元 1–2 个主要目标、适量复现目标，默认 6 题。六种题型按教学需要混合，不强制每单元正好每种一题。

## 6. 剧情与题目独立性的样例

原创构思：Ruby 在咖啡馆门口准备周末海岸活动，桌上有报名卡和用品。剧情负责人物动机与气氛，题目自带小情境。

合格题：“你想礼貌地要一杯水，应选择哪一句？”题目列出完整选项。无需记得 Ruby 刚才拿了什么。

不合格题：“Ruby 刚才拿了什么？”“根据上面的故事，她为什么迟到？”“她下一站要去哪？”这些必须依赖剧情事实。

“礼貌要水”这里只展示独立性，不作为小一年级定稿题，也不声称已经对应某教材单元。正式题必须经过对应档位的词汇、句式、读写负担核对。

盲做验收：从单元中随机抽走任一题，仅显示该题本身和其媒体，编写者仍能解释题意并唯一判分。短交际题可以有本题自己的两句对话，不能依赖前面的剧情或上一题答案。

## 7. 首版题型合同

1. 情境选句：理解功能与合适表达；至少给清晰语境，避免两个选项都自然成立。
2. 词块组句：提供完整语义目标，接受合规等价次序；点击放入/撤回，拖动只是补充操作。
3. 补全表达：选词或短输入，限定所需信息与答案范围；不能仅凭随意 LLM 判定。
4. 听辨选择：本题独立录音与选项；重听、慢速可用；字幕揭示与计分状态有明确关系。
5. 配对：词义/图片/表达功能，所有配对完成只算一道题；防止固定位置提示答案。
6. 短听写或受控改写：按档位启用，明确目标形式和可接受变体；低年级不强制复杂输入。

语音角色演绎不等于发音评分。首版不做开放口语能力认证，也不把 ASR 转写正确率冒充发音能力。

## 8. 原创与复核流程

预设内容由本任务编写者亲自完成，顺序为：读参考单元→填写目标矩阵→写角色剧情→逐题出题与解释→独立重做→删除剧情盲做→级别反证→音频实听→设备实做→发布。

可以用脚本查 schema、重复、答案可达性、缺失媒体与超纲词；不能用模板扩写脚本替代原创。不得使用“换个人名、换个食物”生成几百个所谓不同单元。

上线硬性拒绝：多解未登记、语法错误、题干缺条件、答案依赖剧情、初级题干超纲、音频错读关键点、素材缺失、角色失真、同题伪装新内容。未核实教材引用不得标成“教材对齐”。

初期所有种子逐题复核；条件允许时再引入独立教师审校与目标用户试做，记录实际审校者和证据。当前没有外部审校，不能虚构。

## 9. 用尽后的服务端生成

生成输入只能来自审核过的角色蓝图、档位目标、先修词表、语法范围、题型白名单、剧情长度限制、答案合同、最近已发布单元的脱敏结构摘要和重复排除条件。不能把用户私人聊天塞入公共内容生成提示。

流水线：

`合格池不足/用户用尽 → 去重生成任务 → 草稿 → 结构检查 → 答案与独立性检查 → 难度/角色/近似重复复核 → 可发布 → 公共池`。

- 按角色×档位×目标维护库存，使用“低水位预生成+真正用尽时补充”，降低用户等候。题池对其他用户可复用，对同用户同角色不重复分配。
- 生成数量与重试有上限；模型/规则/提示版本可追溯。主请求不长时间同步等待；使用 worker、退避、超时和断路保护。
- 独立审核调用不沿用作者的推理自证；结构、确定性答案和去重检查仍由程序执行。模型审核也可能出错，不能把评分高当唯一上线条件。
- 前几个批次全部由编写者逐题审阅，建立失败集；仅对已验证蓝图与可确定判分题型逐步开放自动发布。高歧义或新题型留在待审池。
- 生成请求成功不代表可用；审核失败的候选不进入用户抽取范围。题库不足时保留机会并提示准备中，不降低年级、不重复旧单元、不把未经审核内容直接交给用户。
- 共享单位是公开角色蓝图与课程版本；自建私有角色的内容默认私有，不能为了公共补库泄露用户自定义设定。
- 给公共单元配置撤下、修订、质量反馈和受影响尝试处理。统计单题首次错误率、误判反馈与审核缺陷，不以点击率选择题目。
- 作者调用为服务端内容成本，不能未经产品决定按每次题库准备扣用户聊天额度；复用既有 AI 路由基础设施时须检查计费 task 和输出上限。

## 10. 对学习有效性的验证

首答正确率、提示使用、补答获得进度、不同语境的新题表现分开记录。补答原题是练习成果，不直接证明长期保留。

九星后段单元安排此前目标的陌生语境题，题目仍可独立作答；后续单元适量复现已学目标，保持新剧情新题目。追踪隔日/更长间隔的正确表现，避免所有成长都来自立即记忆刚看过的答案。

持续验证：哪些题在低档过难、哪些高档题无需学习就可猜对、哪些解释能减少后续同类错误。没有真实结果前，不声称 540 点对应客观学校学年能力，也不宣称学习效果已得到证明。

## 首批实际内容：小学三年级

正式文件位于 [Backend/config/learning](../../Backend/config/learning/README.md)：三个主角色各三个不同单元，共 54 题，逐题亲自编写剧情、题干、提示、解释、答案和自审记录。题目无需记忆剧情；输入任务给出明确目标，不让开放语境中的多个合理答案被误判。

本批处理了 grandmother 的中英称谓覆盖、颜色组合的两种合法语序、数字与单复数、物主词与介绍对象、请求与感谢的区别。书店、海岸志愿活动、家庭摄影及餐车场景来自真实角色设定。低年级剧情提供中文译文；题目用中文情景和给定词块降低英文题干负担。

课程来源与限制随目录入版本管理。课标扫描页已实际目视阅读；人教 PEP、精通的交友页面提供正文依据，其余主题目前只核对 PEP 目录，并根据课标一级范围编写，不声称对应单元全文、词表已精确匹配。2025 四年级官方书目已确认，但阅读器返回验证页；旧链接返回错误，未当作读取成功。译林正文链接本轮未成功获取；外研仍为书目取证。

发布器将 9 个来源化能力目标、逐题审核和内容哈希绑定，整批发布事务避免半批成功。自动检查只能验证合同及已编写的正误反例，不能证明题目真实教学效度。当前无独立教研审核、真人测试或听说测评证据。这 9 个样板不替代既定 36 个跨档样板及后续扩库目标，且本批 54 个可得点数尚不足以完整获得第一颗 60 点星星；生成补库、更多原创内容与课程覆盖仍要继续完成。
