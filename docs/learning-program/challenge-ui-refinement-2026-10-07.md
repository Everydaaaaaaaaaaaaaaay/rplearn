# 单元挑战界面收紧记录

本轮针对故事沉浸与底部操作区，保持教学题干、提示、解析和必要的退出确认。手动切换水平的强提醒及独立主线剧情边界不在本次改动范围。

| 位置 | 调整前 | 调整后 |
| --- | --- | --- |
| 故事顶栏 | “开场故事”阶段标签，正文再次展示单元名 | 顶栏直接显示故事名，同行角色使用当前角色名 |
| 故事操作 | “继续故事”加另一行“直接开始题目” | 继续与跳过图标共用一行，末段只有“开始挑战” |
| 答题底栏 | 检查按钮加一行跳过文字 | 检查与跳过图标同排；输入时原位换成收起键盘图标 |
| 听写键盘 | 中途候选版使用额外键盘工具栏，占用更多空间 | 无额外工具栏，收起键盘与检查处于同一行 |
| 完成页 | 重复解释归入水平、补分与归零规则 | 直接展示本轮获得点数、水平及待补答题数 |
| 失败与提示 | 长句说明重试或跳过流程 | 简短失败状态，保留原重试、跳过、教学提示与解析 |

图标按钮保留描述性辅助功能标签；所有常规底部图标触控区域至少48×52点，大字号仍可滚动访问操作。播放区仍是紧凑单行，没有重新引入大音频卡。

## 实际验证

- iOS27模拟器正式四级听选、听写：真实音频完整播放前不能提交，完整播放后解锁；慢速重播、停止重播不撤销已听资格，公开页面不展示录音脚本。输入时收起键盘与检查的垂直中心误差不超过2点，跳过按钮退出该行；播放区高度不超过64点。
- 选择、排序、配对、填空的退出、题干与底栏可见性通过。
- 故事完整发生在题目之前，译文按需展开，末段只保留单一开始入口。最初新增标题标识受外层SwiftUI标识传播影响，测试无法定位；改为按真实标题检验后通过，不将定位失败当作产品未显示。
- 最终故事证据：`build/DerivedData/VerificationResults/20261007T030848Z-39689.xcresult`。正式媒体与四题型证据：`20261007T025827Z-36458.xcresult`中的两个通过用例；该次故事定位失败由前述最终单测复核。
- 已读取真实截图：最终故事末段、四级听写及四种题型；截图存放本轮build证据目录，未将生成文件加入Git。Computer Use的Device Hub窗口映射返回缩略窗口及`windowNotFoundAtPosition`，因此交互结论来自原生UI测试，不冒称本轮手动逐页通过。

依用户授权仅清理当前模拟器可再生的`com.apple.coresymbolicationd`缓存；未清空设备或App数据。关闭模拟器后系统盘恢复约5GB可用，不能把全部空间恢复都归因于约700MB缓存删除。最新版随后使用`Scripts/preview.sh`安装，正式四级单元通过公开字段注入离线Debug预览，供用户继续查看；不提交生产学习成绩。
