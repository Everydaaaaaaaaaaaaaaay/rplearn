# 独立声音配图

新增 `audioMatching`：2–4段独立声音对应图片，右侧必须比声音多至少一项；全部声音都需显式配对，不自动补全最后一项。同一底图可配不同简短可见标签，例如“会／不会”，避免用摔倒、哭泣等不可靠画面表达能力否定。

声音播放和当前配对焦点分开。可慢速、重播、切换图片、撤销；将已用图片交给另一声音会移除旧配对，不偷偷交换答案。所有声音听完、所有图片加载成功且配对完整后可检查。整题全部正确才奖1点；部分正确返回逐项反馈，补答沿用幂等奖励与冻结题面。

公开题面只给音频身份，不给原文或答案。声音和图片分别按挑战身份稳定打散，重进和补答保持顺序。资源授权、素材发布校验、语义去重、后台预览与答案编辑覆盖新类型；纯文字生成仍不得发布未验收音频。未改数据库结构。
