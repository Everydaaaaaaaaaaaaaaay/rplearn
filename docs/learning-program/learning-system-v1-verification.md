## 已实现

- 原生聊天挂接学习观察和自选任务，保留原有角色回复及打字节奏；216 个任务、36 个听力材料。
- 量化证据、确认间隔、复用时间、每日请求预算、经验去重、按账号本地持久化与证据删除。
