# 公共题库与角色同行挑战

本轮将原先按角色存放的题目提取为公共题库。普通角色不再要求单独编写一套题；主角色已有的完整剧情单元优先保留，耗尽后也使用公共组卷。

## 内容与抽取

- 首批导入现有正式目录的 87 个单元、522 道题，覆盖小学一年级至高中三年级。保留原题、答案、解析、音频、图片和教材参考；来源校验与已有逐题审核哈希必须一致。
- 题目拥有独立身份、不可变版本、年级、场景、学习目标、题型和角色适用范围。题干与材料决定初始身份，调整答案、解析或选项顺序不会成为可重复得分的新题。
- 87 条组卷规则沿用原单元的六个目标/题型插槽与先修条件。严格匹配年级、场景、目标、题型和角色范围；缺题时不降级、不凑题。规则保存在版本化目录，后台提供覆盖统计和预览。
- 同账号跨角色共用已见题、掌握情况；优先新题及尚未覆盖的目标。已见但未答对的题留在原挑战补答，已掌握题至少间隔七天才能复习。不同账号可以抽到同一道公共题。
- 普通角色使用五类通用同行场景，剧情只提供环境，不含解题必需信息。英语开场按低小、小学和中学分档；角色姓名由真实角色资料提供，不虚构职业，也不将题内第三人或录音声线冒充当前角色。
- 现有手编题是第一批可复用材料，不代表完整课程或独立教师验收。角色专属剧情、更多同目标变式及独立教学质量评估仍可逐步增加。

## 挑战与计分

聊天累计、1000 字触发、角色独立循环、全局水平与升星逻辑不变。组卷时保存整个挑战快照及各题版本；后台修订、下架或停止组卷不改变已开始挑战。主角色专属单元仍引用不可变单元版本。

每个账号对每道公共题只有首次答对获得 1 点。补答只处理尚未答对的题；重复请求不会重复发分。到期复习答对记录为正确，但奖励 0 点，不产生新的晋级证据。全局晋级证据按公共题身份去重，情境数量按组卷规则统计，不能通过反复创建挑战扩大证据。

后台修订过或下架过的原题，不会再从旧专属单元绕过审核状态发出；已有挑战继续使用原版本。导入时登记已有答题记录的公共身份，保留既有成绩，不补发、不扣分。

## 后台管理

入口：`/internal/admin/learning/bank`，沿用学习后台管理员鉴权。

支持年级、场景、目标、题型及发布状态筛选，逐题材料/答案/解析检查，鉴权图片与音频预览，版本修订、下架、以现有题为模板另存新题、审核记录、目标覆盖统计和六题组卷预览。写入要求内容哈希未变、版本递增及人工审核确认，服务端校验选项/答案引用；相同材料不能另建身份。

本轮模板新增保留年级、学习目标、题型、参考来源和媒体边界；新增目标、素材与组卷规则走版本化内容目录审核。新建听力/图片素材不通过文本编辑器上传。未将原模型生成链路扩大为自动公共题库生产：原三名主角色的小三/小四生成流程继续保留，其余缺题需要补充公共题库，候选模型题不能自动绕过审核。

## 发布与功能回退

使用 Node 24、项目 pnpm，在 `Backend` 下运行：

```sh
pnpm exec tsx src/cli/learning-bank.ts validate
pnpm exec tsx src/cli/learning-bank.ts publish <validate返回的哈希>
```

生产内容 CLI 使用 `nice -n 10 node --max-old-space-size=128` 执行，避免在小内存服务器上使用默认堆上限加载和校验目录。

生产先部署含 `0040_learning_question_bank.sql` 的后端，再使用同一归档的 `dist/cli/learning-bank.js validate` 和 `publish <哈希>`，加载既有生产环境但不打印凭据。迁移默认关闭公共组卷，发布事务核对已发布来源、导入并启用。重复导入不会覆盖后台已经修订的题目。

```sh
node dist/cli/learning-bank.js pause
```

`pause` 只停止创建新的公共组卷，已有快照、答题、补答和历史仍可读取。重新执行已验证目录的 `publish <哈希>` 可恢复。首次启用且生成快照后，旧二进制不认识快照挑战，**不能直接切回旧版本**；功能回退使用 `pause`，代码问题应部署保留快照读写能力的修复版本。保留上一归档和数据库备份，不删除学习数据解决故障。

- 隔离 PostgreSQL：十二年级普通角色、跨角色并发去重、账号隔离、首次得分/重放/补答、版本快照、下架、七天复习零奖励、管理端鉴权与写入校验。
- 相关学习单元测试 33 项通过；前一轮 42 项相关集成路径中 8 项受本机资源压力超过默认 5 秒，保持断言、延长本次超时后 23 项相关复测全部通过。
- 后台浏览器实际检查：筛选、查看题目、图片与录音鉴权代理、在隔离库发布修订、组卷预览。没有用真实生产题目的修改来做 UI 验收。
- 本轮保持客户端公开挑战合同，没有修改 Swift，也未将后台验收当作真实设备上的学习效果验证。

最终类型检查、任务涉及文件 ESLint、依赖架构检查均通过；收尾复跑学习模块单测与公共题库/学习引擎集成测试，共 10 个文件、45 项通过。
