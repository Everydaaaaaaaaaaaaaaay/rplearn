# 对话学习系统 v1：产品合同与量化规则

版本：2026-09-22。本文取代旧原型中的临时规则；数值是可执行的 v1 产品决策，不是已完成效度验证的测量标准。实现、测试与未完成项须在配套验收表逐项记录，不以回放结果冒充完整体验。

[实现与验收记录](learning-system-v1-verification.md)

## 1. 框架与边界

- 同一正式聊天、原有角色提示词、等待/输入/分条节奏、词典/翻译/通话功能。学习观察不得改变回复延迟或逐条插入考试。默认不增加 NPC 主动问题。普通聊天没有练习横幅、保存返回或模式配置。
- 全账号旅程：参与经验。共同篇章：按角色过滤证据的视图，不是第二套经验。能力画像：全账号的文字沟通与听力，分别记录。
- 文字能力：表达选择与理由、描述经历、安排计划、澄清误解。听力：明确细节、主旨、意图/简单推断。v1 不覆盖完整英语能力，不合成总英语分数。
- 绝不评价发音、口音、口语流利度、口语等级；没有跟读评分、录音考试或口语题。语音转写可作为参与，但不纳入独立文字能力证据。
- 随时聊天，不强迫练习；不活动不催促、不欠任务，不因拒绝或暂停扣关系/经验。普通问候原策略不变。
- 入口：聊天右上角设置中的“共同篇章”；打开即看成果，不能要求选角色/情境/判定来源。全账号画像在同页，不同角色只是过滤。听力由用户点击开始，不在聊天中自动播放。

## 2. 规则清单（唯一产品参数）

| ID | 确切规则 | 用户效果 |
|---|---|---|
| OBS-1 | 用户主动开启学习记录后，只处理新发出的消息，不追溯历史 | 可暂停，暂停不评估 |
| OBS-2 | 同一会话累计 4 条新文本，或最后一条后 90 秒无新消息，提交一批；每批最多 8 条、用户文本 4000 字符、NPC 上下文 2000 字符 | 不等待评分才回复 |
| OBS-3 | 每账号每 UTC 日最多 6 批，每批最多 2 次调用，第二次只重试超时/5xx/格式错误，退避 2 秒；401/403/额度不足不重试 | 失败不变成学习失败 |
| OBS-4 | 批次 ID + 消息 ID + 规则版本做幂等；新消息不被旧批次覆盖。终止/切账号取消任务；保留待处理，不跨账号 | 不错记、重复记 |
| EVD-1 | 观察窗口按明确会话 ID 划分；4 项能力可多标签，每批每项最多 1 条，引用必须来自当前批次用户原文 | NPC 文字不计入用户能力 |
| EVD-2 | 同一技能、同一 UTC 日最多 1 条独立进阶证据；重复原文只记参与一次，不能堆叠能力 | 不刷消息升级 |
| EVD-3 | 工具帮助按批次保守标记；查词、翻译、粘贴来源不明或语音转写均不能作独立证据 | 仍可完成练习、获得参与经验 |
| XP-1 | 每批至少一项有效完成或完成一组听力练习 +10 XP；全账号每日最多 30；相同内容/题组不重复奖励 | 不按字数或消息数计奖 |
| XP-2 | 等级 = 1 + floor(累计 XP / 100)；不代表 CEFR；删除证据不回收经验，但保留不可逆去重摘要 | 不通过删除刷分 |
| TIME-1 | 所有间隔按服务器/设备 UTC 绝对时间，1 日=86400 秒；旅行时区不提前到期 | 展示用用户当地时间 |
| REV-1 | 第一次成功后，下一次可选复用最早 48 小时；再次成功后 7 日；第三次及以后 21 日 | 不是“隔天凌晨立刻到期” |
| REV-2 | 到期仅出现 1 个建议；用户选“今天先不练”延后 24 小时；忽略不弹窗/通知；无累积债务 | 长期离开只看一个建议 |
| REV-3 | 新情境不得与来源主题相同；自然聊天已提供所需证据则自动推进，无需点建议 | 复习不必做成作业 |
| AGE-1 | 能力计算使用最近 90 日证据；已确认但 90 日无新证据显示“需重新确认”，不抹掉历史成就 | 不静默降级 |
| DATA-1 | 本地原型按账号隔离持久化；删除原文撤回相关能力证据并取消来源建议，保留奖励摘要；损坏存档报错，不覆盖原文件 | 可恢复、可删除 |

证据时间取该批最后一条用户消息的发送时间，不取延迟评价返回时间；经验日上限取发奖时的UTC日。UTC 日用于每日限额，绝对秒用于间隔；设备时间倒退不得提前发奖或解锁，回到最近记录时间后才继续。正式上线服务端应成为时间和经验权威，单机原型不是跨设备防作弊证明。

## 3. 文字沟通：4 项能力 × 3 档任务

| 能力 | 第 1 档 | 第 2 档 | 第 3 档 |
|---|---|---|---|
| 选择与理由 | 明确一种选择及一个有意义的理由 | 比较至少两种选择，说明取舍 | 在限制/条件变化后调整选择并解释 |
| 描述经历 | 一个已发生的事件及相关细节 | 至少两个事件的先后关系 | 解释事件原因与结果，并补充感受/反思 |
| 安排计划 | 表达要做的事及时间/地点之一 | 将两项安排按顺序连起来 | 处理冲突，提出可行的替代安排 |
| 澄清误解 | 指明没懂的内容并请求澄清 | 用不同说法解释原意 | 识别误解、纠正并确认双方一致 |

同一次表达每技能最多评一个最高可证实档，不因用长词、句子长或语法复杂自动提档。没有相关任务机会时记“无证据”，不能记 0 分。

每条证据按四项 0/1/2 分，共 8 分：

| 维度 | 0 | 1 | 2 |
|---|---|---|---|
| 任务完成 | 未完成/偏题 | 完成部分要求 | 该档所有要求有原文证据 |
| 可理解性 | 核心意思无法确定 | 结合上下文可理解 | 核心信息清楚，无需猜测 |
| 衔接 | 信息互相矛盾/关系不明 | 基本连贯，局部跳跃 | 所需因果/顺序/对比明确 |
| 语言控制 | 错误导致核心意思失真 | 有错误但不影响核心意思 | 本次表达所需词句准确充分 |

有效成功 = 总分 ≥6，且任务完成=2，另三项都≥1，证据引用有效。不要求 because 等指定单词；拼写小错、片段回答不自动失败。拒绝/停练、未知来源、含糊指代分别记录 paused / assisted / uncertain，不混入独立失败样本。所有分数必须附原文引用及一句理由，模型自报置信度不作为通过凭证。

### 进阶与“提升”的判断

每技能、每档独立计算；由低到高连续显示。状态：未观察 → 已尝试 → 有独立证据 → 待确认 → 已确认 → 需重新确认。

- 待确认：最近 6 条独立、非重复、有明确任务机会的证据中至少 5 条成功；分布≥3 个 UTC 日、≥3 个主题，最早至最晚≥7×86400秒。
- 确认：满足上条后，再完成 2 个不同主题的新任务，分别达到成功阈值；两次相隔≥48小时；与首条证据相隔≥14日。任务不得复用已经公开答案的题目。跨角色不是必需条件（只喜欢一个角色的用户也能进阶）。
- 后续两次确认失败：保留原档，显示一个具体需练点，最早48小时后可重试新任务；第二次确认还必须等到首次证据满14日才开放，提前点击不消耗题目；不清零已有成功。
- “英语有提升”的展示：同一技能从原确认档进入更高确认档；或原来依赖帮助、现在达到独立确认。基线缺失只说“目前已证明能…”，不声称提升多少。
- 用新情境与跨度排除短期模仿，但无法完全排除外部翻译等不可观测帮助；显示“根据本应用内证据”。
- CEFR 不直接绑定档位。完成外部校准之前不输出 A1–C2、词汇量、考试分数或百分比提升。

## 4. 听力：只听音频，选择答案

TTS 使用现有 SpeechService。答题前不显示台词/字幕/翻译，也不通过无障碍标签泄露台词；题干和选项使用简洁中文，避免主要测英文阅读。每题 3 个互斥选项，仅1个答案；位置打乱并保存；不能凭选项长度、语法或常识直接解题。

| 产品听力档 | 台词词数 | 信息结构 | 目标技能 | 音频约束 |
|---|---|---|---|---|
| 听力1 | 20–40 | 日常具体词，一名说话人，1–2个信息点 | 明确细节、主旨、直接意图 | 清晰正常音量；无背景噪音 |
| 听力2 | 41–70 | 2–3个信息点，包含转折/时间变化 | 细节筛选、主旨、一步推断 | 同一固定引擎/音色配置 |
| 听力3 | 71–100 | 3–4个信息点，因果/取舍/间接请求 | 跨句整合、主旨、一步意图推断 | 不靠生僻词或极快语速拔高 |

以上是编题规格，不是 CEFR 官方语速标准。句法、主题熟悉度、推断跨度必须一起检查。v1固定引擎默认速度1.0，不用全局设置偷偷改变难度；同一题的音频引擎、音色、版本做材料指纹。TTS实测时长/词速另记录；音频变化使原题版本失效，不直接合并成绩。

- 一组6题：细节/主旨/意图各2题；每题最多完整播放2遍；两遍内统一计分，不扣“听第二遍”的分；答题前可看题干和选项。
- 正式听力证据：完整播完≥1遍，未显示台词，未切后台中断；整组交卷前不给正确答案，避免提示后续题。
- 播放失败/来电/耳机断开：该次播放不计次数，可以重播；没有成功播放不能计能力或判错；中途退出保留进度，恢复时更换被泄题的题目，不补猜答案。
- 完成后逐题显示答案、台词、中文解释，可继续听；看过答案的题永不再作为该账号评估材料，可作练习。
- 每档首次确认：两组不重题、相隔≥7日且≤30日；每组≥5/6，合计≥10/12，三个技能各≥3/4。第一组通过显示“首次表现达标”，不是升级。
- 更高档确认后才展示听力进阶。不与文字能力加权合成。不测发音或口语。
- 有限题库耗尽要明确显示“暂无未做过的新题”，不能重复题冒充新测评；练习可重复，不再作进阶证据。
- 发布题需内容复核与真机试听；至少50人次首答后检查题目正确率与区分度（通过率<0.25或>0.95、校正题总相关<0.15标记复查）；阈值只触发审查，不自动删题。上线前尚无这些数据，称产品档位，不称标准化测验。

## 5. 主动练习与聊天融合

默认学习记录关闭，首次打开共同篇章可一键开启，说明处理新聊天内容与额外额度上限。开启后无需配置角色、主题或模型开关。

每次只有一个可选建议，选择规则：有到期复用优先；否则最少证据的技能，平局按固定技能顺序；主题选择未用于该技能最近一次成功的主题。用户点击后回到同一聊天，展示一条独立系统任务提示（不得冒充 NPC 发言），用户自己开始；不预填答案、不关闭词典/翻译、不覆盖输入草稿、不另建好友或聊天数据库。完成后自动记录，手动查看回顾不再额外发奖。

能力确认挑战明确标记“独立尝试”；仍可用帮助，用过则转为辅助练习、不用于独立确认，无处罚。挑战有一个明确退出入口。原有聊天内旧习题须与新建议共用打扰预算：一次对话最多1次主动学习邀请、24小时最多1次；v1最保守实现是不自动邀请，只保留用户主动入口。

## 6. 原型与最终产品的一致性要求

原型可以只有开发版入口，账号数据可处于本地试验命名空间，但用户流程、真实LLM、真实TTS、真实聊天与工具、等待节奏、持久化、错误/暂停/删除必须全部真实。确定性回放只能在自动测试中注入，不能成为用户默认体验。没有登录/网络要展示真实状态，不悄悄退回固定回复。原型未完成以下验收不得称“完整”。

| 验收 | 必须可观察的结果 |
|---|---|
| 正常聊天 | 任意回复不会命中固定脚本；保留原有等待、输入与分条 |
| 自动记录 | 第4条/90秒提交，重复回调不重复奖，用户无需保存返回 |
| 帮助来源 | 查词、翻译、粘贴、转写不误计独立掌握 |
| 能力计算 | 6条/3日/3主题/7日和2次确认/48小时/14日边界均有测试 |
| 听力 | 无字幕实际TTS，3选1、2遍、6题交卷、新题去重、错误播放不计分 |
| 全局与角色 | 换角色经验不清零，证据可按角色过滤 |
| 退出重启 | 待评估/听力进度恢复；账号隔离；错误不清库 |
| 删除 | 原文移除、能力重算、来源建议撤销、奖励不重发 |
| 预算 | 每日6批/12调用硬上限，失败不无限重试 |
| 覆盖 | 小屏/深色/大字/无障碍可操作，台词不泄露；后台/断网可恢复 |

## 7. 验收后的下一轮

下一阶段再做测试—优化循环；不能把本文数值当作不可变真理。变更必须增加规则版本、记录原因、对旧证据重算策略和回归用例。先检验错误通过/错误否定、邀请负担、额外调用量，再比较14/30日的新情境独立完成率。未有对照研究前不宣传提高学习效率多少。

资料边界：参考方向为欧洲委员会 CEFR Companion Volume 的活动/能力分维度描述（https://www.coe.int/en/web/common-european-framework-reference-languages/cefr-descriptors）；本次访问官方资源遇到403/超时，未声称已核实具体阈值。本文的6条、14日、5/6等均为我们自己的待校准决策，不归因于CEFR。

## 8. v1 材料范围与实现补充

首版提供216个文字任务（4技能×3档×6主题×3种具体情境），36道原创听力题（3档×12题）。有限题库是明确产品库存，耗尽要停止新评估并保留复听；不能临时生成未经复核的题替补。听力固定走现有SpeechService的Supertonic-3，使用全局旁白F5音色及默认速度；材料版本为supertonic3-F5-default-v1，不同音源/模型/速度版本不合并确认。模型失败不回退Apple，不计播放次数，提示重试。早期Apple音源UI测试只证明流程，不作为最终音源验收。

文字输入单次净增加超过16个字符时保守标记来源不明（可能粘贴、听写或键盘建议），不读取系统剪贴板。短粘贴和应用外帮助无法完全识别，因此“独立”始终指应用内未观察到帮助，不是防作弊认证。任务开始后90秒无输入不作失败；只有实际发送的文字才会进入回顾。

听力第2组在第1组交卷满7日之前不开放新评估，避免用户提前耗尽确认题。复听原题始终可用。90日时效按最后有效确认时间计算；普通一次失误不撤回已经确认的档位，删除支撑证据会重算。

### 听力编题细则

- 每题只考一个目标点；台词最多分别为3/4/5个句子（档1/2/3），单句最多分别为16/24/30个空格分词；数字、专名不用于陌生词难度。
- 档1不含隐含讽刺、双重否定、专业术语；档2允许一次计划变更或转折；档3最多一步推断，不要求文化冷知识。
- 题干≤35个汉字，选项各≤22个汉字。3个选项在语义类型上相同（时间对时间、原因对原因），禁止“以上皆是”。
- 词汇熟悉度不能单靠词数推断；首批是人工编写规格下的实验材料，词频/词义分级与真人难度校准列为发布前门槛。未完成词义级审校的材料不得宣称已达某CEFR等级。
- 听力1/2/3可自行选择；不强迫从最低档开始。但只能展示已经按标准确认的单项档位，不外推完整英语等级。

### 可复现的词汇门槛

首批材料增加自动词频筛查：复用随包learner_dictionary.sqlite的bnc/frq，取两者非零值的较小排名；用lemma/exchange与明确的不规则动词表还原词形。cannot拆为can/not、去除所有格's，按英文词次统计。每题至少90%的词次在档1前2000、档2前3000、档3前5000以内；未知排名算表外，不默认为常用。校验脚本为Scripts/check-learning-materials.py。当前三个档位最差覆盖率分别为92.0%、90.4%、97.4%。

词频门槛与词数、单句长度、信息点、推断跨度同时适用。频率不等于词义难度：句中具体词义、含蓄意图与选项合理性仍须内容审校；真人作答数据决定后续题目校准，不从词频排名直接推导CEFR。
