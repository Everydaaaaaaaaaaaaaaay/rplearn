# 学习进度与现有主线分离

用户澄清：集满星、升级后播放的剧情是尚待制作的独立进阶剧情，不是当前城市主线。本页覆盖此前学习规划中将两者绑定的表述。

- “英语旅程”恢复原水平选择与校准界面，继续使用已有档案保存流程和切换水平强提醒。
- 当前城市主线只依赖起始旅伴、登录状态与前章完成记录。移除学习里程碑读取器及主线响应中的星星字段；修改学习水平、答题或升星不会影响现有主线。
- 角色学习页保留挑战与全局学习进度，聊天页继续支持向左滑动进入；删除右上角的学习档案入口。学习进度摘要不再命名为“英语旅程”。
- 独立进阶剧情不接到当前城市主线，也不在恢复后的英语旅程中展示。原有学习计分、九星、题库、补答及课程判定数据保留。

## Xcode 调试入口

聊天页右上角的闪电按钮、依赖注入及客户端请求方法均放在 `#if DEBUG` 中，Release 不编译。点击后填满当前角色的单元挑战条，并显示学习页。

按用户明确要求，正常 Xcode Debug 运行使用真实后端，不增加账号白名单或额外管理凭据。`POST /v1/dev/learning/characters/:id/fill` 使用现有账号鉴权；服务端不会把前端 Debug 标记视为安全凭据。该端点可被已认证账号直接调用，但仅能操作其拥有角色的当前循环。

请求包含 `requestId`、`cycleId`，走现有账号事务锁和请求幂等机制。正在挑战时拒绝填满；旧循环请求不能填充新循环。操作不创建聊天消息、贡献记录、作答、学习点数或星星。离线预览使用独立内存状态，不请求生产。

## 验证

后端类型、相关 ESLint 和架构检查通过。独立 PostgreSQL 下主线政策、学习 HTTP、挑战事务和进阶事务共 21 项通过，覆盖鉴权/角色归属、重复填满、请求重放、旧循环、活动挑战保护、零成绩副作用，以及主线不受星星与自选年级影响。
