日期：2026-09-26。实现及线上版本：`685b86f`。本批完成图片选择、听辨选择及配对的资源与展示基础；没有新增正式教材单元，不能将工程图形视为小学一年级课程。

## 实现边界

- 目录登记不可变图片元数据，逐题自审增加 `imageReview`，核对图片语义、替代描述及答案泄露；图片本体按 SHA-256 寻址。来源和作者自审不等同于外部教师审校。
- 限制单帧、8 位 RGB/RGBA PNG，尺寸 128～1024 像素、大小不超过 2 MB。发布器检查摘要、尺寸、块 CRC、解压长度、扫描行及远端对象校验和，拒绝动画和未知关键块。
- 新增附加表 `0039_learning_images`。所有单元发布入口均验证已登记图片，失败全批回滚；已有图片及审核信息不可原地改写。旧挑战仍按冻结版本访问旧资源。
- 图片授权下载必须同时匹配账号、挑战、题目和资源 ID；签名五分钟有效，响应不包含来源与审核资料。客户端不向对象存储发送账号令牌，核对摘要、大小与 PNG 尺寸后进行有界解码。
- 原生选择题使用图片卡片，普通字号两列、大辅助字号单列；配对支持图片与文字组合。屏幕保留编号，辅助功能使用图片描述。图片未全部准备好时禁用选择与检查，但可跳过；失败可重试，离开时废弃在途结果。
- 后台已有单元详情能检查资源标识，尚未提供图片上传和可视化素材审核页。正式图片目前通过受控目录审核发布；模型补库继续只生成文字题，不允许编造图片 ID。
