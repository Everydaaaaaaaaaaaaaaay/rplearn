## 循环二：集成恢复与长期使用

- App 前后台回顾复用同一就绪判断；自动触发不再提前消费新会话，手动重试可显式绕过等待。
- 积压按原顺序拆为最多8条/4000字符，未处理尾部继续保存。问候和未完成回答不结束自选练习。
- 写入检查返回本次真实写入结果；恢复成功清除旧存储失败标志。原消息/上下文不可读时停止该批评分，不拿空上下文猜分。
- 旧批次迟到不会倒推复用日期，按实际表达时间排序。
- 长周期场景：32组，每组120次记录，混合辅助、重复提交、删除、持久化往返。`20260922T104452Z-90122.xcresult`：52项通过（参数化场景在一个测试条目内）。
