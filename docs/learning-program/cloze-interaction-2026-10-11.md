# 共享词库多空题接入

本次新增 `cloze`：原句保留在题面，点击空位后从一份词库选词。填完自动移到下一个空位，可以重新选择任意空位、替换词块或撤回当前填词。每个词块最多使用一次，全部填好后才可检查；请求处理中、提交结果未确认及答后阶段锁定修改。

## 内容与判分合同

- `passage` 使用 `{slotId}` 声明二至六个不同空位；`tokens` 提供二至十二个身份及文字均不同的词块。暂不接受图片词块。
- `acceptedFills` 保存一至八种完整组合，每种必须覆盖所有空位且不重复用词。公开题目只下发原句与词库，答案组合和解析在答前不可见。
- 提交为 `kind: cloze` 与 `fills: [{slotId, tokenId}]`。未知身份、重复空位、重复词块及错题型拒绝；空位顺序不影响正确性。
- 整题全部正确才得一分；部分正确仅给逐空反馈，补答仍只补整题尚未获得的一分。多个可接受答案按最接近的一个完整组合反馈，不拆散拼出未审核的答案。
- 后台题库与单元编辑器支持原句、词库、完整答案组合及题型筛选。AI 出题合同暂不自行生成此题型；作者稿需逐题审核后接入。
