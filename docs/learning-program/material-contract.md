# 第一批复习材料契约

2026-09-16，WF-1.3。代码审计和内容边界已明确，原生加入/选义界面尚未实现。

## 审计发现

`DictKit/DictEntry.swift` 中中文 `meaningGroups` 来自 ECDICT 的翻译行与词性解析；英文 `senses` 来自 WordNet。两者没有已验证的一对一义项映射。中文一行可能包含多个近义或不同义项，不能用数组下标、词性或“第一条”自动匹配英文例句。

`FavoritesFeature/FavoritesView.swift` 优先显示本地词典全部释义组，查不到时退回收藏 translationZh。`FavoriteDTO` 保存词形及可选原消息 ID，没有所选义项 ID、词典版本或内容快照。前批补充的来源只解决“从哪句收藏”，不能证明某条词典释义适用于那一句。

因此第一批只支持显式选择的释义材料、自我回忆，不自动用随机释义或不相干的例句出客观题，也不为每个收藏追加 AI 消歧请求。

## 加入路径

1. 用户主动点“加入复习”，显示单词及可用中文释义组；多组时选择想练的一组，不默认第一组。
2. 显示来源原句供确认；不把来源存在当成义项已验证。用户可以选“只练词义”，原句作为可选辅助材料；不强迫所有历史收藏补来源。
3. 保存被确认的词形、完整释义组、词性、材料版本及来源快照。释义组不被命名为已消歧的单一义项；日后精确义项支持再产生新版本。
4. 复习初始只展示词形/读音入口；原句需主动展开，中文释义与原句译文在揭示后显示。音频播放不把自评自动记成成功。
5. 无释义时提示“这个词还没有可用释义”，允许跳过并回查词；无原句时仍可练词义；缺译文复用既有 Apple 本地翻译能力，不走付费例句翻译。

## 反例与预期

| 输入 | 处理 |
| --- | --- |
| bank 同时有银行/河岸，原句缺失 | 用户选组；不猜语境，不拼出伪造原句 |
| ECDICT 一条含多个意思，WordNet 有多条例句 | 保存释义组；不按索引跨词典配对 |
| 旧收藏只有拼写、无翻译 | 查本地词典；仍无结果则不可作为有答案的复习卡 |
| 来源消息已删除或被中断 | 无可用原句；不回填模型编造内容 |
| 词典更新后释义变化 | 已存材料维持原版本；用户更新时创建新版本 |
| 未揭示但展开原句 | 只显示英文及说话者，不显示中文答案 |
| 撤销评分 | 维持答案已暴露；只改评，不记独立延迟测试 |
| 同一个拼写的两份材料 | 材料数 2，规范化词数 1；分布必须标明按材料计 |

这份契约阻止错误材料自动进入学习队列；尚未证明所有本地词条准确、语境相关或适合目标水平。上线前抽样核查高频多义词、短语、词形变化及低水平用户的释义理解。没有可靠选义证据时只提供自评，不能伪称客观测评正确率。

## 下一实现切片

原生短练入口、用户选义、只读来源、揭示与改评接入已测试的 `ReviewSessionProjection`；先用独立 Debug 夹具验收。正式持久化、排程和历史统计在专门验收后开放，不能把单会话练习包装为完整复习系统。原生视觉/真人理解缺口继续保留，不以文档反例走查代替实机和用户测试。
