# 单元题库短写质量核查（2026-09-25）

## 检查结果

对当前 144 个 v2 原创预设单元，逐题比较短写题标准答案与该单元的英文剧情。先做大小写、全半角、空白及句末标点规范化，再检查**完整答案词序**是否连续出现；可用 `cd Backend && pnpm content:audit -- --ids` 复查到具体单元。

| --- | ---: |

这只是**可抄写风险指标**，不证明所有这些题都无效：低年级的定位、拼写和回忆本身可以是合适的任务。但初中至高中有 54 / 72 道短写题命中，尤其高三 11 / 12 道，说明当前题库不能凭短写题数量证明表达能力。比如高三题的标准答案 `regular cleaning`、`mobile phones`、`six boats` 可在材料中直接定位，通常不需要综合多个证据或面向对象作答。原题仍保留，以免修改已开始或已完成挑战的判分依据；它们需要编辑逐题重写、另版发布，并在真实学习者上校准难度。

人教社[初中新教材介绍](https://www.pep.com.cn/xw/zt/hd/12/xjcjs/cz/202510/t20251024_2004130.html)强调从理解、分析走向表达与迁移，并将听说、读写和综合项目结合。我们据此将**未来服务端生成的初中及高中短写题**收紧为：初中至少两个词、高中至少四个词，完整答案不得连续出现在英文剧情中；提示词要求综合至少两条线索。首次草稿未通过确定性校验时可重写一次，两次均不合格则拒绝入库，保留已积累的挑战门槛。形式校验只能拦截明显的抄写题，无法证明生成内容答案唯一、符合教材难度或具备真实学习效度。

后续编辑顺序：先逐题核对高三、高二、初二和初一；为每题标注“从哪两条线索推得答案、为什么干扰项不成立、是否接受另一种英文表达”；再按新模板 ID 发布，确保旧作答的题干与判分记录不被改写。所有年级仍需教师审校、答案变体与学习者试测。[多邻国的内容反馈说明](https://blog.duolingo.com/how-user-reports-improve-course-content/)也显示，“我的答案应被接受”是其最常见的题目反馈类型；本系统目前的精确匹配短写尤其需要这类复核机制。
