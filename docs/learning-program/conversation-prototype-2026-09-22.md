# 对话成长原型与验证记录 · 2026-09-22

## 交付范围

这是可运行的原生交互与规则原型，不是成品上线，也不是完整真实世界的模拟器。它复用 ChatView、输入框、查词、翻译器与朗读，允许选择现有旅伴，在三个情境中表达选择和理由，或先自由聊天。没有因退出、求助或未完成而扣分、损失关系的机制。

Debug：聊天设置 →「共同篇章（原型）」。免登录模拟器入口：`Scripts/preview-learning.sh build`；已有构建用 `Scripts/preview-learning.sh preview`。Release 不提供入口。

回放默认零远程模型调用，NPC 固定回复、回顾判定由测试开关指定，界面明确标识。正常登录后可切换真实模型，使用现有账户额度。真实模型路径尚未在线验证。原型并未实现完整等级课程、半年学习路线或自动编排的多角色关卡。

## 当前可体验流程

1. 选择旅伴及周末去处、饮料选择、推荐一本书之一。
2. 进入完整聊天页面；用英文表达，也可以查词、使用翻译器和语音。
3. 保存并返回，可退出应用后继续同一次练习。
4. 回顾引用自己的原文；完成目标获得参与经验，需提示或无法判断则保留尝试。
5. 更换情境再次尝试；历史记录可以删除原文，经验保留。

经验暂定每次 10、每日最多 30、每 60 升一级，全部是待校准的原型参数，不能当作英语等级。能力描述只反映证据充分程度；至少跨 3 天、2 个情境才出现较强但仍保守的描述。查词或翻译帮助不会减少参与奖励，却不能据此认定独立掌握。语音转写不证明发音与独立口语能力。

## 数据与成本

- 按账户、回放/真实模式隔离本地 JSON 和 SQLite；每次练习拥有独立的角色副本。
- 不接正式记忆同步、金币或云语音上传；真实模型请求仍经过账户服务，可能有正常服务端请求记录。
- 删除学习原文同时清除该练习聊天、语音文件、聊天衍生记忆与关系状态；保留奖励及哈希去重标记。这不是删除整个账户，也不承诺删除服务端 AI 请求日志。
- 相同规范化表达不重复领奖、不增强能力证据。不同措辞表达相同意思的语义去重尚未实现。
- 回顾每次最多 8 条、8,000 字符，输出上限 450 tokens；未启用逐消息独立评价。聊天自身的后台模型行为仍按 ChatFeature 运行。
- 写入/解码失败停止相关操作，不覆盖损坏文件。聊天已存而观察记录丢失时，恢复时补读，帮助来源标为未知。

## 测试—推导—修正记录

| 轮次 | 暴露的问题 | 修正与证据 |
| --- | --- | --- |
| 1 | 重复回调、迟到判定、虚构引用可能发奖；中途离开容易丢状态 | 版本与引用校验、幂等发奖、恢复活跃尝试；6 项规则测试通过 |
| 2 | 相同表达虽不发奖却仍可能增强能力描述；回放/真实来源可能混合 | 重复表达不计独立证据；按来源筛选、按账户隔离 |
| 3 | 小尺寸 sheet 不像实际聊天；强退存在消息与观察写入窗口；评价输入可无限增长 | 全屏复用 ChatView、恢复补查且保守归因、限制评价输入；新增来源测试 |
| 4 | 每次尝试一个数据库会随使用增长；完成以外的原文缺乏删除入口 | 每模式共用数据库、每尝试隔离角色；全部记录提供删除；清理衍生数据 |
| 5 | 自由聊天套用情境考核不自然；旧句重组引用可重复领奖 | 自由聊天不设考核；逐句去重，新旧混合保守不发新奖励，增加组合测试 |

规则模拟覆盖每天 1、3、20 次尝试的 180 天，共 4,320 次；只验证状态/奖励约束，不模拟学习收益、真实输入分布或数据库性能。

## 验证与边界

自动化真实操作的是模拟器内原生 UI，并以回放模型执行：发送、返回、重启恢复、回顾、同文本不重复领奖、断网保留练习。规则测试另覆盖辅助/语音来源、删除去重标记保留、伪造证据、迟到回调、放弃、来源未知、跨模式隔离。

最终验证结果见本文末尾。产物不进入 Git。

以下仍需验证，不能称为已经排除：
- 真实模型对正确、不完整、跑题、否定句、提示注入、拼写错误的判定准确率；引用 ID 有效不等于语义判断正确。
- 真机 Apple 翻译、语音识别、音频中断、弱网流式失败；回放不提供伪造的 AI 翻译。
- 实际回复等待、角色作息：当前练习缩短了模拟回复延迟，不能据此评价正式聊天节奏。
- 多设备并发、服务器权威奖励、时区/改时钟/反作弊；当前是本地原型。
- 长历史磁盘占用、同步写入开销、低端机/Dynamic Type/VoiceOver/横屏与 iPad 适配。
- 自由聊天暂不考核；自动识别自然对话中的学习机会仍待验证。
- 新旧表达混合时保守不发新奖励，可能低估有效练习，需实际样本校准。原型经验不接实际货币。
- 使用率、打扰感、延迟迁移能力与半年成长节奏，需要真实用户纵向观察。

## 后续闭环及停止条件

每轮记录具体输入、操作、预期、实际、模式、版本与证据；先复现，再区分界面/规则/模型/学习效果问题。修正后回归失败用例与受影响的邻接流程，不反复跑无关全量测试。真实模型必须单列数据集与误判率，不能让回放结果替代。

当前版本只达到原型检查点。只有已定义用例全部通过、未决问题明确记录，才可结束该轮；这不等于所有可能问题不存在。下一轮优先处理真实模型评价集与奖励公平性，再做真机与真实用户验证。新增功能须能改善对话中的学习闭环，否则不扩张范围。
