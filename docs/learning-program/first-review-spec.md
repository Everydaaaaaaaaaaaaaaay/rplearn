# B-003：第一条复习闭环的设计与验收

日期：2026-09-16；采用 WF-1.2。状态：任务原型已自查，原生高保真、真人可用性与持久化系统尚未完成。

## 选择与对照

首个候选为“聊天收藏 → 原语境回忆 → 自评 → 有限量复习安排 → 可解释统计”。证据见 [B-001](research-b001.md) 与 [B-002](research-b002.md)：分散练习/提取练习提供机制依据，墨墨提供自评与负担管理参照，多邻国提供专项训练与按需解释参照，轻听提供同素材多模式参照。它们不证明我们的具体排程或交互有效。

| 方案 | 优点 | 代价/风险 | 决定 |
| --- | --- | --- | --- |
| 保持现状 | 无新增负担 | 收藏后仍主要靠自己回看 | 保留为试验对照 |
| 收藏内回看 | 距离材料近，改动小 | 多种技能扩展后入口承载有限 | 首轮原型对照 |
| 独立学习页 | 训练目标、复习与统计集中 | 新入口需要发现性验证 | 优先设计，不立即新增 Tab |
| 独立学习 Tab | 入口清晰，扩展空间大 | 占据长期导航，可能弱化通讯体验 | 等日常学习任务形成后再决定 |
| 影视片段系统 | 强语境与兴趣 | 素材权限、存储、标注与持续维护 | 暂不进入首个实现切片 |

已独立完成来源保存与收藏页原句展开，不需要等待整个学习系统。该小改动不等于完整间隔复习上线。

## 可操作原型

[打开原型文件](prototypes/context-review.html)。可用 `python3 -m http.server 8766 --bind 127.0.0.1 --directory docs/learning-program/prototypes` 本地运行。无外部依赖、无账号写入、无模型调用；重载会清空原型记录。

比较两个入口的标签/任务路径，尚不代表最终导航和高保真样式。流程：开始 3 词 → 自己回忆 → 可选原句 → 揭示释义 → 忘记/模糊/记得 → 下一词 → 小结。每一步可以结束；小结可继续剩余内容或撤销上一词。

实际浏览器自查：答案揭示前没有中文；提示只显示英文原句；揭示后出现自评；评分后撤销回到 0/3；完成 1 词提前结束为 1/0/0；继续完成另两词后总计 3、分布 1/1/1。去掉了原本多余的“确认结束”步骤，因为提前结束可恢复。尚未用真人验证三档理解，也未检验语音或长期排程。

## 数据语义（实现前约束）

- 收藏与参与复习分开：查词不自动入队，收藏也不默默产生到期负担；用户主动开始或添加至复习后才建立学习项。
- 材料保留规范化词、词义选择、来源消息、来源快照和内容版本。不能只用孤立拼写代表多义词所有知识。
- 单次事件记录唯一 eventID、itemID、sessionID、客户端时间、接收时间、时区、练习模式、自评/客观结果、是否提示、是否重播、是否已看答案、撤销目标及 schemaVersion。
- 自评“模糊”不能直接映射为 Anki/FSRS Hard；Hard 的正确但费力语义与部分记错不同。接入算法前必须定义映射并验证，不改写历史原始评分。
- 撤销不能抹去“已经看过答案”的事实。再次评分属于本次已暴露材料；不能作为新的独立延迟回忆样本。同日多次练习和跨日首评分开。
- 服务端幂等 eventID，事件追加，撤销作为关联事件；日统计与排程可重算。离线重传、重复点击、多设备合并不能重复计数；冲突顺序确定且可解释。
- PostgreSQL 权威，SwiftData 本地缓存；登录切换隔离。旧收藏可读，升级不要求删库。导入历史收藏不伪造学习日期或掌握记录。

## 统计口径

| 指标 | 定义 | 不可替代成 |
| --- | --- | --- |
| 今日回顾词数 | 按学习日去重的规范化词形；材料数另按 itemID，剔除撤销评分 | 点击数或展示数 |
| 自评分布 | 每个材料当日最后一个有效自评；合计对应材料数，多义词不混用词数分母 | 已掌握词数 |
| 尝试次数 | 有效作答/自评事件次数；与唯一词数分别展示 | 新学词数 |
| 有效练习时间 | 前台交互区间、闲置截止、后台暂停、区间去重；跨午夜切分 | App 打开时长 |
| 延迟回忆 | 预定义间隔后、无提示的首次客观测试结果 | 当场重做正确率 |

原型只显示前台停留，不声称实现有效练习计时。正式计时需要暂停、闲置、多窗口/设备重叠与时区测试。三档总和应等于相应口径的去重词数；不混用初始与最终评分分母。

## 排程与成本策略

先离线回放一个透明的简单排程基线，再与有来源的 FSRS 实现比较；没有历史样本不宣称参数已个性化。每日负担上限、到期词优先、难词短组、休息与跳过不惩罚。首版不为每次评分请求 AI；复用词典、已存译文、本地语音、已有原句。新语境生成只有在后续迁移训练有价值且成本被测量后引入，内容去重缓存并记录版本。

## 实施门槛与测试

1. 原生界面：长词/长句/大字体可读，评分和退出可达；翻面与提示状态清楚；减少动态效果仍有反馈；屏幕阅读器可识别进度和评分。当前原生视觉检查受 Device Hub 工具连接影响，仍开放。
2. 数据：重复上传、撤销后重做、同日复习、离线跨日、时区变化、多设备并发、账号切换、删除来源、内容修订、旧库迁移均有明确预期。
3. 内容：词义与语境匹配；中文释义不提前露出；听力模式无文字泄露；没有可靠答案的材料不生成伪客观题。
4. 成本：无新增实时 AI 请求的回忆路径可离线完成；音频缺失提供明确降级，不能无声标记播放成功。
5. 人的验证：让未看过原型的人完成开始、回忆、自评、撤销、退出任务，记录误解；没有参与者就保持待验证，不伪造通过。
6. 试点：先限定训练范围与可撤回入口；聊天、收藏、原历史不受影响。长期学习效果在预定间隔后观察，未到期可继续其他独立研究。

## R-012：排程原始资料复核

2026-09-16 实际搜索 `FSRS official manual Again Hard desired retention`，打开 [FSRS 维护者教程](https://github.com/open-spaced-repetition/fsrs4anki/blob/main/docs/tutorial.md)。页首明确停止更新并推荐现行手册，因此继续打开并阅读 [Anki Deck Options](https://docs.ankiweb.net/deck-options.html)，重点 Daily Limits、Timers、FSRS、Health Check、Simulator。

确认：Hard 是成功回忆；提高目标留存率会增加负担；默认参数与经过个人历史优化的参数不是同一回事。现行手册将 CMRR 标为 25.07 起移除，改为讨论模拟负担；不能照搬旧教程。手册的实验功能和效果主张不能直接当成咕游记用户效果。正式算法选择仍需版本固定、开源许可核对、基线回放和目标用户验证。

本次出现的是来源更新提示被正常识别，现行流程已覆盖，无需为了“自我优化”再新增规则。

## 撤销与事件原型验证（2026-09-16）

`prototypes/review-ledger.mjs` 是单会话可执行规则，不是生产同步接口。原型已接入追加事件、幂等重放与关联撤销，移除直接删除数组记录的旧实现。撤销后保留提示/答案暴露，展示“刚才已看过答案，可以修改自评”，不再要求伪装成新的首次回忆。

`node --test Scripts/tests/review-ledger.test.mjs` 的 7 项测试通过，覆盖重复事件、内容冲突、撤销后曝光、重复撤销、不合法评分、跨尝试撤销和未评分退出。浏览器实际完成“原句提示→揭示→忘记→撤销→记得→结束”，显示 1 个词、1/0/0；撤销中显示 0/3 且答案仍可见。此为原型行为自查，未替代生产离线同步、真人可用性或学习效果验证。
