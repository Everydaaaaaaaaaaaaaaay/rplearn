## 九个独立单元

| 角色与 ID 后缀 | 情景 | 语言目标 |
| --- | --- | --- |
| Oliver / `bookclub-enquiries` | 联系读书会组织者 | 时间、地点、报名方式的间接问句；whether/if |
| Oliver / `bookshop-then-now` | 书店旧照片说明 | used to 的肯定、did 否定与疑问、过去存在状态 |
| Oliver / `repair-labels` | 旧书修补记录 | 日常与过去被动、主语数、执行者 |
| Ruby / `visitor-station-rules` | 海边访客站提示牌 | 情态被动、No doing、否定祈使、条件加祈使 |
| Ruby / `rain-plan` | 社区活动备用安排 | 真实将来条件、主将从现、否定和条件方向 |
| Ruby / `reusable-cafe` | 咖啡馆罐子和纸袋 | 再利用词义、原因与结果、so that 目的 |
| Marcus / `record-corner` | 唱片店描述偏好 | 人与物的关系代词、主谓一致、避免重复宾语 |
| Marcus / `photo-caption-workshop` | 街区照片说明卡 | 过去被动及人物、事物的限制性定语从句 |
| Marcus / `neighbourhood-invitations` | 街坊相片分享夜 | 邀请安排的间接问句、if 两种功能、条件安排 |

每单元 3 段剧情、6 道独立题，使用选择、词块组句、配对、短填空四种文字题型。剧情有译文，题内给出生词释义与必要事实。没有依赖剧情记忆、缺失照片或教材原文才能作答的题。

难度区别于小学：要求处理嵌入语序、主被动转换、关系词的句法角色、同一 if 的不同功能和因果方向；保留少量结构巩固题。没有把句子加长当成九年级难度，也没有把语法练习全对当作九年级综合能力认证。

## 歧义与评分检查

- 限制性定语从句的主语位置，对人接收 `who/that`，对物接收 `which/that`；这些题不能省略关系词。选择题不把另一种合法关系代词当干扰项。
- 表示“是否”的宾语从句同时接收 `if/whether`；不会把宾语从句中的将来时误按普通条件句规则判错。
- 词形题明确指定词根与时态；`does not open` 明确 open 是动词且限定候选，避免误拒形容词用法 `is not open`。
- 条件句与因果题直接给定方向。`because/so/so that` 题同时写明意图和候选范围，不凭单一 can 或句尾形式判断唯一答案。
- 组句在必要处限定句首，词块保留标点边界。配对右栏打乱，不依赖固定对应位置。
- 每题都有独立条件、难度理由、歧义说明和正反样例；选择题逐项解释，填空测试合法变体及大小写。审核绑定规范内容哈希。
