## A-001 重复表达错误推迟复用

- 基线：同一原文成功三次，排程计为三次成功，48小时变成21天；删除源证据后重发也重新出现建议。
- 原始失败：`20260922T133311Z-26784.xcresult`，两条新增反例失败。诊断收集另报simctl路径错误，未混为产品失败。
- 最小修正：每技能按原文指纹仅保留第一次出现，包括删除墓碑。重复不推进排程、不恢复已删除来源；不改48小时/7日/21日常量。
- 规则revision3，存储version1不变；保留原始证据、奖励、处理批次，旧档仅重算排程。
- 回归：`20260922T133437Z-27855.xcresult`，25项测试通过，包含两条反例、不同表达的精确间隔、延迟回顾、时钟倒退、存档重载及已有确认/听力规则。参数化子样本不冒充真人数量。
- 成本：零新增模型调用、零后台接口或迁移。
- 结论范围：修复实现违背去重约束的问题，不代表这些复习间隔已被证实最优。
