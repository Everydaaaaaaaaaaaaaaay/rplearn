# 单元学习系统与原始需求逐项核对

更新：2026-09-25。本文件记录当前代码和材料的可验证状态，不把功能可运行等同于教学质量验收。

## 数据归属与页面位置

| 原始要求 | 当前实现与判断 |
| --- | --- |
| 双方聊天按字符积累 1000 字符挑战进度 | 已接入用户与角色保存后的文本消息；服务端按账号和消息 ID 去重，进度按角色存放并封顶 1000。服务端仅收到客户端报告的字符数，尚未独立校验聊天正文与计数。 |
| 从聊天左滑进入该角色学习页 | 已实现随手指横移、松手完成或回弹；角色页仅显示该角色的挑战门槛、当前挑战和历史记录。 |
| 角色挑战互相独立，只有水平进度全局 | `unit_learning_characters` 和 `unit_learning_attempts` 按角色隔离；`unit_learning_accounts` 保存全局年级、答对数、星星对应的累计数和实际升级次数。新增账号级进度读取接口，英语旅程展示全局水平。 |
| 主线只有一份，随全局学习进阶 | 已移除三套按角色写的主线，改为一条连续的 12 章旅行册剧情；章节只由账号级 `completed_levels` 解锁，手动调整起始水平不跳章。入口位于“我的 → 英语旅程”，原有“当前英语水平”修改入口保留。 |
| 九颗星与年级进阶 | 当前每 10 道新答对题点亮一星，90 道升一级；升年级后更新档案难度，之后的聊天请求和单元按新档。返回聊天时也重新读取当前难度，避免页面内沿用旧值。 |
| 完成后重答漏题、下一轮不重复 | 服务端首轮三题均作答后完成单元并清零该角色聊天进度；新开启的挑战在首轮完成时按答对题数统一结算，完成后补对旧错题只补发一次。此前已开始的挑战继续原计分规则，避免迁移时重复给分。同角色同年级的已用模板不再抽取。 |

## 仍未满足原始质量要求的部分

1. **预设题量不足以支撑持续升级。** 当前三名主角色各年级 4 个预设、每单元 3 题；一轮年级至少需要 30 次全对挑战。一个角色的一个年级至少有 26 次挑战会依赖生成（答错时还会更多）。这不能称为“丰富的预设足够持续抽取”。必须补充经人工编写、逐题审查的内容，或重新设计经学习效果验证的进阶门槛；不能用自动生成冒充亲自编写的预设。
2. **教材证据与能力效度不足。** 教材库登记了官方目录、公开活动和少量样页，但尚未逐册核对完整课文、练习和教师说明；一、二年级与高中实际教材页尤其不完整。当前 144 个原创 v2 单元是内部试用题库，尚无教师逐题审校、首答难度统计、跨日迁移和外部能力验证。九星升级只代表应用内练习进度，不能声称实际达到相应学校年级英语水平。
3. **题型和能力覆盖仍较窄。** 当前只有单选、词块排序、精确匹配短写三种题；剧情现可逐段播放英文，挑战逐题推进，每次作答立即显示本题的答案依据，完成后集中回练错题，但朗读不等于听力测评。仍无听力判分、口语、可接受多种正确表达的写作，也没有以证据作答的长文本任务。高中阶段尤其不能由三道封闭题覆盖阅读、表达和论证能力。
4. **生成题的入库审查仍是自动化。** 服务端会按角色、年级和教材来源生成，进行格式/答案检查和第二次模型审题，公共角色通过的题进入共享库，私有角色题只对所属账号可用。但缺少人工审校、版本发布闸门和上线后的质量回收，不能保证共享库长期保持教材级质量。
5. **年级边界仍需产品与教学规则核定。** 新挑战已改为整轮完成时结算，补答旧错题仍即时补发；达到 90 点时旧年级挑战的超额正确题不会带入下个年级，以免用低年级题获取高年级进度。若结算点数超过当前年级剩余额度，显示实际获得的点数；这会使边界处“答对题数”与“新增点数”不同，需要在真实用户试测中确认是否易于理解。
6. **主线演绎仍是阅读型。** 已有唯一全局剧情和按升级解锁的章节，但章节目前是静态双语阅读，没有剧情系统的角色演绎、已读回执、选择与后续影响。解锁满足基础规则，叙事体验仍需深化。
7. **现有难度档位与单元年级不是完全一一对应。** 旧档位还含启蒙、大学英语与进阶；单元题库目前只有小学一年级至高中三年级。服务端把启蒙映射为小一，把大学及以上映射为高三练习，但聊天仍使用用户选择的原档位。英语旅程现已明确显示这一映射；若要真正共用一个等级概念，仍需扩充题库或重构档位。

## 验证边界

本轮用后端类型检查、隔离数据库集成测试、iOS 模拟器构建和定向 UI 测试验证数据归属、页面入口与基础导航。答案揭示边界由隔离数据库测试覆盖：进行中的挑战题目列表不返回答案；单题提交后才在该题的反馈中返回答案与讲解；完成后提供全部复盘材料。结算测试另覆盖新挑战完成前零发放、完成时结算、答错最后一题时仍结算此前正确题、完成后补答与旧挑战即时计分兼容。免登录模拟器无法替代真实账号的“聊天 → 满条 → 答题 → 升级 → 英语旅程解锁”全链路，也不能验证真实学习效果。正式开放学习系统前，应按上述质量缺口继续补齐并做实际学习者试测。

## 2026-09-25 练习体验调整依据

参考多邻国公开介绍的[短单元与剧情穿插路径](https://blog.duolingo.com/new-duolingo-home-screen-design/)、[可重听的对话材料](https://blog.duolingo.com/whats-the-best-way-to-learn-with-duolingo/)与[错题专项复习](https://blog.duolingo.com/guide-to-duolingo-practice-hub/)，把本应用现有的一屏长卷改为“逐段剧情 → 逐题作答 → 结果与错题回练”。每段剧情可手动播放英文；答完一题后得到该题反馈，再继续下一题；整轮结束后可集中复盘。此处借鉴的是任务节奏和复习方式，题目、角色剧情与文案仍由本项目独立编写。后续需用真实学习者数据检查单题耗时、回练完成率及隔日记忆表现，不能仅凭交互形式推断学习有效。

进一步参考多邻国公开的[作答后解释](https://blog.duolingo.com/explain-my-answer-now-free/)：每次提交后，服务端仅返回**当前题**的参考答案与已有编写的依据说明；未作答的其他题仍不在进行中挑战的公开题目里返回。当前解释是预设的题目讲解，不是针对用户错误类型生成的个性化反馈。错误诊断、合理答案变体和跨日回练仍需另行设计及验证。

后端账号级进度接口随版本 `0070bce` 原子发布：API 与 Worker 正常，公网健康检查为 200；新接口匿名请求为 401，未知路径为 404。旧客户端没有新页面入口，也不依赖这个新增接口。iOS 改动仅安装在本地模拟器，尚未发布商店客户端。上述线上探针不等于已验证登录账号返回的实际进度或主线解锁。

完成后复盘所需的题目答案与讲解随版本 `ed6abdc` 发布：当时隔离数据库测试确认进行中的题目列表没有这些字段，完成的记录才包含它们。线上已确认 API、Worker、Caddy 均运行，公网就绪检查为 200，匿名进度请求为 401。旧客户端可忽略新增字段；新版 iOS 仅安装在本地 iOS 27 模拟器。尚未使用真实登录账号在线走通复盘页面与 TTS 播放。
