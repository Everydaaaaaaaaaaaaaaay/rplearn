# 高三与四六级强化题：媒体与目录候选验收

本轮承接三名独立 Astra 作者逐题亲写的高三、四级、六级各18题，共54题。原题文、候选、解析和完整开场故事没有用程序组合。程序只搬运审定内容、绑定真实媒体、校验判题及组卷约束。

## 内容和教学范围

- 三位分级作者逐题填写正式审核记录，主代理读回全部54题的语境、歧义审核和选择题各选项依据。真实判题器执行181个正反例：四级57、六级61、高三63。
- 新增9项精确目标：四级1项、六级4项、高三4项。普通能力等级沿用原有含义，未把考研、托福或雅思加入自动晋级链。
- 每组均为完整故事先于18道独立题目。故事不携带后续题目的待测答案；题目各自提供必需材料。
- 本轮仍是受控练习和能力切片，没有独立教师或真实学习者效度标定，不代表完整考试、自由写作或口语产出能力。

## 音频实物

11段母版已离线制作：四级3段、六级3段、高三5段。对话使用区分明确的声线；每个话轮完整合成。只做重采样、整段增益及话轮间300毫秒静音，没有逐词拼接、删词或后期变速。

母版及每段候选均用 base.en、small.en 无提示转写。保留原始识别文本，仅对明确缩写、数字、英美拼写和两个不可听辨的所有格撇号差异归一；不放过漏词、否定、时态或重复词。前几轮存在重复 hall、form/forum 和 abandon/abandoned 等差异的候选已淘汰，不能计入通过样本。

母版为24kHz单声道PCM16，无削波；所有完整话轮及数字静音经逐采样重建，与真实母版一致。实际语速范围：四级121.8–127.6词/分、六级137.1–145.1词/分、高三120.5–146.7词/分。短题和长题采用各自审核范围，不能声称这些短录音等同正式考试全卷语速。

审核文件 `Backend/config/learning/authoring/strengthening-audio-review-2026-10-11.json` 绑定真实台词、母版及每段录音哈希、路径、说话人、声线、take、速度、步数、样本位置与原始转写。客观转写和波形通过不代替独立人耳验收。

复审曾发现仅比较转写而没有比较审核声线的缺口，现由Python核验器和候选生成器各自绑定制作计划、选用记录、清单及原始渲染JSON。Python拒绝31种内存变异，生成器拒绝30种；真实证据未为测试而改写。生成器不用依赖操作者先执行Python，Python另外负责完整PCM逐采样重建。

## 互相提示与组卷

新增5项精确高三互斥对，涉及 whether 与 whereas 的直接教学提示，保留在作者审核区。四级 because 旧题已由既有修订完成互斥，不能重复添加；六级的一般方法迁移不当成直接泄漏，避免把整组18题变成无解模板。

本地候选与既存15项修订合并后，15个模板在原主题、合并主题、新题、到期复习及混合历史下，共完成2,880次组卷。核对每题目标、题型、题数、唯一身份和互斥集合。混合历史保留一个真实可解集合；最初假定原模板全部未见便一定可解，被既存互斥规则证伪，已修正测试条件。结果不承诺任意用户历史都能组卷，缺题时不得放宽互斥或重复凑题。

这仍是本地正式基线加修订记录的验证，不是本轮线上题库快照；新增互斥与题目将来必须按真实版本一起事务发布。
