- 变更：工作流第 9 节；启动入口和批次模板增加版本核对。
- 文档场景走查：漏检触发修订；正常批次只记摘要；未验证草案不替换正式版本；中断恢复读取生效版本；新版造成回归则回退。五条均有明确路径，不依赖虚构运行数据。
- 采用状态：B-001 启动已核对 WF-1.1，并产生实际异常记录。
- 后测：工程启动后的前两个适用批次，核验版本读取、异常记录与必要修订是否实际发生；无异常时不能强造修订。

## W-002：研究重心与运行偏差修正

- 触发：用户要求重点学习 App；B-001 网页探索占比偏高。另发现旧 Xcode 路径不可用、轻量测试目标不含 QuizServiceTests。
- 修正：手机端任务优先；官方截图仅为 B 级证据，网页交互单列；先核对工具链和测试目标，零用例必须失败。
- 回放：Readlang 查词实操仍为网页证据；墨墨商店图仍为官方展示；错误测试目标的 0 用例不能计入通过。修正目标后 QuizServiceTests 12 项通过。
- 采用：B-001 后半段已转向墨墨、不背单词 iPhone 官方截图，停止继续深入纯网站；此文档提交起采用 WF-1.2。
- 后测：B-002、B-003 检查是否取得手机端任务证据、是否减少无效探索；未完成前不宣称效率提升。
- 回退：若规则导致必要资料被排除，调整研究分配；保留用户要求的 App 优先与证据诚实性，不恢复过时路径。
