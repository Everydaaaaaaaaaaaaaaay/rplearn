## W-001：监测工作流自身并确保新版实际采用

- 触发：用户要求运行时自我纠错、持续改进并使用最新完善工作流。
- 原问题：原规则能修正产品方案，但缺少工作流自身的反馈、发布及采用核验。
- 变更：工作流第 9 节；启动入口和批次模板增加版本核对。
- 文档场景走查：漏检触发修订；正常批次只记摘要；未验证草案不替换正式版本；中断恢复读取生效版本；新版造成回归则回退。五条均有明确路径，不依赖虚构运行数据。
- 采用状态：仅完成规划文档更新，尚无实施批次。
- 后测：工程启动后的前两个适用批次，核验版本读取、异常记录与必要修订是否实际发生；无异常时不能强造修订。
- 回退条件：监测导致重复工作、冲突或遗漏时修订对应规则；不得撤掉用户要求的监测目标与硬性边界。

## 后续记录规范

新增修订按 W-002 起编号，包含工作流第 9 节要求的字段；每个生效版本关联聚焦提交和验证证据。候选版本未通过保持候选状态。发生回退时显式更新唯一生效版本与原因，保留历史。批次采用情况记录在对应批次卡，账本只汇总遗漏和待后测事项。
