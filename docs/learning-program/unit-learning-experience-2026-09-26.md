# 单元学习系统：界面与交互方案

状态：角色页、横滑、全局旅程与挑战控件已实现初版；首批正式内容已发布，听力播放、慢速和中断恢复正在完成验证；跨年级内容、进阶与多设备验收继续实施。对应[实施总纲](unit-learning-plan-2026-09-26.md)。

## 1. 视觉方向

沿用应用的旅行气质、纸张材质与现有设计系统。学习页像旅伴留下的活动册，英语旅程像一本逐步盖章的旅行手册，挑战像短小的互动片段。三者共享字体、圆角、间距、按钮与反馈规范，各有明确的空间层级。

主要信息保持高对比，装饰只放在页头、边缘、单元封面与结算；不把题干压在复杂照片上，不让九颗星、粒子和进度条同时争夺注意力。美术按页面需要创作，先确认已有可复用角色/城市资产，避免先生成大量无用图片。

## 2. 聊天到学习页

聊天和角色学习是同一角色空间的左右两页。用户在聊天主体向左拖动，学习页从右侧跟随进入；反向回到聊天。另有带文字的学习入口，供发现、单手使用和 VoiceOver，不要求用户猜手势。

手势规则：

- 先判断意图再锁定方向，横向明显大于纵向才分页；距离和速度决定落点，松手可回弹，动画可被新手势打断。
- 使用连续页间位移，不能等松手后突然弹出 sheet。系统左边缘返回由导航优先处理，不和页面横滑竞争。
- 输入框选字、消息长按、可横滚内容、词块拖动与录音期间不抢手势；录音中可通过明确入口结束录音后再进入。
- 完成切页时收起键盘，保留草稿和聊天滚动位置；取消拖动不丢焦点。返回聊天不无条件弹键盘。
- 切去学习页不停止角色正在生成/保存的正常回复，也不重新创建聊天会话。
- 首次只给一次短提示；满条只改变入口状态并给轻触感，不弹强制对话框。
- iPad 使用受限阅读宽度和合适的并排/分页布局，不简单把手机卡片拉满整个屏幕。

## 3. 角色学习页

从上到下：

| 区域 | 呈现与交互 |
| --- | --- |
| 页头 | 返回聊天、角色姓名与头像、角色地点/主题小装饰；视觉上知道属于谁 |
| 本轮挑战 | 大号进度条与明确的“720 / 1000 字符”；旁边一句自然角色文案 |
| 主动作 | 未满时说明还差多少；满条“开始单元挑战”；进行中“继续挑战”；备题中解释准备状态 |
| 全局贡献 | 小面积显示当前全局水平、本角色贡献，点击去英语旅程；不复制一套角色专属等级 |
| 待补答 | 优先列有剩余进度的单元，显示“已答对 4/6，还可获得 2 点” |
| 全部记录 | 单元标题、场景小图、挑战时水平、日期、首次/补答结果、已获/可获进度；分页加载 |

装饰按角色差异化：Oliver 的书签和藏书章、Ruby 的海岸线和志愿活动小卡、Marcus 的胶片边框与照片标签。它们不承担必读信息，也不遮挡操作。

记录详情把“首轮已结束”和“全部答对”区分，不能 4/6 却一边写失败一边隐藏补答。全对后主动作变为“重温”，明确不再发放进度。切水平后旧记录保留档位标签，补答前说明分数归入哪一档。

空状态展示一个具体下一步：“回去聊聊，达到 1000 字符就能开启第一段挑战。”禁止用假历史、假星星或假题目填充正式页面。

## 4. 单元演绎与答题

结构：简短封面 → 2–4 个开场镜头 → 一至数题 → 必要的剧情推进 → 剩余题 → 收束与结算。剧情镜头数量按内容调整，不固定每题前后插一次对话。

舞台区域有场景局部、角色肖像、名字与简短台词，主体使用留白和缓慢变化建立气氛；题目阶段舞台收小，操作区域稳定。台词可点按完整显示、重播与跳过已看剧情；重答默认直达剩余题，不强迫重新看开场。

顶栏固定退出与题数进度；底部固定主按钮。选答案只是选择，“检查”才提交；提交成功后同位置变为“继续”。结果与解释在稳定区域展开，不把选项突然顶走导致误触。

答对：颜色、图标、短文案、轻触感与小幅进度增长协同。答错：指出错误点、展示正确理解和下一步，避免羞辱语气、剧烈抖动与生命惩罚。角色可以鼓励，但不要每题长篇夸赞。

声音只在允许时播放，支持关闭音效。听力音频与角色剧情配音区分，播放中断恢复状态明确，不重复抢音频会话。

## 5. 新交互组件

| 组件 | 正常操作 | 必须验证 |
| --- | --- | --- |
| 情境选项卡 | 点选、再检查 | 长文本换行、选中辨识、不能仅靠红绿表达正确性 |
| 词块组句 | 点击词块进入句槽，点回撤销；可拖拽排序 | 重复单词有独立 ID；VoiceOver 可以移动/删除；换行不乱序 |
| 填空/短输入 | 当前空位突出，键盘不挡检查按钮 | 拼写自动更正是否泄露答案；焦点/退格/粘贴；中文键盘状态 |
| 听辨控制 | 播放、重播、慢速、暂时无法听 | 来电/耳机断开/后台中断、音频失败、字幕与分数语义 |
| 配对 | 先选左项再选右项，成功锁定并轻量淡出 | 不依赖拖线；错误配对可撤销；布局不在操作中重排 |
| 改写/听写 | 明确短目标，受控输出 | 等价答案、标点、空格、大小写；错误说明可理解 |

所有操作均有无需复杂手势的替代方式。低水平题不因输入操作困难而额外变难。

## 6. 结算

展示一段短角色收束、首轮/补答答对数、本次新增点数、当前档位九星中的位置，以及尚可补答题数。

普通首轮主按钮“回到学习页”，次按钮“补答剩余题目”；若仍有生成/同步问题，明确显示待确认状态，不提前播虚假的升级动画。

满星时先完成当前题目反馈，再进入成长展示。升级演出可以跳过，跳过不丢已结算奖励；如有剧情待开启，提供一个清晰入口，不连弹多个模态窗口。

## 7. 重做英语旅程

首屏只回答三件事：“我现在在哪个水平”“接下来做什么”“下一段主线何时开启”。

| 层级 | 内容 |
| --- | --- |
| 当前水平卡 | 档位、来源（自选/测评/挑战进阶）、一句能力目标；低强调的“调整水平” |
| 九星旅程 | 当前档的九个里程碑，已点亮/当前/未到达状态；当前星展开目标与进度 |
| 下一步 | 推荐继续的角色挑战或补答；说明为何推荐，不同时塞入十个待办 |
| 全局主线 | 当前章节封面、下一章条件、已解锁和已完成章；进阶短章与城市主线有明确标签 |
| 学习足迹 | 各角色贡献、近期单元、可展开的历史档位，不做排行榜或连续签到压力 |
| 水平校准 | 现有测评入口与手动选择，保留能力解释 |

九星是内容路线，不能只有九个装饰图标：点一颗星能看到对应目标与完成依据。当前页聚焦当前档，其他年级折叠浏览，避免十二年级全部铺成无法滚完的蛇形地图。

手动调整示例文案：

> 从“小学四年级”调整到“初中一年级”？之后的新对话和新挑战将使用初中一年级难度。已经开始的挑战保持原难度；小学四年级的进度会保留。手动调整不会补发星星或直接解锁主线。

同时显示目标档实际已有进度。操作为“保留当前水平”“确认调整”，默认不选确认。若目标题库未开放，增加一句具体影响，不藏在通用说明里。

## 8. 体验验收材料

P2 必须留下以下真实运行证据，后续只重验受影响部分：

- 三种学习页状态：积累中、满条、进行中；两种历史记录：待补答、已全对。
- 一段实际录屏：聊天左滑→演绎→做对→做错→退出恢复→结算→补答→再次积累。
- 英语旅程普通状态、升星、可进阶、手动换档提醒、内容缺失状态。
- 小屏 iPhone、较大 iPhone、iPad，大字体和 VoiceOver；减弱动态效果时仍可完整操作。
- 键盘打开、消息选字、语音、横向拖动取消、网络慢/断线、音频不可用的边界体验。
- 关键动作没有明显掉帧、文本跳动或意外重复提交；性能在当前设备实测，不能用指定弹簧参数冒充流畅。

验证使用当前 Xcode 27/iOS 27 工具链，复用已构建 Debug 产物和模拟器。完成改动后运行 `Scripts/preview.sh` 安装最新版本并留在目标页面供用户查看。Computer Use 检查必须实际成功才登记；工具超时不等于页面已验收。
