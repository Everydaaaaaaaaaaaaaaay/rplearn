# 单元挑战教材内容核对（2026-09-25）

## 核对结论

本记录审计的是**已弃用的 v1 版 144 个预设单元**，并保留当时发现的问题作为改版依据。现行原创 v2 题库及其证据边界见[内容记录](challenge-content-v2-20260925.md)。旧版题目当时基于课程标准、出版社教材介绍和少量单元目录，未逐册研读教材课文、练习页或教师用书；不能称为已对齐各版本教材的正式题库，也不能以累计答对题目推断用户达到相应学校年级的真实英语水平。历史作答数据仍保留，不在原模板 ID 下改写题目与答案。

本次补充阅读了人教社公开的配套文本与答案：三、四、五、六年级上册的[听力文本及参考答案](https://download.pep.com.cn/yxs/mxyy-3q-3a.pdf)、[四年级](https://download.pep.com.cn/yxs/mxyy-3q-4a.pdf)、[五年级](https://download.pep.com.cn/yxs/mxyy-3q-5a.pdf)、[六年级](https://download.pep.com.cn/yxs/mxyy-3q-6a.pdf)。这些材料对应较早版三年级起点教材，能看到真实的短对话、信息提取、判断、填空和迁移任务，**不能**作为 2024 修订版整册内容的替身。

另核对人教社 2024 修订版[三年级上册](https://www.pep.com.cn/zslth/yyptzy/xypep/3s/)、[四年级上册](https://www.pep.com.cn/zslth/yyptzy/xypep/4s/)、[五年级上册](https://www.pep.com.cn/zslth/yyptzy/xypep/5s/)、[六年级上册](https://www.pep.com.cn/zslth/yyptzy/xypep/6s/)、[七年级上册](https://www.pep.com.cn/zslth/yyptzy/czyy/7s/)、[八年级上册](https://www.pep.com.cn/zslth/yyptzy/czyy/8s/)及[九年级上册](https://www.pep.com.cn/zslth/yyptzy/czyy/9s/)公开的数字资源单元结构。这些网页多数只公开音频栏目及单元题名，不能据此声称已读到整册学生用书。2024 修订版[三年级下册](https://www.pep.com.cn/zslth/yyptzy/xypep/3x/)的部分 Project 附有实际对话文本，可用来核对交际目标和活动方式。

一年级起点的公开证据目前只有人教社[二年级上册教师用书目录](https://www.pep.com.cn/products/jc/jks/201510/t20151026_1250905.shtml)和外研社[一年级起点教材体例](https://www.fltrp.com/ebook/jcjyyjzx/2023_jcjyjxzy/files/basic-html/page10.html)，**尚未获得一、二年级实际课文与练习页**。高中方面核对了[教育部公开的教材课例目录](https://www.moe.gov.cn/jyb_xxgk/s5743/s5744/202304/W020230420309231498801.pdf)和[普通高中英语课程标准](https://www.moe.gov.cn/srcsite/A26/s8001/202006/t20200603_462199.html)，**尚未完成高中教材各册的实际语篇与活动核对**。

## 旧版题库的具体差距（历史审计）

| 范围 | 教材材料中可确认的要求 | 当前题库的问题 |
| --- | --- | --- |
| 小一、小二 | 一年级起点教材有自己的内容次序；目前缺实际课文证据 | 只按一般入门词汇设题，无法证明与具体教材版本、册次一致 |
| 小三 | 新版人教三上依次涉及交友、家庭、动物、植物、颜色和数字；较早版三上听力任务主要是基础交际和语音 | 现有小三单元以课程表、星期、路线为主，与三年级起点的开篇层次错位 |
| 小四至小六 | 新版人教四上涉及家庭帮助、社区、天气与季节；五上涉及朋友、情绪、作息、健康、食物与自然；六上涉及地点、聚会、健康、理财、太空与能源。旧版六上听力文本已包含多轮对话、时间与路线选择、是非判断和简短回答 | 现有题材偏向通用场馆和通知，语篇常仅有一句台词，缺少教材式信息差和任务链；部分语法标签先于实际情境 |
| 初一至初三 | 新版人教七上包含自我、家庭、学校、课程、社团和日常生活；八上有假期、家庭、比较、自然、计划和沟通；九上有社会变化、人物、学习、记忆、创意等主题 | 只按年级分配语法点，没有把语篇体裁、主题任务和读写活动一起递进 |
| 高一至高三 | 课程标准强调语篇理解、表达、文化意识和思维品质；教材课例目录可确认高中有阅读思考、听说和读写等活动 | 现有高中第三题多为从台词抄一个单词，无法证明高中阶段的阅读、论证与表达能力 |
| 三位主角色 | 角色设定应影响事件、信息线索、措辞和任务结果 | 目前三个角色共用同一台词与答案，仅开场叙述替换姓名和地点，不能视为三个独立编写的挑战 |

旧界面同时展示英语台词和完整中文译文，许多中文选择题可直接从译文作答。这会使答对数高估英语阅读理解。v2 客户端已改为作答后显示中文。服务端生成题虽有格式校验和第二次模型审题，但没有人工审校或难度统计，不应自动称为教材级质量。

## 正式题库的准入条件

1. 逐册建立「出版社／版次／起始年级／册次／单元／实际语篇或练习页／目标交际任务／语言知识／前置知识」记录，公开材料不足的部分明确标为待核对，不凭目录推断具体难度。
2. 每道新题标记来源单元与训练目标，剧情和题目保持原创；同一角色的情境、线索和后果应来自其人设，而不只是替换姓名。至少包含理解、运用与反馈三个环节，不用单词抄写题充当高年级能力评估。
3. 教师逐题审看年级匹配、答案唯一性、解释准确性、双语等值性和地区教材差异；机审仅承担辅助筛查。通过前使用新模板版本，旧模板及其作答历史保持不变。
4. 上线后记录首答正确率、错因、完成时间和跨日新题复测，再校准九星与升级门槛。在此之前，产品只可称「应用内练习阶段」，不表示实际学校年级能力。
