# 角色单元挑战 v1

> 历史实现记录。下文按角色区分主线的描述已失效；现行全局主线与需求差距见[逐项核对](unit-learning-requirements-audit-20260925.md)。v1 预设题源码已移除，当前内容库、来源等级与验证边界见[角色单元挑战 v2](challenge-content-v2-20260925.md)；以下关于 v1 题库的数量和内容不代表当前部署状态。

## 体验与数据合同

- 文字聊天中，用户与角色已保存的消息各按用户可见字符计数；同一账号内同一消息 ID 仅计一次。客户端只上传消息 ID 和字符数，不额外上传聊天原文。每位角色有独立的 1000 字符进度条，满条后可开始当前全局年级的一次单元挑战。挑战进行中不继续累加；完成三题的首轮作答后，该角色进度条归零。
- 单元由剧情片段和三道题组成：情境理解选择、英文词块排序、答案唯一的短写。错题在首轮完成后可从记录重答。每道题在该账号首次答对时最多增加一次进度；旧年级题不推动新年级。
- 全账号共享一个年级进度，10 道新答对题点亮一颗星，九颗星进一级。初始档来自当前账号选择的聊天难度，之后自动进阶也同步更新该难度，聊天和新挑战使用同一个当前水平。旧档案中高于高三的自选难度暂以高三作为此系统的最高练习阶段；不会因此清除原档案。没有档案设置则从一年级开始。这是应用内学习阶段，不是学校成绩或外部英语等级认证。
- 学习页允许直接改到小学一年级至高中三年级。选择后必须确认强提醒：所有角色的当前水平一起改变，本级星星清零，原挑战记录保留；正在进行的旧年级题仍可作答，但不为新年级加分。手动改级不算通过挑战完成的进阶，因此不解锁按实际进阶次数开放的主线章节。其他档案入口修改自选难度后，下次读取学习状态会同步到新水平。
- 主角色的学习主线在累计完成 1、3、6、9 个年级后依次开放。剧情按角色分开；其他角色目前没有单独主线章节。
- PostgreSQL 负责判题、角色进度、全局进度、题目去重和历史记录。客户端只保存待上传消息队列，切换账号时取消旧账号任务。旧版“共同篇章”的证据和 XP 不折算为单元挑战分数。
- 题库按角色键、年级、模板 ID 和版本隔离。Oliver、Ruby、Marcus 各有每年级四个原创预设，共 144 个单元。每位其他公开角色首次达到挑战门槛时由服务端按其人设生成；预设/已生成单元用尽时也生成。新题先过结构、选项唯一性、排序词块、字数和第二轮审题，失败时不发布，聊天进度保留。公开角色的通过题目写入共享库，以后其他用户可以抽取；私有角色生成题只属于原账号。

## 年级目标与教材参考

题目是原创情境，不复刻教材课文。编排参考教育部[义务教育英语课程标准（2022 年版）](https://hudong.moe.gov.cn/srcsite/A26/s8001/202204/t20220420_619921.html)、[高中课程标准（2017 年版 2020 年修订）](https://www.moe.gov.cn/srcsite/A26/s8001/202006/t20200603_462199.html)，人民教育出版社[小学英语新教材介绍](https://www.pep.com.cn/xw/zt/hd/12/xjcjs/xx/202409/t20240920_1995564.html)、[初中英语新教材介绍](https://www.pep.com.cn/xw/zt/hd/12/xjcjs/cz/202510/t20251024_2004130.html)，以及外研社[《英语》（新标准）一年级/三年级起点教材结构](https://www.fltrp.com/ebook/jcjyyjzx/2023_jcjyjxzy/files/basic-html/page10.html)。不同地区、出版社和起始年级的教材顺序有差异，因此下表是本产品的训练顺序，不声称与任一教材逐单元等值。

版本差异直接影响年级判断：人教 PEP 三年级起点可在[三年级上册目录](https://www.pep.com.cn/zslth/yyptzy/xypep/3s/)看到交友与基础对话的起点，人教[《英语》（精通）三年级上册](https://www.pep.com.cn/products/jc/jks/201510/t20151026_1250890.shtml)也从问候、文具和颜色展开；外研社另有一年级起点，按模块安排对话与任务。首批一年级、二年级挑战采用一年级起点的入门要求，三年级不会假设用户已完成同一种低年级教材。高年级题材围绕理解、证据与表达逐步加深；题库扩充时须逐题记录所参照的学段主题和目标能力。

| 年级 | 首批训练重点 |
| --- | --- |
| 小一、小二 | 问候、颜色、人物、物品、简单请求与指代 |
| 小三、小四 | 星期、方位、价格、数量、比较 |
| 小五、小六 | 过去经历、计划变化、信息核对与礼貌澄清 |
| 初一 | 日常习惯、频率与现在进行时 |
| 初二 | 过去进行时、条件与替代方案 |
| 初三 | 被动语态、定语从句和限定信息 |
| 高一 | 趋势、事实与观点、相关和因果的区别 |
| 高二 | 权衡方案、反驳和来源可靠性 |
| 高三 | 综合证据、承认限制、按受众重述结论 |

## 发布质量与后续校准

现有预设题库是试作版本，尚未逐册对照实际课文和练习页。对照进度、已核实的原始材料及具体缺口见[教材内容核对记录](textbook-content-audit-20260925.md)。目前不能宣称 144 个单元已经具备教材级质量。

题库编写和机器审题只能排除一部分形式错误。尤其是高年级的真实阅读与表达能力，不能由三道短题或累计答对数直接证明。对外的年级显示应理解为应用内练习阶段；正式宣称“实际英语水平”前，需要教师逐题审校、不同教材版本覆盖审查、首答难度/区分度数据、跨日新题复测和外部效度校准。生成题的自动审题不是人工审校的替代。

本版不读写旧学习状态；不删除用户原有学习证据。暂不支持离线开启挑战，网络恢复后待上传的聊天消息继续计数。服务端的生成任务有每日 100 个新模板上限，失败或达到上限时显示题库准备中，已满进度条不清零。
