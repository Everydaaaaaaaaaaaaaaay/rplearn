## 待确认，不阻止未来独立调研

- 可访问的竞品账号、设备和付费功能范围；没有权限的地方不得假装完成实测。
- 目标用户在不同水平/学习目的上的分布与主要困难；先利用已有资料，再设计轻量访谈，不擅自联系用户。
- 当前学习行为、成本和活跃时间基线；使用必要的聚合数据，不收集无关聊天内容。
- 第一批预算、具体目标与长期效果样本规模：在有基线后定，不在计划阶段虚构。
- 影视/教育视频素材的具体合法来源与权利范围。
