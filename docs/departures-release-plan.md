# 《出发之后》正式替换与全篇演出施工单

2026-09-07。用户明确要求删除旧主线/城市剧情，并把五站新主线与十五篇城市故事全部完成至可发布状态。旧版二十篇脚本、旧剧情入口及失去用途的配套内容退出应用；用户既有记录、资产和奖励账本保留。本文件是本轮实施清单，完成情况必须以资产清单和验证结果为准。

## 交付范围

- 新目录成为唯一主线/城市剧情入口，目录标题、完成数、城市到访与游客限制全部使用新内容；不存在样章卡、临时入口、占位图或失效跳转。
- 20 篇现有双语脚本及 50 条路径全部有逐节点明确镜头。其余 19 篇补足地点背景、固定人物、情绪变体、道具特写及关键事件画面；不得让人物穿过家具、切换时换脸，或在选择之前展示某一分支的既定结果。
- 新剧情断点、选择和完成状态进入现有 StoryProgressStore 与内容同步流程。历史样章本地数据可迁移；新旧剧情使用不同进度标识。奖励继续通过旧的稳定权益标识和现有幂等账本处理，避免旧用户重复领奖。
- 完成章节后执行应有的旅伴解锁及关系事件，失败必须可恢复、可重试；不以退出画面假装奖励已到账。重玩保留首次完成和奖励记录。
- 保留已完成的 462 段配音及场景声音方向。每篇环境声按具体场景选择，保证不抢人声、不循环出明显接缝；不凭“完整”二字给不适合的场景硬塞背景音乐。
- 发布验收覆盖全部脚本/镜头/声音、原文查词、翻译、选择、自动推进、中断续播、结尾、重玩、身份切换、同步和奖励重试，包含无障碍字号、低内存、离线和真机性能。

## 美术规范与记录

人物动作按性格、当句意图与场景调度设计；不能把同一站姿加表情视为演出完成。中性母版只用于身份与服装一致性。交谈、倾听、操作物件、犹豫、释然等镜头使用具体动作：视线有明确对象，左右朝向服务对话轴线，电话中的角色不作为在场人物显示。动作变体直接引用身份母版，保留脸、发型、年龄和衣物，但允许改变身体重心、头部方向、手势与构图。涉及桌椅和道具接触的动作优先制作完整场景 CG，避免透明立绘与背景对不齐。

用户补充的最终验收：对本轮生成的**全部人物立绘**制作横向姿态对照，包括调整前已提交生成的中性母版。记录身体朝向、头向、视线对象、重心、双手动作、道具、对应节点；同时检查每篇连续镜头，不让“身子略左、头略右、双手下垂”在整批正式演出中机械重复。没有合适演出用途的母版保留于制作来源，不打包进 App。检查发现的问题实际替换后再记录通过，不能只检查最新一批。

沿用伦敦已认可的成人日系动画角色及细腻手绘背景。各地为原创虚构场所，不冒称真实经营的店铺。人物设计尊重既有 Oliver/Ruby/Marcus 人设，其他人物固定母版后再生成变体。不同构图引用母版，禁止连续依赖上一张变体导致形象漂移。

每份资产独立生成并保留原提示词、来源、参考关系和原文件。正式文件集中于 `App/Resources/StoryArt/Departures/`，源文件/生产清单位于 `Assets/Stories/Departures/`。不得把画出来的棋盘格当作透明 alpha；用户已明确允许本地抠图、缩放与压缩，处理后检查发丝、眼白、衣物、深浅背景边缘及原生场景合成。

## 完成依据

本轮不以截图数量或工具退出码代表“可上线”。资产需真实存在、验收并被镜头使用；每条可达路径需要正确的内容与可恢复的状态。所有变更完成相关验证并提交 Git。若实际外部权限、工具额度或设备状态阻止某项验收，明确记录并继续所有不依赖该条件的工作，不把未验收项标为完成。
