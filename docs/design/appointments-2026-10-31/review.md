# 赴约设计原型检查记录

2026-10-31，版本 v1。验收对象是本目录的 HTML 交互样稿和三张城市摄影候选，范围不包含 iOS 运行代码、真实 AI输出、关系算法或生产部署。

## 已完成的检查

| 项目 | 观察与结果 |
| --- | --- |
| 三页默认画面 | 已在本地浏览器实际打开、截图并检查。1280px 宽页面中三个 370×790px 预览并列；没有页面横向溢出，图片均加载成功 |
| 赴约与预设选择 | 点击赴约后约定卡变“进行中”；选择“坐一会”后进入与该行动匹配的下一块 |
| 自定义输入 | 空白不可提交；500 字上限；输入关闭后重新打开保留草稿；提交后总结逐字显示输入并标记“自己说的” |
| 自然结束 | 第二次回应或主动离开路径使用预写告别，支持查看总结；不代表正式故事只支持两次选择 |
| 未到时间 | 外部状态切换后主按钮禁用，并显示开放时间 |
| 暂停与取消 | 暂停不丢故事；取消先显示确认 Sheet，确认后约定显示“已取消” |
| 生成失败 | 切换到失败状态后显示同节点重试；重试回到选择界面 |
| 待结算 | 显示“待结算”“故事已保存”和记忆待整理，不展示伪造的零变化 |
| 好感降低 | 同步展示明确施压的另一条示例路径、角色边界、负向说明与相应记忆；与友好路径分开 |
| 短屏与大字 | 375px 浏览器宽度，667px 高预览与大字组合无页面横向溢出；约定、阅读、总结通过内部滚动容纳内容；自定义入口和提交实际可操作 |
| 叙事标题与阅读层 | 小屏复查后降低阅读层最大高度，保留标题空间；默认画面 DOM检查无两层重叠 |
| 轻反馈 | 移除提示浮层的点击拦截，提示不会挡住后续选择 |
| 城市轮播 | 在正常播放状态等待 20 秒，DOM 中实际照片源已变化；轮播没有改变故事正文或选择状态 |
| 语法和示例数据 | 提取原型脚本后 `node --check` 通过；内嵌示例与 fixtures.json 一致；静态 ID无重复 |
| 摄影文件 | 已逐张查看三张源图；哈希、实际文件尺寸与 photos.json 对应。API报告的缩略图尺寸与实际返回文件不同，已分别保留两者，实际文件为 1920px 宽 |
| 服务边界 | 样稿没有模型/后端/聊天/支付请求，也没有 localStorage持久化；所有交互仅改变当前页面演示状态 |

轮播参数为每张 18 秒、交叉淡化约 0.7 秒。输入、弹层、后台与降低动态效果的暂停分支已写入原型。照片和故事状态独立；真实生命周期、内存与功耗需原生施工后验证。

## 摄影候选范围

已核对用户指定的双层巴士题材，以及当前来源清单里的塔桥、大本钟、圣保罗大教堂。候选为小威尼斯运河、樱草山、诺丁山街区；内容主导元素与上述题材不同，未用同一地标换角度代替新内容。未声称完成全部历史素材的视觉相似度审计。

源页及元数据明确给出伦敦地点和对应 CC许可；实际下载文件未经本地像素修改，预览使用 CSS裁切。每张作者与许可可在原型的“伦敦风景”入口查看。候选尚未进入 App，也尚未通过用户最终审美确认和原生场景验收。

## 仍需在施工后验证

浏览器大字不等于 Dynamic Type；HTML焦点约束不等于 VoiceOver验收。系统键盘、原生滚动/返回手势、安全区、查词浮层、语音队列、后台恢复、真实生成延迟、断流重试和真实结算均未在本轮宣称通过。

正式字号按原生 pt和 Dynamic Type重新排版，不照搬网页中的缩小辅助文字。正式可点击目标至少 44×44pt。真实摄影还需在原生页面检查裁切、可读性、轮播亮度变化、授权署名出口与低功耗表现。
