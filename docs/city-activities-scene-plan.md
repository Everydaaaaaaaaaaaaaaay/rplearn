# 城市活动：场景驱动重构施工方案

## 已确认的方向

删除旧活动首页的城市大卡、今日推荐、分类胶囊和路线列表。首页入口直接进入
摄影场景。顶部横向场景条负责滚动、点选和切换；每个场景有独立的物件锚点与
行动集合，不把同一组分类按钮换皮。行动直接展开，不跳回旧列表。

## 首批交付与施工顺序

1. 先验素材：现有公园作为已验收基线；新增素材优先选择固定镜头下的雨滴、
   水面、植物等非重复身份的自然运动。授权、机位、曝光、接缝任一不合格即淘汰。
   不承诺用一段只有一人的片子生成更多人物。
2. 首批形成两个完整可切换场景，每个场景三个不同的行动。素材验收后选定
   「公园小憩」与「池畔观察」，不为凑数量发布低质量场景。
3. 行动使用离线可用的中英情境、选择、对应反馈和收尾；每次行动有明确目的与
   可理解的选择后果。不是抽奖等候，也不假装进行了实际定位、支付或拍照。
   进度/完成记录按用户与城市隔离，保留以前的联系人、聊天和历史数据。
4. 提取场景配置、物件投影与动态播放能力，复用既有象牙白微光材质、0.12 秒
   按压流程和 App 交叉隐现导航。顶栏只控制场景，左缘返回当前层级。
5. 替换 App 的真实城市活动路由，删除临时样板入口和旧列表界面；活动结果不再
   绕回旧 UI。旧数据结构仍被别处使用的部分保留，不做破坏性数据库清理。
6. 校验内容图完整性、选择分支、用户隔离、取消不结算、重复点击幂等、素材存在；
   c955 专属模拟器验收入口、场景切换、行动完成/退出、左缘返回及静态降级。
   保存实机尺寸截图与素材来源，完成独立提交。

## 查漏补缺一轮（施工前）

- 地理/天气：素材仅为情景美术，不宣称当前城市实拍或实时天气；不要让内陆城市
  出现被说成当地的海滩。场景标签与动作不杜撰具体地标和真实商家。
- 交互闭环：每个可点击物件都有真实目的地和可完成的过程；返回不等于完成，
  取消不能发奖励、造聊天或消耗金币。保留英文学习价值但不强制联网。
- 动态逻辑：自然环境与人物事件区分；人物只能完整进出画，不能倒放、镜像冒充
  新人；背景接缝不能靠人物溶解蒙混过关。自然层允许局部相位错开，不改变运动
  方向或随机跳剪。没有合格多人素材就明确不发布多人。
- 生命周期：当前场景之外暂停/释放播放器；行动覆盖、后台、低电量、过热、减少
  动态时停播。切换静态只改变动态层，不能改变构图与入口位置。
- 手势冲突：顶部横向条与左缘返回分区；行动内左缘回场景，场景左缘回首页。
- 排版：保持图文比例、四角投影和已验证的文字水平留边补偿；按物品面积缩放，
  大字体使用可读替代布局，按钮不得被顶栏/底栏遮挡。
- 成本与资源：不接入付费生成视频服务，不增加服务端依赖；新增前景一次生成，
  不做多轮图生图；保留母版、提示词、授权、确定性处理脚本。多场景共享逻辑
  不等于多场景同时解码。

## 验收边界

这是首批完整场景系统，不等于每座城市都已有独占实景资产。后续扩展必须沿用
同一素材门槛。设备安装、真机功耗和多人动态，未执行时不得写成已验证。

## 首批内容脚本落点

| 场景 | 物件入口 | 行动过程 |
| --- | --- | --- |
| 公园小憩 | 地图：读图出发 | 表达路线偏好 → 复述并确认方向 |
| 公园小憩 | 咖啡：礼貌入座 | 询问共用座位 → 尊重对方的阅读空间 |
| 公园小憩 | 笔记本：随手一记 | 选择观察细节 → 为小记收尾 |
| 池畔观察 | 望远镜：细看倒影 | 描述水中形状 → 区分影像和真实物体 |
| 池畔观察 | 速写本：构思速写 | 选择主体 → 决定留白与线条 |
| 池畔观察 | 明信片：写张短笺 | 分享地点或心情 → 选择结尾 |

完整中英脚本及每个选择的反馈集中在 `ActivitySceneCatalog.swift`。每项两次选择，
24 条可验证的完整路径。首批是离线情境行动，不自动招募新 NPC、假装创建聊天、
导航到真实路线或代用户寄信；以前已获得的联系人、聊天及其他数据不动。
「行动足迹」可回看情境、问题、选择及反馈；明确标示仅本机保存。
