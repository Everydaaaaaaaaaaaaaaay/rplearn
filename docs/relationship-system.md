# 角色关系系统

> 当前实现以 `RelationshipEngine`、`RelationshipService` 和对应测试为准。本文记录模型边界、研究依据与校准入口。

## 产品边界

用户可见的“好感度”是 0...150 的连续数值，但它不是关系的唯一事实来源。内部同时保留相互了解、
信任、默契、相互关心、尊重、未修复张力和已经沉淀的长期纽带。角色回复使用这些连续信号，不能把
用户划入一个永久阶段，也不能公开算法或分数。

初识默认值为 10。英语错误、英语水平、礼貌拒绝、表达不同意见、设立个人边界和一段时间没有联系，
都不能被直接判定为负面行为。关系系统不得奖励依赖、排他、讨好、消费、性升级或学习成绩；角色也
不得以失联为由责备用户。

## 研究依据与不可声称的内容

本系统把研究用于确定方向和约束，而不是声称心理学提供了一个可精确计算真人感情的公式：

- 友谊质量通常包含陪伴、认可关怀、帮助、自我披露和冲突解决等多个维度：
  [Friendship Quality Questionnaire 相关研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC5761066/)。
- 被理解、被关心和被重视的感受与亲密和关系满意度相关：
  [Perceived Partner Responsiveness](https://pmc.ncbi.nlm.nih.gov/articles/PMC5922804/)。
- 对好消息作出主动、建设性的回应比冷淡或破坏性回应更有利于关系：
  [Capitalization support](https://pmc.ncbi.nlm.nih.gov/articles/PMC3776926/)。
- 自我披露与关系质量存在长期的相互促进，但披露不是越多越好，需要符合语境并具有互惠性：
  [Longitudinal self-disclosure study](https://pmc.ncbi.nlm.nih.gov/articles/PMC11349471/)。
- 关系需要互动维持，但长期关系可以成为低频联系却仍然存在的 dormant tie：
  [Enduring bonds](https://pmc.ncbi.nlm.nih.gov/articles/PMC10949355/)。
- 联系频率和共同活动的变化与情感亲近变化相关，关系不会因为一次普通互动机械增减：
  [Managing relationship decay](https://pmc.ncbi.nlm.nih.gov/articles/PMC4626528/)。
- 道歉与补偿可以促进修复，但修复不应立即抹去伤害：
  [Apology and restitution](https://pmc.ncbi.nlm.nih.gov/articles/PMC7082420/)。

这些研究的样本、关系类型和文化背景不同，不能直接推出 LingoTrip 的数值参数。因此现有权重是可测试
的产品模型，不是临床量表或对真人关系的科学测量。上线后只能在不操纵用户的前提下，以匿名聚合行为、
用户反馈和角色一致性评测校准。

## 计算流程

每条用户消息沿用原有的 `coach_review` 快速模型调用，同时产生社会信号，避免为好感度增加一轮网络请求。
模型只识别语境中的温暖、回应、尊重、同理、互惠、披露、共鸣、投入、越界、修复、事件重要性和置信度；
最终分数由客户端确定性算法计算。

正向变化具有五层约束：

1. 互动必须超过普通礼貌的中性基线；
2. 同一天重复互动按平方根衰减，避免刷消息；
3. 越接近 150，增长越慢；
4. 未解决的关系张力会暂时限制正向增长。
5. 每个自然日的正向总收益设有上限，不能靠高频发送跨过递减约束。

明确的不尊重、操纵、骚扰、越界或残酷行为会产生更大的负向变化。负向结果不会因为同日重复而像正向
收益一样显著衰减。真诚修复可以降低张力并恢复部分好感，但单次最多恢复有限数值。

## 时间衰减

时间衰减只作用于“近期活跃亲近度”，不会消耗已经沉淀的长期纽带。对最后结算分数 `S`、长期下限 `F`、
超过宽限期后的不活跃天数 `t` 和关系自适应半衰期 `H`：

```text
displayScore = F + (S - F) × 0.5^(t / H)
```

相互了解和长期下限越高，宽限期和半衰期越长。新关系会较快回到“只是见过”的低下限；深厚关系即使
多年不联系，也只会逐渐接近由共同历史形成的下限，不会因时间自动变成陌生人。明确伤害仍可以降低长期
下限，因为现实中的旧关系可能被事件改变。

## 持久化与一致性

- `RelationshipSnapshot` 跟随 `CharacterEntity` 本地持久化并进入角色内容同步载荷。
- 每次结算记录消息时间、消息 ID 和修订号；乱序返回、跨会话重新编号或重复点评不会再次加减分。
- 最近只保留 24 条简短变化说明，避免建立无期限的行为评判档案。
- 联系人详情展示当前好感度、五个关系维度和最近一次变化；不显示阶段标签。
- 角色提示词读取最新关系快照，所有维度只作为软倾向，不能形成突然的阈值式人格切换。

## 校准时必须保持的性质

调整权重前必须确保测试覆盖：范围不越界、正向收益递减、负向越界明显、修复有限、乱序幂等、时间只
衰减到长期下限、英语错误不参与关系判断。不得只为了提高留存而放大失联惩罚、主动消息压力或亲密奖励。
