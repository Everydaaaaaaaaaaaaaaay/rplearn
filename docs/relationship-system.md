# 角色关系系统

> 当前实现以 `RelationshipEngine`、`RelationshipService` 和对应测试为准。本文记录模型边界、研究依据与校准入口。

## 产品边界

用户可见的“好感度”是 0...150 的连续数值，但它不是关系的唯一事实来源。内部同时保留相互了解、
信任、默契、相互关心、尊重、未修复张力和已经沉淀的长期纽带。角色回复使用这些连续信号，不能把
用户划入一个永久阶段，也不能公开算法或分数。

初识默认值为 10。英语错误、英语水平、礼貌拒绝、表达不同意见、设立个人边界和一段时间没有联系，
都不能被直接判定为负面行为。关系系统不得奖励依赖、排他、讨好、消费、性升级或学习成绩；角色也
不得以失联为由责备用户。

## 研究依据与不可声称的内容

本系统把研究用于确定方向和约束，而不是声称心理学提供了一个可精确计算真人感情的公式：

- 友谊质量通常包含陪伴、认可关怀、帮助、自我披露和冲突解决等多个维度：
  [Friendship Quality Questionnaire 相关研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC5761066/)。
- 被理解、被关心和被重视的感受与亲密和关系满意度相关：
  [Perceived Partner Responsiveness](https://pmc.ncbi.nlm.nih.gov/articles/PMC5922804/)。
- 事件日记研究发现，自我披露与亲密之间的重要通道是对方被感知到的理解、认可和关心；情绪披露也不能
  简化为“字数越多越亲密”：
  [Laurenceau、Barrett 与 Pietromonaco（1998）](https://pubmed.ncbi.nlm.nih.gov/9599440/)。
- 新生友谊的纵向研究显示，关系发展后互动的亲密质量能解释单纯互动数量之外的友谊强度差异：
  [Hays（1985）](https://pubmed.ncbi.nlm.nih.gov/3989674/)。
- 对好消息作出主动、建设性的回应比冷淡或破坏性回应更有利于关系：
  [Gable 等（2004）](https://pubmed.ncbi.nlm.nih.gov/15301629/)。
- 室友关系的纵向研究观察到回应性可以在双方之间形成逐渐累积的循环，而不是由一次高分互动确立：
  [Canevello 与 Crocker（2010）](https://pubmed.ncbi.nlm.nih.gov/20565187/)。
- 自我披露与关系质量存在长期的相互促进，但披露不是越多越好，需要符合语境并具有互惠性：
  [Longitudinal self-disclosure study](https://pmc.ncbi.nlm.nih.gov/articles/PMC11349471/)。
- 双人日记研究中，每日被感知的伴侣回应性稳定关联当天关系满意度，而每日披露本身没有独立显著作用；
  高披露还可能在不合适的关系期待下伴随较低满意度：
  [Candel 与 Turliuc（2021）](https://pmc.ncbi.nlm.nih.gov/articles/PMC8022838/)。
- 关系需要互动维持，但长期关系可以成为低频联系却仍然存在的 dormant tie：
  [Enduring bonds](https://pmc.ncbi.nlm.nih.gov/articles/PMC10949355/)。
- 联系频率和共同活动的变化与情感亲近变化相关，关系不会因为一次普通互动机械增减：
  [Managing relationship decay](https://pmc.ncbi.nlm.nih.gov/articles/PMC4626528/)。
- 真实通信记录显示，人与人分配联系投入的模式存在稳定个体差异；这支持学习每段关系的节律，而不是给
  所有关系套同一个“多久必须联系”阈值：
  [Saramäki 等（2014）](https://pmc.ncbi.nlm.nih.gov/articles/PMC3903242/)。
- 道歉与补偿可以促进修复，但修复不应立即抹去伤害：
  [Apology and restitution](https://pmc.ncbi.nlm.nih.gov/articles/PMC7082420/)。
- 道歉后的信任恢复受对方仍被感知为可信以及受害者负面情绪影响；即使有道歉，信任也没有恢复到未发生
  违背的水平：[Ma 等（2019）](https://pmc.ncbi.nlm.nih.gov/articles/PMC6457316/)。跨三项研究，关系亲近与
  宽恕之间的主要中介同样是违背后的信任，而不只是有没有说过道歉：
  [post-transgression trust](https://pubmed.ncbi.nlm.nih.gov/27862012/)。
- 从受伤者视角看，违背越频繁、越像会再次发生，道歉越不利于修复；修复行为的意义之一是降低再次被利用
  的风险感：[Martinez-Diaz 等（2021）](https://pmc.ncbi.nlm.nih.gov/articles/PMC8096994/)、
  [McCullough 等（2014）](https://pubmed.ncbi.nlm.nih.gov/25024227/)。
- 支持不是越多越好。相对支持接受者自身需要的不足或过度提供，都与较差的关系评价有关；情绪披露后，
  与需要匹配的情绪支持更容易被感知为敏感，错配支持则可能通过较低的伙伴敏感度关联较低婚姻满意度：
  [support under/overprovision](https://pmc.ncbi.nlm.nih.gov/articles/PMC2776033/)、
  [optimally matching support](https://pubmed.ncbi.nlm.nih.gov/18179347/)。
- 自主与联结并非二选一；同时保留自主和联结更有利于建设性的关系维护。这支持把倾听、询问需要和尊重拒绝
  与强行解决、施压或接管区分开：
  [Autonomy in Relatedness](https://pmc.ncbi.nlm.nih.gov/articles/PMC7057354/)。
- 三项研究区分了自主支持与指令式支持：前者与目标进展、关系质量和主观福祉都有关，后者虽可能帮助完成
  目标，却不自动关联更好的关系质量；支持互动研究也指出支持寻求者和提供者双方的自主性会影响体验：
  [Koestner 等（2012）](https://pubmed.ncbi.nlm.nih.gov/22930370/)、
  [Don 与 Hammond（2017）](https://pubmed.ncbi.nlm.nih.gov/28903719/)。
- 道歉可以提升违背后的可信感和信任行为，但不能恢复到从未发生违背的水平；重复信任博弈还把“道歉”与
  之后实际返还行为分为连续步骤。这支持让言语修复影响当前感受，却把长期沉淀更多留给后续行动：
  [Ma 等（2019）](https://pmc.ncbi.nlm.nih.gov/articles/PMC6457316/)、
  [重复信任博弈](https://pmc.ncbi.nlm.nih.gov/articles/PMC11273912/)。
- 支持的日内变化不必然代表不稳定，短期波动可能反映对当下需要的适应；较长时间尺度上的持续高波动才可能
  与较差结果相关。因此系统比较互动的社会质量，不要求角色永远使用同一种支持方式：
  [支持波动的日记研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC10101879/)。
- 冲突后的主动修复与换位思考和更好的情绪恢复相关，回避则与更差恢复相关；近期受伤者的纵向数据还显示，
  和解行动通过提升关系价值、降低再次被利用的风险感来促进宽恕：
  [Parsons 等（2020）](https://pubmed.ncbi.nlm.nih.gov/31393139/)、
  [McCullough 等（2014）](https://pubmed.ncbi.nlm.nih.gov/25024227/)。
- 共同回忆可能增强联系，但来自伙伴的错误推断也会污染记忆；因此关系分数只能调节语气，不能作为
  “曾共同经历某事”的证据：
  [关系回忆与亲密](https://pubmed.ncbi.nlm.nih.gov/33939765/)、
  [伙伴推断对记忆准确性的影响](https://pubmed.ncbi.nlm.nih.gov/42145251/)。
- 五轮伴侣纵向数据中，更多冲突和退缩、更少建设性行为会预测之后较低的关系满意与更高的不稳定感：
  [Johnson 等（2018）](https://pubmed.ncbi.nlm.nih.gov/29723003/)。

这些研究的样本、关系类型和文化背景不同，不能直接推出 LingoTrip 的数值参数。因此现有权重是可测试
的产品模型，不是临床量表或对真人关系的科学测量。上线后只能在不操纵用户的前提下，以匿名聚合行为、
用户反馈和角色一致性评测校准。

### 证据适用边界

上述研究不是一套可移植的真人好感度公式。回应性和冲突研究大量来自伴侣关系，dormant tie 研究来自
65 岁以上样本，早期友谊研究样本规模也有限；[日本与美国的跨文化研究](https://pubmed.ncbi.nlm.nih.gov/29698009/)
还发现同一关系过程的效应强度会随文化语境变化。因此实现只采用“方向与安全约束”，不复制论文效应量：回应性只温和影响沉淀和信任，
互动稳定性不会成为人格标签，国籍不会产生任何系数，简短、含蓄、间接、少 emoji 或不热烈都不自动扣分。

## 计算流程

每条用户消息沿用原有的 `coach_review` 快速模型调用，同时产生社会信号，避免为好感度增加一轮网络请求。
模型只识别语境中的温暖、回应、尊重、同理、互惠、披露、共鸣、投入、越界、修复、事件重要性和置信度；
最终分数由客户端确定性算法计算。

正向变化具有五层约束：

1. 互动必须超过普通礼貌的中性基线；
2. 同一天重复互动按平方根衰减，避免刷消息；
3. 越接近 150，增长越慢；
4. 未解决的关系张力会暂时限制正向增长。
5. 每个自然日的正向总收益设有上限，不能靠高频发送跨过递减约束。

正向亲近、普通负面判断、可信修复和关系维度变化严格按审阅置信度缩放。置信度为零的正向、普通冷淡或
修复输出只能记录技术接触，不能建立有效联系锚点、重要互动、关系事件或任何亲近变化。只有明确越界和
清晰轻视保留低置信度下的有限谨慎影响：这是一项面向角色安全的非对称策略，不表示系统已经确认用户有
恶意，也不能扩展到简短、低共鸣、暂时没有回应等模糊线索。

明确的不尊重、操纵、骚扰、越界或残酷行为会产生更大的负向变化。负向结果不会因为同日重复而像正向
收益一样显著衰减。越界信号优先于同一次审阅中的矛盾正向字段，不能被错误包装成加分或“更了解彼此”。
普通的不愉快交流影响当前亲近度和张力，但不会直接抹去已沉淀的长期纽带；只有明确越界或极端且重要的
敌意才会改变长期下限。

真诚修复可以降低张力并恢复部分好感，但不会立即抹去伤害。普通正向互动每日最多增加 4，修复另有每日
最多 2 的独立“恢复信用”：这样既不能靠反复道歉刷取关系，也不会因为当日普通收益已满而阻断一次必要的
修复。同日重复道歉不能继续消除张力；之后跨日出现充分回应、尊重、没有新增伤害的可靠行动时，才会继续
有限降低未修复张力。言语道歉可以较快改善当前好感和张力，但其写入长期纽带的比例低于同等质量的可靠
行为；一般友好、敷衍问候或高频消息不算修复跟进。

直接道歉的即时恢复还受两项限制：既往信任和尊重形成有下限的“历史可信度”，当前未修复张力越高，单次
言语道歉的作用越克制。因而重复发生“伤害—隔天道歉”会逐渐削弱同样道歉的恢复信用；真正稳定的跨日行为
仍可通过后续行动通道逐步修复。这里不把宽恕设为用户义务，也不让高历史好感免除新伤害。

“相互了解”不按消息数增长。只有包含安全、可信且确实交换信息的披露、回应或投入才会逐渐增加熟悉度；
无信息量重复、模型低置信度和越界互动都不能伪造熟悉度。

第三代模型进一步区分以下过程：

- **披露与承接**：披露仍可以提供事实信息，但只有伴随理解、同理和回应时，才会更充分沉淀到长期纽带；
  披露不再直接进入亲近度正向项，避免单方面或不合时宜的倾诉自动加分；
- **积极事件回应**：共鸣、回应和投入同时出现时产生很小的协同证据，用来区分主动建设性回应与礼貌敷衍；
- **互动稳定性**：只对有证据的互动维护近期质量预期和可预测性。重复一致的互动逐渐提高稳定性，突然反转
  会降低它；只有“稳定且既往正向”的历史才小幅帮助信任形成，稳定敌意不能被误当可靠，任何情况下都不能
  反转伤害或安全边界；
- **可信修复**：`repair` 必须由回应、同理和尊重支持。“说了抱歉”可以是一点修复意图，但不能等价于承担
  影响、补偿或改变行为；
- **冲突累积**：未解决张力会温和放大后续同类伤害，并继续限制正向增长，但单次伤害仍受确定性上限约束。
- **混合信号安全优先**：清晰轻视具有独立安全成本，不能被同一条消息中的热情、幽默、共鸣或高投入抵消；
  这只针对明确不尊重，不把普通分歧、直接表达或文化差异当轻视。
- **支持匹配与自主**：审阅器只在支持回应了对方实际表达或请求的需要时给高回应性；未经请求的强行解决、
  施压、淡化感受或接管不因“提供了帮助”自动加分。指令式建议可能有实际帮助，但不自动等同关系回应；
  倾听、协作、保留对方选择、询问希望得到什么支持和尊重拒绝可以是正向回应。
- **叙事证据门**：重要性和修复标签只有在同时存在达到最低置信度的实际社会信号时才能写入最近关系事件；
  全零信号不能仅凭模型声称“很重要”制造共同关系历史。

## 时间衰减

时间衰减只作用于“近期活跃亲近度”，不会消耗已经沉淀的长期纽带。对最后结算分数 `S`、长期下限 `F`、
超过宽限期后的不活跃天数 `t` 和关系自适应半衰期 `H`：

```text
displayScore = F + (S - F) × 0.5^(t / H)
```

相互了解和长期下限越高，宽限期和半衰期越长。新关系会较快回到“只是见过”的低下限；深厚关系即使
多年不联系，也只会逐渐接近由共同历史形成的下限，不会因时间自动变成陌生人。明确伤害仍可以降低长期
下限，因为现实中的旧关系可能被事件改变。

v3 会从相邻“有效互动”中学习这段关系自己的跨会话联系间隔。至少两个间隔样本后，稳定的低频关系才会
获得有上限的额外宽限和半衰期；同一聊天内的多条消息不计入节律，一次超长失联也不能单独改变投影。节律
只调整时间曲线，不直接加分，不产生催促消息，也不会取消最终向长期下限收敛。

衰减现在使用“最后有效互动”而不是“最后收到任意消息”。有效互动必须包含达到最低置信度的社会信息；
短而自然的问候可以维护联系，完全空白、无法判断的模型结果和离线兜底只记录技术上的接触，不能无限刷新
衰减时钟。v1 快照在第一次 v2 结算时用旧的最后联系时间迁移一次，此后明确区分两种时间。

## 持久化与一致性

- `RelationshipSnapshot` 跟随 `CharacterEntity` 本地持久化并进入角色内容同步载荷。
- v2 新增最后有效互动、近期互动质量预期和互动稳定性；v3 新增典型联系间隔和间隔样本数。新增字段均可选，
  后端同时接受 v1/v2/v3，同步后自然迁移；v2 的空有效锚点不会被旧技术接触时间错误回填。
- 每次结算记录消息时间、消息 ID 和修订号。最近 64 个消息 ID 构成有界去重账本：不同消息即使乱序
  返回也会分别结算，而同一消息、跨会话重新编号或模型失败后的迟到结果不会再次加减分；“最新消息”
  游标和最后联系时间只向前移动。
- 最近只保留 24 条简短变化说明，避免建立无期限的行为评判档案。
- 联系人详情展示当前好感度、五个关系维度和最近一次变化；不显示阶段标签。
- 角色提示词读取最新关系快照，所有维度只作为软倾向，不能形成突然的阈值式人格切换。
- 关系提示明确禁止凭分数伪造共同经历或个人事实；具体回忆只能来自实际对话或已提供的记忆证据。

## 校准时必须保持的性质

调整权重前必须确保测试覆盖：范围不越界、正向收益递减、负向越界明显、修复有限、乱序幂等、时间只
衰减到长期下限、熟悉度需要有效信息、英语错误不参与关系判断。当前校准过程、曾暴露的缺陷和成熟度
门槛见 [`relationship-calibration-log.md`](relationship-calibration-log.md)。不得只为了提高留存而放大
失联惩罚、主动消息压力或亲密奖励。

日常关系改动先运行 `Scripts/test-relationship.sh`。它默认连续执行三轮关系服务、压力、成熟度和科学性
验证套件，并在每轮输出结构化 xcresult 摘要；可用 `RELATIONSHIP_TEST_PASSES` 调整轮数。专项通过后仍必须运行 `Scripts/test.sh`，因为关系状态同时进入持久化、
同步、聊天提示词和 Debug UI，专项测试不能替代全量回归。

## Debug 好感度实验室

Debug 构建临时增加第五个“测试”Tab，用于在不污染真实数据的情况下检查完整关系模型：

- 从真实联系人载入关系快照，或重置为初识状态；
- 快速应用投机聊天、普通寒暄、尊重分歧、积极消息承接、空洞刷联系、空洞道歉、越界和修复等固定情景；
- 调整全部十二项社会信号，并选择文字、语音、共同活动或剧情来源；
- 让真实模型把自定义聊天文本转换为社会信号，再应用到沙盒；
- 推进 1 天至 1 年，观察渐近衰减；批量检查重复互动、每日上限和冲突修复；
- 展示关系自身的联系节律和跨会话样本数，验证单次长间隔、稳定低频关系和同会话消息的差异；
- 一键运行核心算法回归矩阵，覆盖矛盾信号、乱序结算、普通摩擦、无信息重复、正负零置信度误报、无证据
