# 给相遇一点时间：施工方案

2026-09-10；工作树 8883。用户确认后直接施工，不设必然相遇/必然独处规则。

## 行为与状态

确认行动 → 独立异步准备结果，同时开启 15 秒展示时钟 → 相遇 / 独处 / 等待 / 失败。
Tab Bar 始终可用，活动内容上方覆盖全部场景操作。切 Tab 不取消请求、不重抽、不重计时；
不可见时暂停视频解码与语音，返回按实际经过时间定位。到时不抢占其他 Tab，首页标记未读结果。
应用进入系统后台不保证 iOS 持续执行，回前台按截止时间恢复；不申请无用途的后台执行权限。
正在进行的行动由 App 持有，页面仅观察。一次保留一个未处理行动，避免重复提交。
十五秒后结果未准备好就进入同风格等待；失败明确重试，不能当作独处或增加未相遇次数。

## 概率

初始相遇概率 0.65。连续成功完成的独处次数 m：p = 0.90 - 0.25 × 0.65^m。
始终在 [0.65, 0.90]；不按连续相遇次数强制独处。
同一人物按近期出现次数和距上次时间降权，权重保留正下限，不使用24小时禁止重遇。
城市、语言、移除联系人等身份边界仍为硬约束；非零机会仅适用于符合这些边界的人物。
按账号/城市保存抽签与历史；同一行动重试不重复计数。后端公共池也取消时间硬排除并改为加权抽样。

只允许可免费用于应用的当地实拍，逐项记录源页面、作者、许可、地点证据、原始尺寸/fps/PTS、

优先4K缓慢运镜，按竖屏裁切后速度/方向/亮度匹配；无快切闪白、黑帧和人影叠化。

缺失/损坏资源提供安静底色以保障行动功能，但降级不能作为十五城影像交付。
